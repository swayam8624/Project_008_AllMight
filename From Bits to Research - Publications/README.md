# FROM BITS TO RESEARCH — Reader Publications

Canonical digital exports for the seven-book technical curriculum.

- `EPUB/`: one complete reflowable EPUB per approved book.
- `PDF/`: one complete reading PDF per approved book. No physical parts.
- `Manifests/`: SHA-256 checksums, provenance and release status.
- `Archive/`: superseded or exact-duplicate reader editions retained safely.

A candidate's presence here is not by itself EPUBCheck, mathematical, or reader-display acceptance. Read `../CHATGPT.md` for the seven-book release gates. Run `python tools/publication_library.py verify` to check manifest identity.
