# Chapter Edition

A chapter-by-chapter reading copy of the three continuous masters. All original source spans remain in order; the masters remain authoritative and intact.

Read one substantial chapter at a time. Opening bridges give the context for its first topic; the full lessons, equations, figures, examples and code follow. The reading maps provide goals and recall prompts.

**Length:** roughly 50 estimated pages per chapter. These are reading-size estimates, not measured PDF pages: 400 prose words, 48 wrapped code lines or 36 equation/table lines per page, with allowances for headings and figures. Actual Obsidian, print and screen layouts vary.

**Vault links:** Concepts, Supplementary and image assets are shared with the surrounding Master vault. Copy the vault along with this folder if you need those external companions.

**Updates:** edit a master, then run `python3 tools/build_chapter_edition.py`; `--check` detects stale or altered chapter copies. Human-reviewed boundary plans live in `tools/chapter_plans`. Do not edit generated chapter bodies directly.
