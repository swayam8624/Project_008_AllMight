# Code Parts

This folder contains the repository tools and local development output.

- `tools` contains repository automation, validation, and publishing scripts.
- `C++23 and Native Labs` contains the executable C++23, GPU, and native
  teaching laboratories.
- `C++23 Project Lessons` contains the corresponding learner-facing project
  lessons.
- `Book One Academic Programs` contains the Book One academic programs.
- `Production Tools` contains the LaTeX and EPUB production utilities.
- `CI Workflows` points to the repository workflow definitions.

Shortcuts provide direct access to individual lab and workflow folders.
