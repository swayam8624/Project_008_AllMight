# From Bits to Research

A seven-book technical series by Swayam Singal on how computers represent, render, simulate, and measure worlds. The series moves from bits and C++23 through mathematics, graphics, and game engines to computer vision, XR, and reproducible research.

| Book | Focus |
| --- | --- |
| 1. From Bits to Parallel Systems | C++23, CPU execution, GPU memory, and reliable software |
| 2. From Equations to Geometry | Mathematics, numerical methods, and optimization |
| 3. From Geometry to Images | 3D geometry, transformations, cameras, and projection |
| 4. From Light to Realism | Materials, ray tracing, and light transport |
| 5. From Code to Living Worlds | Game engines, collision detection, and simulation |
| 6. From Frames to Real Time | GPU architecture, Vulkan, Metal, and performance |
| 7. From Perception to Discovery | Vision, neural rendering, XR, and scientific experiments |

The first two ebooks are published on Kindle. Local EPUB and PDF editions live in `From Bits to Research/`, which is Git-ignored.
