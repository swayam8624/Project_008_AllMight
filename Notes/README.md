# Notes

This folder is the notes front door for the repository. Its entries are symbolic
links to the canonical notes and production sources, so there is one source of
truth instead of a copied second vault.

- `Continuous Notes`, `Concepts`, `Visual Recall`, and `Chapter Edition` are
  the main teaching material.
- `Dependency Map.md` and `Keyword Index.md` provide cross-topic navigation.
- `Production XML and Sources` contains the canonical XML, XHTML, source AST,
  and production material used by the book pipeline.
- `Seven-Book Curriculum` contains the reader-facing curriculum and editorial
  policy.

Do not replace these links with copied folders. Update the canonical target and
the linked library updates with it.
