## Conceptual boundaries that must survive

**Active versus passive.** The new 2D studio's \`Affine2::transform_point\` computes a declared affine map. The same matrix can describe a physical motion of an object relative to fixed world axes or a local-to-world coordinate conversion for an unchanged object, depending on what each API frame means. It cannot decide this solely from six numeric coefficients. The full original source should provide a richer discussion of basis-change direction and active/passive inverse relationships.

**Column vectors versus memory order.** In the new P04 header, \(F*G\) means apply \(G\) first, then \(F\). The \`row_major_3x3()\` method is merely an explicit array serialization convention for the same algebraic matrix. It is not a row-vector multiplication API. The original Kairo shader examples have to be rechecked at pinned source revisions before claiming that the teaching API matches any particular engine implementation.

**Point versus direction versus normal.** A point receives translation, a vector does not, and a surface normal requires inverse transpose under nonorthogonal scaling/shear so it remains perpendicular to transformed tangents. A later 3D discussion must handle normal orientation and winding separately. Do not imply an inverse-transpose normal alone resolves every face-facing/reflection policy.

**Affine versus projective.** The new \(\begin{bmatrix}A&t\\0&1\end{bmatrix}\) is a 2D affine matrix. Its homogeneous \(w\) remains one for a point, zero for a vector. A 3D pinhole camera uses a different homogeneous projective representation and can produce nonunit \(w\), which is divided after clipping. The existing original source already develops that; do not crowd it out with this simplified first on-ramp.

**Numerical claims.** \`Affine2::inverse()\` uses a small-classroom relative-determinant guard and finite input checks. That guard can reject some severe anisotropy without proving numerical stability for arbitrary matrices. A true condition-number analysis and robust geometry proof remain in Book 02 and the later Book 03 geometry-predicates chapter. Do not make universal claims from a passing toy transform test.
