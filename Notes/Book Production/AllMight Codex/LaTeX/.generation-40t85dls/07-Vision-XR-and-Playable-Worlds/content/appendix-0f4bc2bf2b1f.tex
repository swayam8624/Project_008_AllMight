\section{Matrix functions}\label{appendix-0f4bc2bf2b1f-matrix-functions}

\hypertarget{appendix-0f4bc2bf2b1f-matrix-functions}{}

For diagonalizable matrices, a scalar function can be applied to eigenvalues in a usable eigenbasis. Matrix exponential models linear constant-coefficient dynamics; logarithm and square root require domain and branch choices. Stable algorithms such as scaling-and-squaring are distinct from the defining power series.

\textbf{Use it when:} integrating linear dynamics or interpolating structured transforms.

\textbf{Developed in Phase 8:} A matrix function applies scalar behavior to invariant directions when the decomposition permits it, but its definition and its stable algorithm are separate. The exponential solves a linear differential equation; logarithms and square roots require domain and branch choices, and powers range from repeated multiplication to fractional transforms. \href{../02-Mathematics-for-Visual-Computing/main.pdf\#nameddest=02-foundations-ii-ch026-matrix-functions-turn-repeated-linear-actions-into-one-operator}{matrix functions (Mathematics for Visual Computing, Ch. 10)} · \href{../02-Mathematics-for-Visual-Computing/main.pdf\#nameddest=02-foundations-ii-ch026-logarithms-and-square-roots-need-domains-and-branches}{domains and branches (Mathematics for Visual Computing, Ch. 10)}
