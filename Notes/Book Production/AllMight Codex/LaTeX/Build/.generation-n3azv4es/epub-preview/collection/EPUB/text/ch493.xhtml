Linear systems and fundamental subspaces

A linear system A x = b asks which inputs satisfy all row measurements at once. It is consistent exactly when b lies in the column space. The null space contains input changes invisible to every measurement; rank-nullity counts observable versus free directions.

Use it when: explaining consistency, underdetermination, least squares, parameter observability, or constraints in geometry.

Developed in Phase 8: The expanded treatment connects each row to a hyperplane and the complete matrix to a map: consistency asks whether the target lies in the column space, while the null space describes every invisible change to a solution. Rank then counts constrained directions and determines the dimension of the solution family. constraint geometry (Mathematics for Visual Computing, Part 1, Ch. 3) · rank and solution families (Mathematics for Visual Computing, Part 1, Ch. 3)
