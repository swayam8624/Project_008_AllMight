SIMD and GPU data layouts

Curriculum depth: Developed · First seen: C001 · Latest development: C003

Definition and mechanism

Wider words, lanes, buffers, pixels, and vertex formats reuse exact-width representation and packing principles.

SIMD applies an operation across multiple data lanes; GPU buffers and formats specify how values are arranged for parallel access. Packing can reduce traffic but adds decoding and alignment constraints. Lane layout, alignment, and access grouping require later treatment.

Prerequisites

  • Machine word (Bits, Programs, and Reliable Systems, Part 1, Reference notes: Machine word) — A processor’s natural integer processing width is often called its word width, but the term is architecture dependent.
  • Alignment and padding (Bits, Programs, and Reliable Systems, Part 2, Reference notes: Alignment and padding) — Alignment is a required address multiple for an object.

M003 development

Alignment of vector loads and buffer offsets is a separate requirement from endian order. Packed structures and misaligned access (Bits, Programs, and Reliable Systems, Part 2, Reference notes: Packed structures and misaligned access) may save space but introduce boundary crossings; Field reordering and AoS versus SoA (Bits, Programs, and Reliable Systems, Part 2, Reference notes: Field reordering and AoS versus SoA) can improve fieldwise access. CPU ABI layout is not automatically a GPU buffer schema.
