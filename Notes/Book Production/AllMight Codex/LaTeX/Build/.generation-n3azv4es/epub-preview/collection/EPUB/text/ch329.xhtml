Singular value decomposition

For any real rectangular matrix, A = U Σ V T . Right singular vectors are input directions, left singular vectors are output directions, and nonnegative singular values are principal stretches. Unlike eigenvectors, the two sets live in different spaces.

Use it when: revealing rank and conditioning, solving rank-uncertain least squares, compressing a matrix, or understanding PCA.

Developed in Phase 8: The SVD expresses a rectangular map using orthonormal input and output directions joined by nonnegative stretches. University course development

Extend the existing factorization note with its role in estimation, conditioning, and geometry. For matrix A , the decomposition A = U Σ V T separates orthogonal input directions, axis-aligned scaling, and orthogonal output directions. Singular values on the diagonal of Σ quantify how strongly each independent direction is preserved; a zero or tiny value signals rank loss or poor conditioning. Least-squares fitting can use this structure to identify which parameter combinations are well constrained and to avoid amplifying measurement noise along nearly invisible directions. The same analysis explains why a camera calibration or bundle-adjustment system can have gauge freedoms: translating or scaling the entire reconstruction may leave image measurements unchanged. Singular values diagnose these ambiguities, while constraints or fixed reference poses remove them. Thus SVD links linear algebra to robust vision, not just matrix compression.
