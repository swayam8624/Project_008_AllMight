Off-axis stereo projection and disparity

Curriculum depth: Developed · First seen: Phase 11 · Latest development: Phase 11

Definition and mechanism

Stereo cameras use two eye centres separated by a baseline, while each projection frustum is shifted so a chosen zero-parallax plane aligns in the images. Parallel eye orientations with asymmetric frusta avoid the vertical mismatch and discomfort often introduced by toe-in cameras. For rectified pinhole cameras, disparity is approximately Δ x = f x B / Z , so inferred depth is Z = f x B / Δ x under the calibration and rectification assumptions. Depth uncertainty grows roughly with Z 2 for fixed pixel disparity error. Distinguish interpupillary distance from lens and display-centre spacing; the rendered baseline is an optical/comfort design decision. Use consistent pixel units for focal length, baseline, and disparity before computing metric depth.
