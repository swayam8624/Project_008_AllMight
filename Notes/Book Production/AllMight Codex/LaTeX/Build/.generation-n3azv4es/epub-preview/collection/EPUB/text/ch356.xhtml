Hough transform and geometric voting

Curriculum depth: Developed · First seen: University courses · Latest development: University courses

Definition and mechanism

The Hough transform detects a parametric shape by letting each image feature vote for compatible shape parameters. A line can be represented by normal angle θ and signed distance ρ , avoiding the vertical-line singularity of slope-intercept form. Each edge point votes along a curve in ( ρ , θ ) space; a bin with many votes indicates a line supported by many image points. Circle detection adds center and radius parameters, increasing accumulator dimension and cost. Quantization controls a tradeoff: coarse bins merge nearby hypotheses but reduce precision; fine bins need more votes and memory. Gradient direction can restrict votes and reduce clutter. The transform tolerates missing edge segments because evidence accumulates globally, but unrelated edges can also create peaks, so candidates need geometric validation and robust fitting.
