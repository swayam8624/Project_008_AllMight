\section{Const qualification and shallow constness}\label{appendix-c25d60fed375-const-qualification-and-shallow-constness}

\textbf{Curriculum depth:} Introduced · \textbf{First seen:} C008 · \textbf{Latest development:} C008

\subsection{Definition and mechanism}\label{appendix-c25d60fed375-definition-and-mechanism}

Const restricts modification through an access path; another mutable alias can change a mutable referent. An actually const object cannot be made writable by const\_cast. Pointer-member constness is shallow: const span\textless int\textgreater{} permits integer writes whereas span does not.
