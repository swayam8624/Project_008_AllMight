\section{Absolute and relative error}\label{appendix-3ae74e89b4e6-absolute-and-relative-error}

\textbf{Curriculum depth:} Introduced · \textbf{First seen:} C005 · \textbf{Latest development:} Phase 10

\subsection{Definition and mechanism}\label{appendix-3ae74e89b4e6-definition-and-mechanism}

Absolute error \textbar computed−reference\textbar{} has the reference's units. Relative error divides by nonzero reference magnitude and is dimensionless; it is undefined at true zero. A 1e-12 absolute error can be 100\% of a 1e-12 value.
