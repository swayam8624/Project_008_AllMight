\section*{Matrix functions}
\section{Matrix functions}\label{matrix-functions}

For diagonalizable matrices, a scalar function can be applied to eigenvalues in a usable eigenbasis. Matrix exponential models linear constant-coefficient dynamics; logarithm and square root require domain and branch choices. Stable algorithms such as scaling-and-squaring are distinct from the defining power series.

\textbf{Use it when:} integrating linear dynamics or interpolating structured transforms.

\textbf{Developed in Phase 8:} A matrix function applies scalar behavior to invariant directions when the decomposition permits it, but its definition and its stable algorithm are separate.
