\section{LU factorization and reusable solves}\label{appendix-55e4b5b0a1e6-lu-factorization-and-reusable-solves}

LU stores elimination as triangular factors. With row pivoting in this vault's convention, \(PA=LU\); apply the same permutation to each right-hand side, then solve one lower- and one upper-triangular system. Factorization cost is amortized across repeated solves.

\textbf{Use it when:} solving square general systems, especially with multiple right-hand sides.

\textbf{Developed in Phase 8:} The multipliers used to eliminate entries become the lower factor, while the remaining upper triangle records the reduced system; with row exchanges the convention is \(PA=LU\).
