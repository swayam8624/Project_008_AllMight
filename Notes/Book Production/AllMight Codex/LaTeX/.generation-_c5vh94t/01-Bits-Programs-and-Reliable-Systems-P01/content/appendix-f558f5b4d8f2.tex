\begin{allmightroledefinition}

\subsection{Definition and mechanism}\label{appendix-f558f5b4d8f2-definition-and-mechanism}

\hypertarget{appendix-f558f5b4d8f2-definition-and-mechanism}{}

Invalid shifts, out-of-bounds access, signed overflow, division by zero, and \texttt{INT\_MIN\ /\ -1} provide no valid C++ execution result; optimizers may assume they never occur.

\end{allmightroledefinition}

The C++ language imposes no requirements on an execution that invokes undefined behavior. It is not an error value or a guaranteed trap. Signed overflow, division by zero, invalid shift counts, and out-of-bounds accesses are examples. Check preconditions before performing the operation.
