# Matrix functions

For diagonalizable matrices, a scalar function can be applied to eigenvalues in a usable eigenbasis. Matrix exponential models linear constant-coefficient dynamics; logarithm and square root require domain and branch choices. Stable algorithms such as scaling-and-squaring are distinct from the defining power series.

**Use it when:** integrating linear dynamics or interpolating structured transforms.

**Developed in Phase 8:** A matrix function applies scalar behavior to invariant directions when the decomposition permits it, but its definition and its stable algorithm are separate. The exponential solves a linear differential equation; logarithms and square roots require domain and branch choices, and powers range from repeated multiplication to fractional transforms.
