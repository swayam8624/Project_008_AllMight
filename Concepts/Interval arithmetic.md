# Interval arithmetic

**Curriculum depth:** Introduced · **First seen:** C004 · **Latest development:** C004

## Definition and mechanism

An interval encloses a possible exact value between lower and upper bounds. Correct outward rounding can preserve containment when the whole algorithm honors necessary assumptions.

- [[Directed rounding modes]] — The signed rounding direction is state that a demonstration or enclosure algorithm must control.
