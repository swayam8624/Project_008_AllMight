# Bit

**Curriculum depth:** Introduced · **First seen:** C001 · **Latest development:** C001

## Definition and mechanism

A two-state unit of information whose meaning depends on an interpretation contract.

A bit has two possible logical states. Eight independent bits have 2⁸ = 256 patterns because each position doubles the choices. A Boolean value is a truth value; a stored bit may instead be part of a number, instruction, or format field.
