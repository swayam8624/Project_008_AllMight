# Visual acuity and eccentricity

**Curriculum depth:** Introduced · **First seen:** XR01 · **Latest development:** XR01

## Definition and mechanism

Acuity is task-specific fine-detail performance; MAR specifies an angular feature convention. A linear eccentricity model is a useful approximation, not a complete visibility law. Detection, resolution, hyperacuity and recognition have different thresholds.
