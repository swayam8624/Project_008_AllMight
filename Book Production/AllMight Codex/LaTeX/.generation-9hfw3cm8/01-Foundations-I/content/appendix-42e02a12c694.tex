\subsection{Definition and mechanism}\label{appendix-42e02a12c694-definition-and-mechanism}

Declarations, deletion and expression usability differ. A user-declared destructor suppresses dedicated implicit moves even when defaulted. is\_move\_constructible asks if construction from T\&\& works, which can use copying; an explicitly deleted best move can still reject that expression.
