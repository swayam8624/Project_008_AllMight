\subsection{Definition and mechanism}\label{definition-and-mechanism}

\texttt{std::weak\_ptr\textless{}T\textgreater{}} observes a \texttt{shared\_ptr} ownership group without increasing its strong count. \texttt{lock()} atomically attempts to create a temporary strong owner; the result is empty if the managed object is no longer alive. Replacing one edge of an otherwise all-strong ownership cycle with a weak observation can allow the strong count to reach zero. A check with \texttt{expired()} followed later by access is not equivalent to a successful \texttt{lock()}.

\texttt{enable\_shared\_from\_this} joins the already-established shared ownership group; it must not create a second \texttt{shared\_ptr} control block from \texttt{this}.
