\section{Pages and page offsets}\label{appendix-0c67cd5bf30a-pages-and-page-offsets}

\hypertarget{appendix-0c67cd5bf30a-pages-and-page-offsets}{}

\textbf{Curriculum depth:} Introduced · \textbf{First seen:} C003 · \textbf{Latest development:} C003

\begin{allmightroledefinition}

\subsection{Definition and mechanism}\label{appendix-0c67cd5bf30a-definition-and-mechanism}

\hypertarget{appendix-0c67cd5bf30a-definition-and-mechanism}{}

A page is a virtual address block; a frame is page-sized physical backing. With page size P=2\^{}k, divide VA into VPN=floor(VA/P) and offset=VA mod P. Translation substitutes frame identity while preserving offset. The 4-KiB examples use k=12; actual supported sizes are platform-dependent.

\end{allmightroledefinition}
