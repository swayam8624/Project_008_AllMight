\hypertarget{use-identifier_name-in-a-heading}{}

A long condition can break while preserving its characters:
\BookInlineCode{matches\ \&\&\ candidate-\textgreater layout\_buffer{[}index{]}\ ==\ no\_previous\_owner\_and\_current\_generation\_is\_valid}.
The path
\BookInlineCode{some/long/directory/name\_with\_underscores/and/file.hpp}
also fits.

The Windows path
\BookInlineCode{C:\textbackslash\textbackslash cache\textbackslash\textbackslash shader\_sources\textbackslash\textbackslash material\_cache.hpp}
stays visible.

\textbf{Strong code:}
\BookInlineCode{left\_side.field\_name\ ==\ right\_side.value\ \&\&\ pointer-\textgreater next\ !=\ nullptr}.
