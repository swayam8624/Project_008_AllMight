# Use `identifier_name` in a heading

A long condition can break while preserving its characters: `matches && candidate->layout_buffer[index] == no_previous_owner_and_current_generation_is_valid`. The path `some/long/directory/name_with_underscores/and/file.hpp` also fits.

The Windows path `C:\\cache\\shader_sources\\material_cache.hpp` stays visible.

**Strong code:** `left_side.field_name == right_side.value && pointer->next != nullptr`.
