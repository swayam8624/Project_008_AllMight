\begin{allmightroledefinition}

\subsection{Definition and mechanism}\label{appendix-d6d562ca9fbb-definition-and-mechanism}

\hypertarget{appendix-d6d562ca9fbb-definition-and-mechanism}{}

A reference is an alias established by binding, not a reseatable pointer object. Assignment through it assigns the referent. In \texttt{int\&\ r=a;\ r=b;}, r still names a. A reference definition needs a binding; an extern reference declaration can defer the definition. References can dangle and are non-owning.

\end{allmightroledefinition}
