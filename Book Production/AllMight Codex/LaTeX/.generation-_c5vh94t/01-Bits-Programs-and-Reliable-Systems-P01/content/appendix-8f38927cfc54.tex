\begin{allmightroledefinition}

\subsection{Definition and mechanism}\label{appendix-8f38927cfc54-definition-and-mechanism}

\hypertarget{appendix-8f38927cfc54-definition-and-mechanism}{}

Complements every lane within an explicit representation width.

\end{allmightroledefinition}

Complement must specify width: eight-bit complement of \texttt{0x0F} is \texttt{0xF0}, while sixteen-bit complement is \texttt{0xFFF0}. C++ first promotes narrow operands, so \texttt{\textasciitilde{}uint8\_t\{0\}} usually has type int and value −1. Cast or mask intentionally when retaining eight bits.
