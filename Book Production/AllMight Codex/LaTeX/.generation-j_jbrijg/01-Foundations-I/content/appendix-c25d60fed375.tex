\section{Definition and mechanism}\label{appendix-c25d60fed375-definition-and-mechanism}

Const restricts modification through an access path; another mutable alias can change a mutable referent. An actually const object cannot be made writable by const\_cast. Pointer-member constness is shallow: const span\textless int\textgreater{} permits integer writes whereas span does not.
