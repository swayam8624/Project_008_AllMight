\section{Sparse and iterative solvers}\label{appendix-67c87a3d9e94-sparse-and-iterative-solvers}

Sparse storage avoids zeros when structure and scale justify its index overhead. Iterative methods replace a dense factorization with matrix-vector products and a convergence process. Conjugate gradient requires symmetric positive definiteness; preconditioning, residual criteria, and a maximum iteration count belong in the contract.

\textbf{Use it when:} large structured systems make dense storage or factorization impractical.

\textbf{Developed in Phase 8:} Sparse storage pays off when zeros and dimensions outweigh indexing overhead, while direct factorization can create fill that destroys sparsity. Iterative methods instead use matrix-vector products and stopping tests; conjugate gradient requires an SPD operator, and preconditioning, a maximum iteration count, and a true residual make convergence reviewable. \href{../03-Geometry-Cameras-and-Image-Formation/main.pdf\#nameddest=02-foundations-ii-ch038-sparse-storage-changes-the-cost-model}{storage and fill (Geometry, Cameras, and Image Formation, Geometry, Cameras, and Image Formation, Chapter 7)} · \href{../03-Geometry-Cameras-and-Image-Formation/main.pdf\#nameddest=02-foundations-ii-ch038-direct-and-iterative-solvers-suit-different-workloads}{direct versus iterative solving (Geometry, Cameras, and Image Formation, Geometry, Cameras, and Image Formation, Chapter 7)}
