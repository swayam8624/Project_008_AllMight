Real projections add scale, spacing, and incidence geometry

The real setting adds scales

For unit balls X in a large ball B R ⊂ R 2 , take directions D ⊂ S 1 separated at angle 1 / R . Let S = max θ ∈ D | π θ ( X ) | denote projected one-dimensional measure. Clustering matters, so define

N X ( r ) = max c | X ∩ B ( c , r ) | , N D ( ρ ) = max | γ | = ρ | D ∩ γ | .

A pair of balls at distance about r can collide only for directions in an arc of width O ( 1 / r ) . Summing over dyadic distances gives

| D | | X | S ≲ ∑ 1 ≤ r ≤ R N X ( r ) N D ( 1 / r ) .

This is the real double-counting inequality. Hausdorff spacing controls both clustering functions at every scale and collapses the sum to a finite-field-like alternative; without it, a tightly clustered cloud behaves very differently from a spread-out grid.

Fourier analysis supplies a complementary estimate. Smooth a tube indicator, decompose into dyadic frequency annuli, and use that a frequency piece at radius 1 / r is locally constant on spatial r -balls. Distinct tubes have negligible inner product unless they fit in a common O ( r ) × O ( R ) container. The number of tubes in such a container is the scale-dependent tube-clustering factor. The detailed Fourier normalization and weighted local-constancy step appear below.

Sieve and incidence geometry

The large sieve is a parallel sampling principle. Reducing f : [ N ] → C modulo many primes samples its Fourier transform at rational frequencies α / p . Distinct reduced fractions with p ∼ M are separated by ≳ M − 2 ; when M 2 ≤ N , this is at least the local-constancy scale 1 / N . Plancherel then bounds the total mean-zero residue-class energy. Quadratic-residue sparsity gives the model application. It is an arithmetic energy estimate analogous to projection Fourier bounds, not itself a geometric projection theorem.

For m points and n lines in R 2 , Szemerédi–Trotter states

I ( P , L ) ≲ m 2 / 3 n 2 / 3 + m + n .

The crossing proof joins consecutive incident points on each line, applies the graph crossing lemma, and uses that two distinct lines cross at most once. Polynomial partitioning instead distributes points among O ( D 2 ) cells, each with O ( m / D 2 ) points; a line crosses O ( D ) cells. The cell argument proves the sharp exponent but forgets how one line’s incidence pattern is coordinated across different cells, so it does not classify grid-like near-extremizers.

This explains why equal total cardinalities are not equivalent: on a curve-neighborhood N X ( r ) ∼ r ; a spread grid changes from one point per ball to about r 2 points at larger scales; a tight cluster accumulates quadratically until the whole cloud is captured. Under Hausdorff spacing for both points and directions, the dyadic sum becomes a logarithmic loss times the largest endpoint term. Fourier analysis gives the complementary bound. Smooth 1 × R tubes, decompose their sum into dyadic frequency annuli | ξ | ∼ 1 / r , and note the piece has support in B ( 0 , O ( 1 / r ) ) , so it is nearly constant on spatial r -balls. Sumsets, energy, and robust structure (Lectures 10–12)

A set can resist additive growth because it sits in a low-dimensional arithmetic pattern. An arithmetic progression A = a + { 0 , … , L − 1 } d has | A + A | ≤ 2 | A | . A rank- r generalized arithmetic progression

A = a + { n 1 d 1 + ⋯ + n r d r : 0 ≤ n j < L j }

has | A + A | ≤ 2 r | A | . Freiman–Ruzsa says conversely that bounded doubling | A + A | ≤ K | A | forces containment in a generalized progression whose rank and volume factor depend only on K . This is a structural classification, but the dependence is enormous; the polynomial Freiman–Ruzsa conjecture asks for meaningful control already when K is a small power of | A | .

Two short inequalities let us propagate smallness without invoking that deep classification. For finite subsets of an abelian group,

| A | | B − C | ≤ | A − B | | A − C | .

For each d ∈ B − C , fix b ( d ) − c ( d ) = d ; the map ( a , d ) ↦ ( a − b ( d ) , a − c ( d ) ) is injective, since subtracting its coordinates recovers d , and then one coordinate recovers a . Substituting B = C = − A gives | A − A | ≤ K 2 | A | whenever | A + A | ≤ K | A | . Plünnecke’s inequality says that if | A + B | ≤ K | A | , then for integers m , n ≥ 0 ,

| B ⊕ m − B ⊕ n | ≤ K m + n | A | .

Petridis’ proof picks X ⊂ A minimizing | X + B | / | X | = K ¯ ≤ K . Inductively prove | X + C + B | ≤ K ¯ | X + C | for every finite C : when a new translate c is added, separate the new sums and use the minimizing property on the subset of X whose c + B translate is already covered. Iterating with C = B ⊕ j gives | X + B ⊕ m | ≤ K m | X | ; Ruzsa’s inequality then compares B ⊕ m − B ⊕ n with the two iterated sumsets above. This is why small sumsets yield a whole family of small derived sets.

A prime field has no proper subfield, but a quantitative proof needs to rule out approximate subfields. Define the ratio set ( A − A ) / ( A − A ) using nonzero denominators. If c is outside the ratio set, then a 1 + c a 2 has a unique representation: two representations with unequal second coordinates would solve for c as a difference ratio; equal second coordinates force equal first coordinates. Therefore | A + c A | = | A | 2 . If the ratio set is proper, the prime-field fact that repeated addition of 1 visits every element supplies a b in it with b + 1 outside. Write b as a quotient of differences, insert the representation into A + ( b + 1 ) A , and clear denominators as a literal set map. The resulting bounded-complexity expression in A must have at least | A | 2 values unless the ratio set is already all of F p . This denominator-clearing detail matters: multiplying a set by a denominator does not preserve cardinality if the denominator might vanish, so the rational expression is defined only on nonzero denominators and then expanded algebraically.

The course bootstraps this lemma with Plünnecke and Ruzsa to prove the sum-product theorem. If | A | = p s with 0 < s < 1 , then for some ε ( s ) > 0 ,

max ( | A + A | , | A ⋅ A | ) ≥ p s + ε ( s ) .

An arithmetic progression can have small sumset, and a geometric progression can have small product set; the theorem says a proper prime-field subset cannot keep both operations small. The classroom proof first proves a bounded algebraic expression such as A ⊕ 3 − A ⊕ 3 expands by a power. Under the contrary assumption of small growth, Plünnecke bounds iterated additive combinations, and the multiplicative form of Ruzsa’s inequality transfers those bounds to a quotient of the expression from the approximate-subfield lemma, contradicting its lower bound. The gains and losses depend on s and are small; constants and the explicit epsilon formula are suppressed in the lecture. Repeated application shows that for any s < t < 1 , a bounded-complexity expression Poly K ( A ) can be made to have at least p t elements, where K = K ( s , t ) .

Now let D ⊂ F p be a set of slopes. If every A + t A ( t ∈ D ) were small, contagious structure would force smallness for slopes formed by bounded additions, products, and sign changes of elements of D . Sum-product expansion makes this generated slope set larger than A ; finite-field double counting then says one of its projections must be large, a contradiction. Quantitatively, if | A | = p s A and | D | = p s D with 0 < s A < 1 and s D > 0 , there is ε ( s A , s D ) > 0 such that

max t ∈ D | A + t A | ≥ p s A + ε | A | .

The direct double-counting bound already settles s D ≥ s A ; the sum-product/contagious-structure argument handles the harder s D < s A case. This theorem is exactly the product-set projection case X = A × A .

Why does the product-set case not immediately imply BKT for arbitrary X ⊂ F p 2 ? After normalizing two directions to horizontal and vertical, let A = π 0 ( X ) ∪ π ∞ ( X ) , so X ⊂ A × A and, under a hypothetical near-square-root small-projection bound, X is a large fraction of the product. But a large subset can concentrate on a few unusually heavy fibers while the rest of the product supplies most of its projection values. For example, the diagonal in A × A has a single value under π − 1 ; a grid plus a comparably sized random garbage set shows that the whole product can have a large image even when a large structured portion has small image. The BSG theorem removes this garbage.

In restricted-projection form, if A , B have size at most N , X ⊂ A × B , | X | ≥ K − 1 N 2 , and | π t ( X ) | ≤ K N , then BSG finds A ′ ⊂ A , B ′ ⊂ B such that X ′ = X ∩ ( A ′ × B ′ ) still has size at least K − O ( 1 ) N 2 and | A ′ + t B ′ | ≤ K O ( 1 ) N . The reason is Cauchy–Schwarz: the many pairs in X landing in few projection values create high additive energy; BSG turns that energy into large subsets with small full sumset. Applying Plünnecke–Ruzsa gives small A ′ − A ′ as well.

The remaining symmetry lemma is the bridge from a large subset back to its product. Fix a direction t 1 with A ′ + t 1 B ′ small. For any t , fix one pair ( a 1 , a 2 ) ∈ A ′ × A ′ representing each value c = a 1 − ( t / t 1 ) a 2 in π − t / t 1 ( A ′ × A ′ ) . The map

( c , ( a , b ) ) ↦ ( a 1 − a ,   a 2 + t 1 b ,   a + t b ) , ( a , b ) ∈ X ′ ,

is injective from π − t / t 1 ( A ′ × A ′ ) × X ′ into ( A ′ − A ′ ) × ( A ′ + t 1 B ′ ) × π t ( X ′ ) . Indeed, from outputs ( u , v , w ) recover the chosen projection value c = u − ( t / t 1 ) v + w ; that fixes ( a 1 , a 2 ) , then a = a 1 − u , and b = ( w − a ) / t (handle t = 0 separately by the trivial coordinate projection). Thus

| π t ( X ′ ) | ≥ | X ′ | N 2 | π − t / t 1 ( A ′ × A ′ ) | .

Since | X ′ | is a fixed power fraction of N 2 and the transformed slope set still has positive power size, the product-set BKT estimate forces one of these images to grow. Choosing the contradiction epsilon much smaller than the product-case gain absorbs the K O ( 1 ) losses from BSG and the small-set inequalities. This proves the full finite-field projection theorem.

E ( A , B ) = # { ( a 1 , a 2 , b 1 , b 2 ) ∈ A 2 × B 2 : a 1 + b 1 = a 2 + b 2 } = ∑ z r A , B ( z ) 2 ,

where r A , B ( z ) = # { ( a , b ) ∈ A × B : a + b = z } . Since ∑ z r A , B ( z ) = | A | | B | , Cauchy–Schwarz gives

| A | 2 | B | 2 ≤ | A + B | E ( A , B ) .

| Y | 2 ≤ | π 1 ( Y ) | E ( A , B ) .

The course therefore uses cardinality for algebraic propagation and energy/BSG for robust passage to large subsets.

Why the Euclidean projection theorem needs scale regularity

The finite-field Bourgain–Katz–Tao theorem says that if X ⊂ F p 2 has p t points and the direction set D ⊂ F p has p s slopes, then some projection π θ ( x 1 , x 2 ) = x 1 + θ x 2 has at least p t / 2 + ε values; a robust version says the same direction expands every sufficiently dense subset of X . The exponent t / 2 is the elementary baseline: two distinct slopes determine a point by an invertible 2 × 2 linear system, so the map x ↦ ( π θ 1 x , π θ 2 x ) is injective. Thus | X | ≤ | π θ 1 X | | π θ 2 X | , forcing one image to have size at least | X | 1 / 2 . [P2-14]

The analogous real theorem cannot hold for arbitrary unions of unit balls inside a large ball. A thin 1 × R rectangle projected near its short direction has image length only about R s if the direction set is concentrated in an interval of width R s ; when s < t / 2 , this can be below the square-root scale R t / 2 . Even a well-spread set of directions cannot fix a clustered point set: a ball of radius R 1 / 2 has area about R and every projection has length about R 1 / 2 . These show two distinct failures: the directions can cluster in slope, or the points can cluster spatially. Therefore Bourgain’s real result assumes power-law nonconcentration of both.

After rescaling to the unit ball and resolution δ = 1 / R , measure sets by the δ -covering number | X | δ , the smallest number of radius- δ balls that cover X . For a 2 δ -separated finite set this is its cardinality; for a union of bounded-overlap δ -balls in R d it is comparable, with constants depending only on d , to δ − d times Lebesgue measure. It is also comparable to the number of mesh cubes of side δ that meet the set. Define a ( δ , s , C ) d set by

| X ∩ B ( x , r ) | δ ≤ C r s | X | δ ( δ ≤ r ≤ 1 ) .

This says no ball at an intermediate scale captures too much of the set; s is a dimension-like nonconcentration exponent and C is a tolerance constant. In the projection theorem C = δ − η for a small η > 0 . If X has global size δ − t and D ⊂ [ 0 , 1 ] has size δ − s , and both obey their corresponding nonconcentration conditions, then some direction projects every subset Y ⊂ X with | Y | δ ≥ δ η | X | δ to size at least δ − t / 2 − ε . The same parameter θ works for all such Y . This robust quantifier matters because later steps repeatedly pass to large subsets.

The cover-number language lets familiar discrete tools survive in Euclidean space. Snap points to a mesh at scale δ ; bounded-scale sums and differences can move a snapped point only a bounded number of mesh cells, so Ruzsa triangle, Plünnecke, and BSG inequalities transfer with dimension-dependent multiplicative losses. For example, | B | δ | A − C | δ ≲ d | A − B | δ | B − C | δ . The “almost commutes” qualification is important: snapping a difference is not exactly the difference of snapped representatives, but only a bounded number of neighboring mesh cells are involved.

In the prime-field proof, one studies the ratio set ( A − A ) / ( A − A ) . If it is proper, the fact that repeated addition of 1 traverses the whole prime field lets us choose an element b inside it but b + 1 outside; this forces polynomial growth. Over R , a direct copy fails: a small interval has little additive or multiplicative growth; ratios may be unbounded from tiny denominators; “add one” can leave the reference interval; and R has many additive subgroups. The real proof therefore first cuts off denominators smaller than δ γ and intersects the resulting ratio-like set with [ 0 , 1 ] . It then uses order and gaps rather than field simplicity.

Specifically, for a closed B ⊂ [ 0 , 1 ] containing 0 , 1 , let ρ be the supremum length of complementary intervals. Form B ′ = B / 2 ∪ ( B + 1 ) / 2 . Since 1 / 2 ∈ B ′ , a gap in B ′ cannot cross the midpoint; each half is a scaled copy of B , so every gap has length at most ρ / 2 . Choose an almost-largest gap of B with length ρ − o ( ρ ) and take a centered subinterval of length about ρ / 2 . This subinterval contains a point of B ′ (otherwise it would create a larger gap in B ′ ), and that point is at distance at least a fixed fraction, say ρ / 5 , from B . Since the point is either b / 2 or ( b + 1 ) / 2 for some b ∈ B , one of these affine transforms escapes B by a definite gap. Thus either B is ρ -dense or there is a controlled escaping value, playing the role of the finite-field b + 1 ∉ B . The precise constants are inessential; the order structure on the real line is essential. This yields a polynomial-expansion lemma under nonconcentration hypotheses, but only at the chosen resolution at first. Iterating it requires a further mechanism to preserve those hypotheses. Uniform trees make multiscale size usable

A set can be large at the finest scale and still fail to have enough points at coarser scales. Uniform sets repair this mismatch. Choose a dyadic base Δ ∈ ( 0 , 1 ) and a depth m , with bottom scale δ = Δ m . Tile [ 0 , 1 ] d by nested half-open cubes of side Δ j . For each level- j cube Q that meets X , count the level- ( j + 1 ) children that meet X . The set is ( Δ , m ) -uniform if this number is the same, R j , for every occupied parent at level j . The branching factor may vary with level but not from parent to parent. Equivalently, the occupied cubes form a rooted tree with a level-dependent regular branching number. Uniformity makes the number of descendants below any occupied cube a product of the same R i ’s, independent of which branch was chosen.

Two consequences explain the value of this bookkeeping. First, for a uniform set, if at every dyadic scale ρ ∈ { 1 , Δ , … , Δ m } its covering number is at least C − 1 ρ − s , then it is a ( δ , s , O Δ ( C ) ) set. To see it, take an occupied level- j cube Q . It contains one occupied level- j cube, and its number of bottom descendants is R j ⋯ R m − 1 . The whole set has R 0 ⋯ R m − 1 bottom descendants and R 0 ⋯ R j − 1 level- j cubes. Their ratio gives

| X ∩ Q | δ = | X | δ | X | Δ j .

The assumed lower bound | X | Δ j ≥ C − 1 ( Δ j ) − s rearranges to | X ∩ Q | δ ≤ C ( Δ j ) s | X | δ . A ball meets only boundedly many cubes of its comparable scale. Between adjacent powers of Δ , sandwich the radius and lose only a constant depending on Δ , d . Thus scale-by-scale lower bounds imply local nonconcentration. Second, if X is already ( δ , s , C ) and uniform, the same descendant ratio plus the lower bound | X | ρ ≥ C − 1 ρ − s shows that the set is ( ρ , s , O Δ ( C ) ) at every coarser resolution ρ ≥ δ . This addresses the failure that a fine-scale nonconcentration condition alone says nothing about a much coarser covering scale. [P2-15]

Any set contains a large uniform subset, by a bottom-up pruning argument. Let μ be any subadditive set function ( μ ( E ∪ F ) ≤ μ ( E ) + μ ( F ) ); the δ -covering number is an important example. Begin at the finest level. For each parent cube, its branching number is between 1 and at most Δ − d . Group parents by dyadic ranges [ 2 ℓ , 2 ℓ + 1 ) . There are at most O ( d log ⁡ ( 1 / Δ ) ) groups. Subadditivity says the total μ -mass is at most the sum of group masses, so one group retains at least a reciprocal-logarithmic fraction. Within that group, trim every parent down to exactly 2 ℓ occupied children; because each had fewer than 2 ℓ + 1 , this costs at most another factor of two. Now all surviving parents have the same branching factor. Repeat at the next coarser level. Working from leaves upward preserves uniformity already established at finer levels: removing a parent branch does not alter the descendant count inside branches that remain. After m levels we have a uniform Y ⊂ X with

μ ( Y ) ≥ [ 2 d log ⁡ ( 1 / Δ ) ] − m μ ( X ) = δ − σ μ ( X ) , σ = log ⁡ ( 2 d log ⁡ ( 1 / Δ ) ) log ⁡ ( 1 / Δ ) .

The loss is a small power of δ when Δ is chosen sufficiently small, since σ → 0 as Δ → 0 . This pruning is not ordinary measure-theoretic density; only subadditivity is needed, so it works for covering number and for specialized set functions used to measure fibers.

Szemerédi–Trotter partitioning and the cross-cell limitation

For m points and n lines, first remove incidences from lines with fewer than a fixed number of points; this costs O ( m + n ) . Join consecutive incident points along each remaining line. The resulting graph has V = m vertices and E ≳ I edges. In a drawing with E ≥ 4 V , the crossing lemma gives at least c E 3 / V 2 crossings. Two distinct straight lines cross at most once, so the drawing has at most O ( n 2 ) crossings (after a generic perturbation resolves multiple edges at a point without increasing the relevant order). Thus I 3 / m 2 ≲ n 2 , or I ≲ m 2 / 3 n 2 / 3 ; restoring low-degree lines and the cases E < 4 V yields I ≲ m 2 / 3 n 2 / 3 + m + n .

Bourgain’s real theorem: what uniformization actually preserves

At scale δ , a ( δ , s , C ) set X means | X ∩ B ( x , r ) | δ ≤ C r s | X | δ for all δ ≤ r ≤ 1 . This is an upper bound on local mass. It is not the same as the lower growth condition | X | r ≳ r − s at every scale unless the set is regularized. In a dyadic tree with base Δ and depth m , uniformization selects a subset whose every occupied level- j cube has the same number R j of occupied children. The mass of a descendant subtree is then the fixed product R j R j + 1 ⋯ R m − 1 . That identity converts a global scale lower bound into a local upper bound: for an occupied cube Q of side ρ = Δ j ,

| X ∩ Q | δ = | X | δ / | X | ρ ≤ C ρ s | X | δ .

Conversely, the ( δ , s , C ) upper bound implies the same condition at coarser scales for a uniform set. This is exactly what allows each magnified piece in the iteration to satisfy the same type of hypothesis.

The first expansion lemma alone is not iterative: it can show that a polynomial image Q ( A ) is large at the finest scale, but that mass could be concentrated in a few coarse intervals. Robust expansion fixes this by applying to every dense subset Z ⊂ A k , not only the whole product. To extract a nonconcentrated part of the image, inspect its occupied intervals at scales ρ j from coarse to fine. If a parent interval contains too many descendants relative to its share of the current image, take the preimage tuples mapping into those descendants. If this preimage has at least the density threshold required by the robust lemma, its image must expand by an extra factor, contradicting the assumed concentration. Therefore the bad parents together carry only a small share; retain the good parents and continue. After finitely many scales, the retained image is both large and nonconcentrated. A subadditive fiber weight can then uniformize this image without losing the fiber cardinality needed in the next projection step. Each assertion has a separate role: robust expansion handles arbitrary dense subsets; good-parent pruning handles scale concentration; the fiber weight preserves multiplicity; uniformity makes the next application legal. The full Bourgain theorem’s repeated BSG/direction reductions have more parameter bookkeeping than this conceptual account, so it remains a proof map rather than a complete parameter-level proof.

Additive structure and robust projection growth

Small sumsets indicate additive structure. Ruzsa’s triangle inequality and Plünnecke’s inequality propagate smallness from A + B to iterated sums and differences; Petridis’ minimizing-subset argument provides a short proof. BSG converts many additive relations on a dense subset of A × B into large subsets with a small sumset by cleaning a bipartite graph until every cross-pair has many length-three paths. The proof and variables are made explicit below.

In F p , ratio sets and the lack of proper subfields force sum-product growth. Over R , there are no finite-field escape steps, denominators can be tiny, and arithmetic subgroups abound. Bourgain’s real projection theorem therefore assumes nonconcentration at all scales, regularizes to uniform dyadic trees, and iterates robust expansion. Uniform branching lets one infer local mass from global scale counts; robust polynomial expansion must work for every dense subset so that pruning does not destroy the next step’s hypotheses. The argument is outlined in the source and not a full parameter-level proof in these notes.

Sumsets, energy, and robust structure

A set can resist additive growth because it sits in a low-dimensional arithmetic pattern. An arithmetic progression A = a + { 0 , … , L − 1 } d has | A + A | ≤ 2 | A | . A rank- r generalized arithmetic progression

A = a + { n 1 d 1 + ⋯ + n r d r : 0 ≤ n j < L j }

has | A + A | ≤ 2 r | A | . Freiman–Ruzsa says conversely that bounded doubling | A + A | ≤ K | A | forces containment in a generalized progression whose rank and volume factor depend only on K . This is a structural classification, but the dependence is enormous; the polynomial Freiman–Ruzsa conjecture asks for meaningful control already when K is a small power of | A | .

Two short inequalities let us propagate smallness without invoking that deep classification. For finite subsets of an abelian group,

| A | | B − C | ≤ | A − B | | A − C | .

For each d ∈ B − C , fix b ( d ) − c ( d ) = d ; the map ( a , d ) ↦ ( a − b ( d ) , a − c ( d ) ) is injective, since subtracting its coordinates recovers d , and then one coordinate recovers a . Substituting B = C = − A gives | A − A | ≤ K 2 | A | whenever | A + A | ≤ K | A | . Plünnecke’s inequality says that if | A + B | ≤ K | A | , then for integers m , n ≥ 0 ,

| B ⊕ m − B ⊕ n | ≤ K m + n | A | .

Petridis’ proof picks X ⊂ A minimizing | X + B | / | X | = K ¯ ≤ K . Inductively prove | X + C + B | ≤ K ¯ | X + C | for every finite C : when a new translate c is added, separate the new sums and use the minimizing property on the subset of X whose c + B translate is already covered. Iterating with C = B ⊕ j gives | X + B ⊕ m | ≤ K m | X | ; Ruzsa’s inequality then compares B ⊕ m − B ⊕ n with the two iterated sumsets above. This is why small sumsets yield a whole family of small derived sets.

A prime field has no proper subfield, but a quantitative proof needs to rule out approximate subfields. Define the ratio set ( A − A ) / ( A − A ) using nonzero denominators. If c is outside the ratio set, then a 1 + c a 2 has a unique representation: two representations with unequal second coordinates would solve for c as a difference ratio; equal second coordinates force equal first coordinates. Therefore | A + c A | = | A | 2 . If the ratio set is proper, the prime-field fact that repeated addition of 1 visits every element supplies a b in it with b + 1 outside. Write b as a quotient of differences, insert the representation into A + ( b + 1 ) A , and clear denominators as a literal set map. The resulting bounded-complexity expression in A must have at least | A | 2 values unless the ratio set is already all of F p . This denominator-clearing detail matters: multiplying a set by a denominator does not preserve cardinality if the denominator might vanish, so the rational expression is defined only on nonzero denominators and then expanded algebraically.

The course bootstraps this lemma with Plünnecke and Ruzsa to prove the sum-product theorem. If | A | = p s with 0 < s < 1 , then for some ε ( s ) > 0 ,

max ( | A + A | , | A ⋅ A | ) ≥ p s + ε ( s ) .

An arithmetic progression can have small sumset, and a geometric progression can have small product set; the theorem says a proper prime-field subset cannot keep both operations small. The classroom proof first proves a bounded algebraic expression such as A ⊕ 3 − A ⊕ 3 expands by a power. Under the contrary assumption of small growth, Plünnecke bounds iterated additive combinations, and the multiplicative form of Ruzsa’s inequality transfers those bounds to a quotient of the expression from the approximate-subfield lemma, contradicting its lower bound. The gains and losses depend on s and are small; constants and the explicit epsilon formula are suppressed in the lecture. Repeated application shows that for any s < t < 1 , a bounded-complexity expression Poly K ( A ) can be made to have at least p t elements, where K = K ( s , t ) .

Now let D ⊂ F p be a set of slopes. If every A + t A ( t ∈ D ) were small, contagious structure would force smallness for slopes formed by bounded additions, products, and sign changes of elements of D . Sum-product expansion makes this generated slope set larger than A ; finite-field double counting then says one of its projections must be large, a contradiction. Quantitatively, if | A | = p s A and | D | = p s D with 0 < s A < 1 and s D > 0 , there is ε ( s A , s D ) > 0 such that

max t ∈ D | A + t A | ≥ p s A + ε | A | .

The direct double-counting bound already settles s D ≥ s A ; the sum-product/contagious-structure argument handles the harder s D < s A case. This theorem is exactly the product-set projection case X = A × A .

Why does the product-set case not immediately imply BKT for arbitrary X ⊂ F p 2 ? After normalizing two directions to horizontal and vertical, let A = π 0 ( X ) ∪ π ∞ ( X ) , so X ⊂ A × A and, under a hypothetical near-square-root small-projection bound, X is a large fraction of the product. But a large subset can concentrate on a few unusually heavy fibers while the rest of the product supplies most of its projection values. For example, the diagonal in A × A has a single value under π − 1 ; a grid plus a comparably sized random garbage set shows that the whole product can have a large image even when a large structured portion has small image. The BSG theorem removes this garbage.

In restricted-projection form, if A , B have size at most N , X ⊂ A × B , | X | ≥ K − 1 N 2 , and | π t ( X ) | ≤ K N , then BSG finds A ′ ⊂ A , B ′ ⊂ B such that X ′ = X ∩ ( A ′ × B ′ ) still has size at least K − O ( 1 ) N 2 and | A ′ + t B ′ | ≤ K O ( 1 ) N . The reason is Cauchy–Schwarz: the many pairs in X landing in few projection values create high additive energy; BSG turns that energy into large subsets with small full sumset. Applying Plünnecke–Ruzsa gives small A ′ − A ′ as well.

The remaining symmetry lemma is the bridge from a large subset back to its product. Fix a direction t 1 with A ′ + t 1 B ′ small. For any t , fix one pair ( a 1 , a 2 ) ∈ A ′ × A ′ representing each value c = a 1 − ( t / t 1 ) a 2 in π − t / t 1 ( A ′ × A ′ ) . The map

( c , ( a , b ) ) ↦ ( a 1 − a ,   a 2 + t 1 b ,   a + t b ) , ( a , b ) ∈ X ′ ,

is injective from π − t / t 1 ( A ′ × A ′ ) × X ′ into ( A ′ − A ′ ) × ( A ′ + t 1 B ′ ) × π t ( X ′ ) . Indeed, from outputs ( u , v , w ) recover the chosen projection value c = u − ( t / t 1 ) v + w ; that fixes ( a 1 , a 2 ) , then a = a 1 − u , and b = ( w − a ) / t (handle t = 0 separately by the trivial coordinate projection). | π t ( X ′ ) | ≥ | X ′ | N 2 | π − t / t 1 ( A ′ × A ′ ) | .

Since | X ′ | is a fixed power fraction of N 2 and the transformed slope set still has positive power size, the product-set BKT estimate forces one of these images to grow. where r A , B ( z ) = # { ( a , b ) ∈ A × B : a + b = z } . Since ∑ z r A , B ( z ) = | A | | B | , Cauchy–Schwarz gives

| A | 2 | B | 2 ≤ | A + B | E ( A , B ) .

From many additive coincidences to a genuinely structured rectangle

A large set of graph edges with few sums does not itself force the whole ambient sumset to be small: a small “garbage” portion of the ambient sets may contribute many unrelated sums. The Balog–Szemerédi–Gowers theorem (BSG) is a cleaning statement. In its additive form, if A , B lie in an abelian group, | A | , | B | ≤ N , X ⊂ A × B , | X | ≥ K − 1 N 2 , and the restricted sum image π 1 ( X ) = { a + b : ( a , b ) ∈ X } has size at most K N , then one can find A ′ ⊂ A , B ′ ⊂ B such that X ′ = X ∩ ( A ′ × B ′ ) still has size at least K − O ( 1 ) N 2 while | A ′ + B ′ | ≤ K O ( 1 ) N . “Large” and “small” here mean polynomial losses in K ; the constants hidden in O ( 1 ) are absolute but not optimized. The key point is that the new sumset is the full sumset of the selected subsets, not only the restricted sums of the surviving edges. [P2-13]

View X as a bipartite graph, with left vertices A , right vertices B , and edge ( a , b ) when the pair belongs to X . A path of length three from a to b has form a − b 1 − a 1 − b . The three edge sums z 1 = a + b 1 , z 2 = a 1 + b 1 , z 3 = a 1 + b all belong to π 1 ( X ) , and a + b = z 1 − z 2 + z 3 . Thus each length-three path gives a representation of the endpoint sum using three elements of the restricted sumset. If every pair ( a , b ) ∈ A ′ × B ′ has at least P such paths, count pairs consisting of an endpoint sum and one of its representations. There are at least P | A ′ + B ′ | representations from paths, while there are at most | π 1 ( X ) | 3 triples ( z 1 , z 2 , z 3 ) . Therefore

| A ′ + B ′ | ≤ | π 1 ( X ) | 3 P .

This converts a graph-connectivity property into small additive structure. The hard part is to produce large vertex subsets on which every cross-pair has many paths.

For a vertex b ∈ B , write N ( b ) = { a : ( a , b ) ∈ X } . The number P 2 ( a 1 , a 2 ) of length-two paths between left vertices is exactly the number of common neighbors of a 1 and a 2 . If the edge density is at least K − 1 , then Cauchy–Schwarz gives

∑ a 1 , a 2 ∈ A P 2 ( a 1 , a 2 ) = ∑ b ∈ B | N ( b ) | 2 ≥ | X | 2 | B | ≥ K − 2 | A | 2 | B | .

This is only an average; some vertices could be isolated or some pairs could be bad. Fix a tolerance ε > 0 , and call ( a 1 , a 2 ) bad when P 2 ( a 1 , a 2 ) < ε K − 2 | B | . Let B P ε ( b ) count bad ordered pairs in N ( b ) 2 . Double-count triples ( a 1 , a 2 , b ) with both edges present and bad endpoints. For each bad pair, its common-neighbor count is less than ε K − 2 | B | , so averaging over b yields E b B P ε ( b ) ≤ ε K − 2 | A | 2 . Combining this with E b | N ( b ) | 2 ≥ K − 2 | A | 2 , choose b with a positive objective | N ( b ) | 2 − ( 2 ε ) − 1 B P ε ( b ) . Its neighborhood A 0 = N ( b ) has size at least a constant multiple of K − 1 | A | , and at most a 2 ε fraction of ordered pairs in A 0 2 are bad. Delete vertices of A 0 that have too many bad partners. The survivors A 2 remain a constant-power fraction of A , and for every a ∈ A 2 , all but at most 10 ε | A 2 | of the a 2 ∈ A 2 satisfy P 2 ( a , a 2 ) ≥ ε K − 2 | B | .

To obtain length-three paths, first prune A to A 1 = { a : | N ( a ) | ≥ ( 10 K ) − 1 | B | } ; this removes only a bounded fraction of the edges, since the total number of edges is at least K − 1 | A | | B | . Apply the length-two cleaning lemma to this graph to get A ′ = A 2 ⊂ A 1 . For each a ∈ A ′ , the set G ( a ) of its good partners in A ′ misses at most 10 ε | A ′ | . Now define B ′ as vertices with more than 20 ε | A ′ | neighbors in A ′ . For b ∈ B ′ , at least 10 ε | A ′ | of those neighbors lie in G ( a ) for each chosen a ∈ A ′ . Each such intermediate vertex contributes at least ε K − 2 | B | length-two paths from a ; adjoining its final edge to b gives

P 3 ( a , b ) ≳ ε 2 K − 3 | A | | B | .

The pruning retained each a ∈ A ′ with degree at least a constant times K − 1 | B | , so X ( A ′ , B ) has at least a constant times K − 2 | A | | B | edges. Vertices outside B ′ have at most 20 ε | A ′ | such edges, hence X ( A ′ , B ∖ B ′ ) ≤ 20 ε | A ′ | | B | . Choose ε as a sufficiently small negative power of K ; the discarded edges are then a small fraction of X ( A ′ , B ) , leaving | X ′ | ≥ K − O ( 1 ) | A | | B | . Every surviving cross-pair has the stated many-path lower bound, so the path-count inequality proves BSG. The proof is a sequence of explicit repairs to average information: discard low-degree vertices, select a neighborhood where most pairs share many neighbors, remove vertices with too many bad partners, and finally retain right vertices with enough links to the remaining good partners. Why the Euclidean projection theorem needs scale regularity

The finite-field Bourgain–Katz–Tao theorem says that if X ⊂ F p 2 has p t points and the direction set D ⊂ F p has p s slopes, then some projection π θ ( x 1 , x 2 ) = x 1 + θ x 2 has at least p t / 2 + ε values; a robust version says the same direction expands every sufficiently dense subset of X . The exponent t / 2 is the elementary baseline: two distinct slopes determine a point by an invertible 2 × 2 linear system, so the map x ↦ ( π θ 1 x , π θ 2 x ) is injective. Thus | X | ≤ | π θ 1 X | | π θ 2 X | , forcing one image to have size at least | X | 1 / 2 . [P2-14]

The analogous real theorem cannot hold for arbitrary unions of unit balls inside a large ball. A thin 1 × R rectangle projected near its short direction has image length only about R s if the direction set is concentrated in an interval of width R s ; when s < t / 2 , this can be below the square-root scale R t / 2 . Even a well-spread set of directions cannot fix a clustered point set: a ball of radius R 1 / 2 has area about R and every projection has length about R 1 / 2 . These show two distinct failures: the directions can cluster in slope, or the points can cluster spatially. Therefore Bourgain’s real result assumes power-law nonconcentration of both.

After rescaling to the unit ball and resolution δ = 1 / R , measure sets by the δ -covering number | X | δ , the smallest number of radius- δ balls that cover X . For a 2 δ -separated finite set this is its cardinality; for a union of bounded-overlap δ -balls in R d it is comparable, with constants depending only on d , to δ − d times Lebesgue measure. It is also comparable to the number of mesh cubes of side δ that meet the set. Define a ( δ , s , C ) d set by

| X ∩ B ( x , r ) | δ ≤ C r s | X | δ ( δ ≤ r ≤ 1 ) .

This says no ball at an intermediate scale captures too much of the set; s is a dimension-like nonconcentration exponent and C is a tolerance constant. In the projection theorem C = δ − η for a small η > 0 . If X has global size δ − t and D ⊂ [ 0 , 1 ] has size δ − s , and both obey their corresponding nonconcentration conditions, then some direction projects every subset Y ⊂ X with | Y | δ ≥ δ η | X | δ to size at least δ − t / 2 − ε . The same parameter θ works for all such Y . This robust quantifier matters because later steps repeatedly pass to large subsets.

The cover-number language lets familiar discrete tools survive in Euclidean space. Snap points to a mesh at scale δ ; bounded-scale sums and differences can move a snapped point only a bounded number of mesh cells, so Ruzsa triangle, Plünnecke, and BSG inequalities transfer with dimension-dependent multiplicative losses. For example, | B | δ | A − C | δ ≲ d | A − B | δ | B − C | δ . The “almost commutes” qualification is important: snapping a difference is not exactly the difference of snapped representatives, but only a bounded number of neighboring mesh cells are involved.

In the prime-field proof, one studies the ratio set ( A − A ) / ( A − A ) . If it is proper, the fact that repeated addition of 1 traverses the whole prime field lets us choose an element b inside it but b + 1 outside; this forces polynomial growth. Over R , a direct copy fails: a small interval has little additive or multiplicative growth; ratios may be unbounded from tiny denominators; “add one” can leave the reference interval; and R has many additive subgroups. The real proof therefore first cuts off denominators smaller than δ γ and intersects the resulting ratio-like set with [ 0 , 1 ] . It then uses order and gaps rather than field simplicity.

Specifically, for a closed B ⊂ [ 0 , 1 ] containing 0 , 1 , let ρ be the supremum length of complementary intervals. Form B ′ = B / 2 ∪ ( B + 1 ) / 2 . Since 1 / 2 ∈ B ′ , a gap in B ′ cannot cross the midpoint; each half is a scaled copy of B , so every gap has length at most ρ / 2 . Choose an almost-largest gap of B with length ρ − o ( ρ ) and take a centered subinterval of length about ρ / 2 . This subinterval contains a point of B ′ (otherwise it would create a larger gap in B ′ ), and that point is at distance at least a fixed fraction, say ρ / 5 , from B . Since the point is either b / 2 or ( b + 1 ) / 2 for some b ∈ B , one of these affine transforms escapes B by a definite gap. Thus either B is ρ -dense or there is a controlled escaping value, playing the role of the finite-field b + 1 ∉ B . The precise constants are inessential; the order structure on the real line is essential. This yields a polynomial-expansion lemma under nonconcentration hypotheses, but only at the chosen resolution at first. Iterating it requires a further mechanism to preserve those hypotheses. Uniform trees make multiscale size usable

A set can be large at the finest scale and still fail to have enough points at coarser scales. Uniform sets repair this mismatch. Choose a dyadic base Δ ∈ ( 0 , 1 ) and a depth m , with bottom scale δ = Δ m . Tile [ 0 , 1 ] d by nested half-open cubes of side Δ j . For each level- j cube Q that meets X , count the level- ( j + 1 ) children that meet X . The set is ( Δ , m ) -uniform if this number is the same, R j , for every occupied parent at level j . The branching factor may vary with level but not from parent to parent. Equivalently, the occupied cubes form a rooted tree with a level-dependent regular branching number. Uniformity makes the number of descendants below any occupied cube a product of the same R i ’s, independent of which branch was chosen.

Two consequences explain the value of this bookkeeping. First, for a uniform set, if at every dyadic scale ρ ∈ { 1 , Δ , … , Δ m } its covering number is at least C − 1 ρ − s , then it is a ( δ , s , O Δ ( C ) ) set. To see it, take an occupied level- j cube Q . It contains one occupied level- j cube, and its number of bottom descendants is R j ⋯ R m − 1 . The whole set has R 0 ⋯ R m − 1 bottom descendants and R 0 ⋯ R j − 1 level- j cubes. Their ratio gives

| X ∩ Q | δ = | X | δ | X | Δ j .

The assumed lower bound | X | Δ j ≥ C − 1 ( Δ j ) − s rearranges to | X ∩ Q | δ ≤ C ( Δ j ) s | X | δ . A ball meets only boundedly many cubes of its comparable scale. Between adjacent powers of Δ , sandwich the radius and lose only a constant depending on Δ , d . Thus scale-by-scale lower bounds imply local nonconcentration. Second, if X is already ( δ , s , C ) and uniform, the same descendant ratio plus the lower bound | X | ρ ≥ C − 1 ρ − s shows that the set is ( ρ , s , O Δ ( C ) ) at every coarser resolution ρ ≥ δ . This addresses the failure that a fine-scale nonconcentration condition alone says nothing about a much coarser covering scale. [P2-15]

Any set contains a large uniform subset, by a bottom-up pruning argument. Let μ be any subadditive set function ( μ ( E ∪ F ) ≤ μ ( E ) + μ ( F ) ); the δ -covering number is an important example. Begin at the finest level. For each parent cube, its branching number is between 1 and at most Δ − d . Group parents by dyadic ranges [ 2 ℓ , 2 ℓ + 1 ) . There are at most O ( d log ⁡ ( 1 / Δ ) ) groups. Subadditivity says the total μ -mass is at most the sum of group masses, so one group retains at least a reciprocal-logarithmic fraction. Within that group, trim every parent down to exactly 2 ℓ occupied children; because each had fewer than 2 ℓ + 1 , this costs at most another factor of two. Now all surviving parents have the same branching factor. Repeat at the next coarser level. Working from leaves upward preserves uniformity already established at finer levels: removing a parent branch does not alter the descendant count inside branches that remain. After m levels we have a uniform Y ⊂ X with

μ ( Y ) ≥ [ 2 d log ⁡ ( 1 / Δ ) ] − m μ ( X ) = δ − σ μ ( X ) , σ = log ⁡ ( 2 d log ⁡ ( 1 / Δ ) ) log ⁡ ( 1 / Δ ) .

The loss is a small power of δ when Δ is chosen sufficiently small, since σ → 0 as Δ → 0 . This pruning is not ordinary measure-theoretic density; only subadditivity is needed, so it works for covering number and for specialized set functions used to measure fibers.

Robust expansion is what makes the real argument iterate

For a nonconcentrated one-dimensional set A , the first real expansion lemma gives a fixed polynomial Q for which | Q ( A ) | δ ≥ δ − s − ε when | A | δ = δ − s . This alone does not permit iteration: Q ( A ) might be concentrated at intermediate scales. The stronger robust statement says, for some fixed polynomial Q : R k → R , if A is a ( δ , s , C ) set and Z ⊂ A k occupies a fixed power fraction of A k , then | Q ( Z ) | δ ≳ δ − s − ε . The notes use the concrete k = 3 map Q ( a 1 , a 2 , a 3 ) = a 1 + a 2 a 3 . This handles arbitrary dense subsets of the product, rather than only the entire product, and is the new input needed to recover a well-distributed subset of the expanded image. [P2-16]

Here is how robustness feeds iteration. First uniformize A . Uniformity and the scale-wise expansion argument imply Q ( A ) has large covering number at every coarser scale. But that is not enough: much of the coarse-scale image could come from a tiny part of the domain while the fine-scale covering number is contributed by another part. To prevent this split, examine the image in intervals at a sequence of nearby scales 1 ≥ ρ 1 > ρ 2 > ⋯ > ρ N = δ . At the first scale retain all image intervals; at each next scale call a parent interval bad if it captures more than ρ j s + ε − η | Q ( Z ) | ρ j + 1 of the next-scale image. Pull the bad intervals back to the parameter tuples in A k . If they occupied a substantial fraction of A k , the robust expansion lemma applied to that bad preimage would force their image to be large, contradicting the bound defining badness. Thus the bad preimage is small and can be removed while leaving enough parameter tuples for the robust estimate to remain applicable. Iterating the removal across the finite scale chain constructs a subset whose image obeys the nonconcentration inequality at each adjacent pair of scales; multiplying adjacent scale ratios gives the bound for separated scales, and choosing a sufficiently fine scale mesh controls intermediate radii. The resulting image contains a ( δ , s + ε / 2 , C ′ ) set, with tolerances reduced to absorb the accumulated losses. This is the detailed logic behind the official proof sketch; the transcript emphasizes that robustness, rather than a generic appeal to uniformity, is what eliminates the “large coarse part / different large fine part” enemy.

Why is the robust lemma true? Its proof reuses BSG rather than relying on a minor tweak of the earlier expansion argument. The first step gives some a ∈ A with | A + a A | δ ≥ δ − s − ε . A contradiction/exceptional-set argument upgrades this so almost every a has the property that every dense X ⊂ A × A still has | π a ( X ) | δ ≳ δ − s − ε . If not, a large set of bad a ’s would itself be a nonconcentrated subset to which the initial expansion applies. To prove the dense-subset claim, a restricted small projection creates high additive energy; Euclidean BSG at covering scale finds dense subsets with controlled full sumset, and the same symmetry injection used in the finite-field proof transfers expansion back to the chosen projection. Once this holds for most coefficients, apply it to a dense subset of A 3 : view Q ( a 1 , a 2 , a 3 ) = a 1 + a 2 a 3 as the projection ( x , y ) ↦ x + a y of the product pair ( a 1 , a 2 a 3 ) , use the robust two-coordinate estimate after a product/fiber decomposition, and absorb the constant-power losses in the small exponent ε . It would be inaccurate to report the complete technical proof as shown in these sources.

Once one expansion step returns a larger nonconcentrated subset inside Q ( A ) , iterate: the exponent s increases by a positive amount depending continuously on s , so for any target 1 − τ < 1 only finitely many steps are needed. Finite groups: when a walk is stuck, look for an approximate subgroup

For a finite group G , a probability measure m u describes one random step. Its convolution is

( f ∗ g ) ( x ) = ∑ a b = x f ( a ) g ( b ) , ( μ ∗ ν ) ( x ) = ∑ a b = x μ ( a ) ν ( b ) .

If the walk multiplies on the right, its distribution after k independent steps, started at the identity, is μ ∗ k . The operator T μ f = f ∗ μ is a weighted average of right translations. Each translation preserves counting-measure ℓ 2 ( G ) , so the triangle inequality gives ‖ T μ f ‖ 2 ≤ ‖ f ‖ 2 . Constants are fixed and mean-zero functions stay mean-zero. Let σ 1 ( T μ ) be the largest singular value on that mean-zero subspace. Starting at g 0 , write δ g 0 = | G | − 1 1 + f 0 ; then ‖ f 0 ‖ 2 ≤ 1 , so

‖ T μ k δ g 0 − 1 | G | 1 ‖ 2 ≤ σ 1 ( T μ ) k .

Thus a fixed spectral gap 1 − σ 1 > 0 gives exponential ℓ 2 mixing, and since counting-measure ‖ f ‖ ∞ ≤ ‖ f ‖ 2 , also a pointwise error bound. Symmetry μ ( g ) = μ ( g − 1 ) makes T μ self-adjoint, which lets powers of the walk be analyzed through the same singular values.

The first obstacle is algebraic trapping. If a step set is contained in a proper subgroup, the walk never leaves that subgroup; on the full group there is an invariant nonconstant function and σ 1 = 1 . But failure to mix need not mean literal containment. The Bourgain–Gamburd proof begins with an inverse principle: if a symmetric walk on SL 2 ( F p ) has no spectral gap, repeated convolution must concentrate substantial mass on a set that behaves approximately like a subgroup. The lecture formulates this with a set H capturing a large portion of some bounded-length walk distribution, whose fixed product H 5 is at most p O ( δ ) | H | and whose size lies below the scale p 2.5 . This is a schematic lecture statement: the small exponents and mass constants depend on the parameters, and should not be silently replaced by a sharp classification theorem.

Here is why an approximate subgroup emerges from a stalled walk. Begin with uniform measure on a set A , so ‖ μ A ‖ 2 2 = 1 / | A | . Square the measure repeatedly, μ j + 1 = μ j ∗ μ j . A progress step decreases ‖ μ j ‖ 2 2 by a factor p − δ ; after boundedly many such steps the ℓ 2 norm is small enough to imply a spectral gap. The implication comes from the representation-dimension estimate established in the preceding lecture:

σ 1 ( T ν ) 2 ≤ C p 2 ‖ ν ‖ 2 2 .

For symmetric μ , T μ is self-adjoint, so applying this to a convolution power gives σ 1 ( T μ ) 2 k ≤ C p 2 ‖ μ ∗ k ‖ 2 2 . Therefore, unless the walk already mixes, some step must stall: its next squared ℓ 2 norm remains a large fraction of the previous one. Decompose the group into dyadic level sets of the point masses of μ j . There are only logarithmically many levels, so one level set H captures a substantial share of the probability and μ j is roughly uniform there. The stalled convolution inequality then forces many product collisions in H .

For finite subsets A , B ⊂ G , define the representation count r A , B ( g ) = # { ( a , b ) ∈ A × B : a b = g } and multiplicative energy

E ( A , B ) = ∑ g ∈ G r A , B ( g ) 2 = # { a 1 b 1 = a 2 b 2 : a i ∈ A , b i ∈ B } .

It counts pairs of factorizations of the same group element. For A = B , the diagonal choices alone give | A | 2 collisions; choosing three factors determines the fourth, so | A | 2 ≤ E ( A , A ) ≤ | A | 3 . Energy close to the upper scale means products have many representations, a sign of additive or multiplicative structure. In a noncommutative group the order of the factors matters: E ( A , B ) does not in general equal E ( B , A ) .

The stalled ℓ 2 inequality is exactly an energy lower bound after replacing the distribution by its heavy level set. Balog–Szemerédi–Gowers converts this average abundance of collisions into an actual structured subset: if E ( H , H ) ≥ K − 1 | H | 3 , then some H ′ ⊂ H has | H ′ | ≥ K − O ( 1 ) | H | and small difference-like product | H ′ H ′ − 1 | ≤ K O ( 1 ) | H ′ | . The graph proof is useful to remember. Draw a bipartite graph with left and right copies of H , joining ( a , b ) when a b is a popular product. High energy means many edges. A graph-cleaning lemma finds a large subset in which each pair of left vertices has many common neighbors. A length-four path between two vertices then writes their quotient in many ways as products of popular elements and inverses. Counting all possible popular factors and dividing by the multiplicity of these representations bounds | H ′ H ′ − 1 | . The inverse is natural here: unlike in an abelian sumset, a small H ′ H need not control later products. This is the noncommutative BSG mechanism behind “stuck implies structured.”

The second half identifies which approximate subgroups can occur in SL 2 ( F p ) . Actual proper subgroups are, up to small exceptional groups and conjugacy, largely contained in triangular subgroups. For approximate subgroups, one needs a robust analogue rather than a classification based on exact group order. The lecture’s theorem says, at schematic level, that a moderately large set H with slowly growing bounded products and | H | ≤ p 2.5 must have a positive fraction inside a coset of a Borel subgroup. A Borel here is a conjugate of the upper triangular subgroup. The prime field matters: in F p m , a proper subfield can support a large structured subgroup and becomes an additional obstruction.

The proof strategy analyzes how the set intersects simpler algebraic subgroups after moving to the algebraic closure, where matrices can be diagonalized. The diagonal torus and the unipotent subgroup expose scalar and additive coordinates. For example,

u ( t ) = ( 1 t 0 1 ) , b ( a , t ) = ( a t 0 a − 1 ) , b ( a , t ) b ( a ′ , t ′ ) = b ( a a ′ , a t ′ + t a ′ − 1 ) .

A set of many unipotents whose product set grows little yields a set of parameters with small additive growth. A large diagonal part with small product growth yields parameters with small multiplicative growth. The upper triangular multiplication law couples these two sets. Once the sets are large enough and not nearly all of F p , this would create an approximate subfield. But the prime field has no proper subfields, and the sum–product theorem rules out a substantial set that is simultaneously additively and multiplicatively structured. Therefore a non-Borel approximate subgroup cannot persist.

An arbitrarily small positive sum–product gain is enough because it rules out exact approximate subfields at every iteration. Homogeneous dynamics: shear, diagonal renormalization, and projection geometry

Let G be a Lie group and Γ a discrete subgroup of finite covolume. The quotient X = G / Γ is a homogeneous space: G acts transitively, while a subgroup H can have periodic, dense, or more complicated orbits. For G = SL 2 ( R ) and Γ = SL 2 ( Z ) , the space parametrizes covolume-one lattices: g Γ corresponds to g Z 2 , and right multiplication by an integer determinant-one matrix changes the basis without changing the lattice. This quotient is not compact. The family ⟨ ( ϵ , 0 ) , ( 0 , ϵ − 1 ) ⟩ keeps area one while its shortest vector tends to zero and its other vector escapes. Mahler’s compactness criterion says precisely that the lattices whose shortest nonzero vector has length at least ϵ form a compact part of the space; the cusp records increasingly skinny lattices.

Two one-parameter subgroups control the picture:

u t = ( 1 t 0 1 ) , a r = ( e r 0 0 e − r ) .

The first shears a lattice horizontally by an amount proportional to height. Hedlund’s theorem says each unipotent orbit { u t x : t ∈ R } in SL 2 ( R ) / SL 2 ( Z ) is either periodic or dense. The geometric periodicity criterion is concrete: for a lattice Λ , a nonzero u T fixes it exactly when Λ contains a nonzero horizontal vector. Indeed, if ( x , 0 ) ∈ Λ , take any independent vector ( y , z ) ∈ Λ ; choosing T = x / z adds ( x , 0 ) to that vector and preserves the lattice. Conversely, if u T Λ = Λ for T ≠ 0 , then for any ( y , z ) ∈ Λ , the difference u T ( y , z ) − ( y , z ) = ( T z , 0 ) is a horizontal lattice vector (some z ≠ 0 ). Most lattices have no horizontal vector, so their unipotent orbit is not periodic; Hedlund supplies the nontrivial alternative, density. Diagonal orbits behave differently: they can be neither periodic nor dense, with closures of intermediate dimension.

To see why a projection theorem enters, compare how the two subgroups interact. Direct matrix multiplication gives

a r u t a r − 1 = u e 2 r t .

Thus a long segment 0 ≤ t ≤ T can be represented as a diagonal rescaling of a unit segment, with e 2 r = T . The dynamical question becomes: what does the diagonal action do to a short family of nearby unipotent orbits?

Put a right-invariant Riemannian metric on G by choosing an inner product at the identity and transporting it using right translations. This descends to the quotient because changing a lift of a point means right multiplication by Γ , an isometry. At the identity the tangent space is sl 2 ( R ) , the trace-zero matrices. An orthonormal basis can be chosen as U = ( 0 1 0 0 ) , U ~ = ( 0 0 1 0 ) , and D = 1 2 ( 1 0 0 − 1 ) . The right action is isometric, but the left action is not. To measure its derivative at the identity, follow it by the inverse right translation, which is an isometry; the resulting differential is conjugation, M ↦ a r M a r − 1 . It sends U to e 2 r U , U ~ to e − 2 r U ~ , and D to D . Consequently the singular values of the left action (under the lecture’s inverse action convention, L a r − 1 ) are e 2 r , 1 , e − 2 r , along expanding, neutral, and compressing directions. Their product is one, so the action distorts lengths but preserves volume. The orbit tangent U is exactly the expanding direction.

The key geometric subtlety is that the compressing direction is not fixed relative to a tube of unipotent orbits. A long stretched orbit is cut into unit-length pieces when it wraps through the quotient’s fundamental domain. Nearby orbit pieces might be packed close together after compression, so length alone does not imply distribution. But the direction of compression twists as one moves along a unit orbit. At any one height, some transverse pairs can collapse; across the full height interval, the collapsing direction sweeps through many slopes. Projection theory says a set of directions that is sufficiently spread out cannot collapse a substantial set of points at every slope: most slices retain large projected covering number. Applying this across the height parameter prevents too many orbit segments from being glued together. The result is a geometric “either spread or exceptional” principle: away from bad concentration directions, the long unipotent segment spreads through the quotient.

The simple picture is closest to a proof when the quotient is compact, where every unit tube has uniformly controlled geometry. For the modular surface the cusp cannot be ignored. A point a − r x may lie very deep in the cusp, corresponding to a lattice with an extremely short vector; then the compact-tube estimates do not apply. The correct conclusion is therefore conditional: either the orbit distributes, or the diagonal renormalization reaches the cusp, which means the original lattice was close to one with a horizontal vector and hence close to a periodic unipotent orbit. This explains why the naive “stretch plus many directions” argument would falsely predict every orbit dense if the cusp were omitted.

There is a useful bridge to number theory. For an indefinite quadratic form Q in at least three variables with coefficients not all proportional to integers, Oppenheim predicts and Margulis proved that Q ( Z n ) is dense in R . After a linear change of variables, the form becomes a standard one while the integer lattice becomes another covolume-one lattice Λ . The symmetry group SO ( Q ) preserves the form, so Q ( Λ ) = Q ( g Λ ) along its orbit in the space of lattices. Understanding whether this orbit is dense therefore controls the set of values of Q ; exceptional nondense orbits correspond to arithmetic structure in the form. The elementary SL 2 shear picture is a visual precursor to the higher-dimensional homogeneous orbit-closure theorems of Dani, Margulis, and Ratner, whose proofs require substantially more machinery.

Comparing term exponents shows A is the minimum when s ≥ t , C when s + t ≥ 2 , and B when s < t < 2 − s . This precisely recovers which classical tool applies: double counting in A, Fourier in C, while B is the difficult grid-like interval.

The continuum Beck theorem is a robust way to get out of a one-scale trap. Suppose E has size about δ − u and satisfies a rectangle nonconcentration condition: for every rectangle of dimensions ρ × 1 , its intersection with E has at most a C ρ η fraction of the total δ -covering number. Then some point x ∈ E sees many directions to the rest of E :

| L x , E | δ ≳ ϵ , η min { δ − u , δ − 1 } .

This resembles the finite-point Beck theorem: either there are many distinct joining lines, or a large fraction of points lie on one line. The nonconcentration condition forbids the second alternative. It is important that the statement is real-geometric; the analogous assertion over C fails because a complex line has real dimension two, so a planar set can lie in one complex line without being concentrated in a real thin rectangle.

Here is the bootstrap mechanism behind the continuum form. For each point x , let L x , E be the direction set to points of E and use pigeonholing to retain a large subset of base points where the direction-set size is nearly uniform. Each L x , E inherits a nonconcentration estimate from the rectangle hypothesis: if many points viewed from x fall into a narrow angular interval, then those points lie in the associated narrow rectangle, contradicting the assumed bound. Counting point–line incidences in two ways makes a typical line rich in points and gives the elementary lower bound on the family of lines. The Orponen–Shmerkin epsilon-improvement theorem then upgrades a direction set of dimension s to size at least δ − s − ϵ in the difficult 0 < s < min ( u , 1 ) range. The same estimate applies after rescaling to subrectangles because the uniform direction sets have nonconcentration at coarser scales. Iterating the improvement increases the exponent by a fixed positive amount each time; after finitely many steps it reaches min ( u , 1 ) . This is why uniformization is not cosmetic: a fine-scale count alone would not imply that the rescaled subsets retain the same hypotheses. AD regularity turns the rich-tube count into a submultiplicative quantity

A set is AD regular at exponent t when every ball of radius ρ centered on the set contains about the fraction ρ t of the total mass, uniformly at every intermediate scale. In a discrete δ -model, a uniform set with branching factors B j is AD regular when the product of the first J branchings is comparable to δ − J t for every J . This is stronger than merely having | E | δ ∼ δ − t : it says the same dimension is visible inside every occupied ball and at every scale.

Let R A D ( δ ) be the largest typical number of δ -balls of an AD-regular set that can lie in one δ -tube, under the direction-set hypotheses of the Furstenberg problem. The crucial submultiplicative estimate is

R A D ( δ 1 δ 2 ) ≲ R A D ( δ 1 ) R A D ( δ 2 ) .

To see the counting behind it, thicken each fine ball and tube to scale δ 1 . A fine tube meets at most R A D ( δ 1 ) coarse balls. Inside each such ball, rescale by δ 1 − 1 ; it becomes a unit ball containing a δ 2 -configuration, and a short fine tube segment becomes a δ 2 -tube. AD regularity guarantees the rescaled set still has the required mass distribution, regardless of which coarse ball was selected. Thus at most R A D ( δ 2 ) fine balls occur in each coarse ball along the tube. Multiplying the two counts proves the estimate. For a merely ( δ , t ) set, a selected coarse ball may contain an atypically dense portion, so this rescaling step is not valid with uniform constants.

The projective variant assumes every base point uses the same tube directions. In the submultiplicative decomposition at δ 1 = δ 2 = δ , directions differing by less than δ cannot be distinguished after thickening, so the local problem inside a coarse ball is projective. Consequently a sharp estimate for projective AD-regular configurations propagates to general AD-regular ones. If the submultiplicative inequality is nearly an equality at every step, then typical coarse balls and typical tubes must also be nearly saturated. In a projective tube, choose coordinates with the coarse tube horizontal. The fine set is contained in a product A × B of transverse positions and longitudinal positions. Near-saturation means a positive fraction of the product rectangles are occupied at the expected density. Projecting at small slope c sends the product to a discretized sum A + c B . If all such projections remain small, an asymmetric Balog–Szemerédi–Gowers reduction extracts a genuine product-like subset; Plünnecke–Ruzsa then propagates small growth to sums with several slopes. The ABC sum-product theorem says that for nonconcentrated real sets of dimensions a , b , c , if every c ∈ C keeps A + c B no larger than A , then a ≥ b + c . The near-saturated geometry would force the opposite dimension inequality in the hard regime, contradiction. This is the source of the epsilon improvement: either the configuration already has more projected points than the extremal estimate permits, or submultiplicativity is strictly improved. The lecture and course notes outline this rigidity argument but explicitly omit the asymmetric BSG and spacing-case details. [P2-23]

The last scale-combination argument

The well-spaced theorem is a continuous analogue of Szemerédi–Trotter. Let E be N radius- δ balls in the unit disk, with at most a bounded number in any ball of radius N − 1 / 2 . This is the maximally spread regime: a tube can meet at most about N 1 / 2 points, which explains why the elementary N / R term in the point-line theorem is unnecessary. A random δ -tube meets about δ N balls on average, so the richness threshold must exceed this baseline by a small power. For R > δ − ϵ δ N , the theorem gives

| T R ( E ) | ≲ ϵ δ − ϵ N 2 R 3 .

The Fourier method alone proves the desired scale when R is near its minimum allowed value: it gives | T R ( E ) | ≲ δ − 1 N R − 2 , and substituting R ∼ δ N makes this N 2 R − 3 up to the small loss. If R is larger, set a thicker scale ρ by ρ N ∼ R . Well-spacing ensures | E ρ | ρ = N (up to constants): thickening each point to radius ρ does not merge distinct points, since the spacing scale N − 1 / 2 exceeds ρ when R ≤ N 1 / 2 . The Fourier estimate for ρ -tubes gives a bound for the number of rich fat tubes. But one fat tube may contain many rich thin tubes.

To count the thin tubes inside one fat tube, first impose a two-ends condition: each rich thin tube has a substantial portion of its incident points near each of its two ends. If the points were all concentrated in a much shorter sub-tube, an induction on scale handles that subproblem; otherwise the two-ends condition holds after decomposition. If a fat tube contains R ~ points, count triples ( T , x 1 , x 2 ) where T is a rich thin tube inside it and x 1 , x 2 are incident points near opposite ends. Each thin tube contributes on the order of R 2 ordered pairs. Conversely there are at most R ~ 2 choices of the pair, and two points separated along the tube determine at most one essentially distinct joining tube. Hence there are at most O ( R ~ 2 / R 2 ) rich thin tubes in that fat tube. The Fourier bound for fat tubes at richness R ~ is O ( N 2 / ( R R ~ 2 ) ) because ρ − 1 = N / R . Multiplication cancels R ~ 2 and yields O ( N 2 / R 3 ) ; dyadically summing over the logarithmically many values of R ~ is absorbed by the δ − ϵ loss. The well-spacing condition is used to preserve N after thickening; the lower richness threshold is needed to suppress the low-frequency Fourier contribution.

Finally, define the branching function of a uniform set E by

f ( x ) = log 1 / δ ⁡ | E δ x | δ x , 0 ≤ x ≤ 1.

Here x = 0 means unit scale and x = 1 means finest scale δ ; thus f ( 0 ) = 0 , f ( 1 ) = t when | E | δ = δ − t . The ( δ , t ) nonconcentration condition gives f ( x ) ≥ t x . Since a radius- ρ disk can be covered by O ( ( ρ / ρ ′ ) 2 ) disks of radius ρ ′ , one has f ( x + h ) ≤ f ( x ) + 2 h . The function is increasing and 2-Lipschitz. AD-regularity corresponds to a straight line of slope t . Well-spaced geometry has an initial slope close to 2 followed by a flat part. Ren–Wang’s semi-well-spaced condition relaxes that broken line: for 0 < s < 1 , the graph lies above the broken profile of slopes 2 − s and s . Fourier analysis controls this whole semi-well-spaced class.

Multiscale decomposition cuts the branching graph at a scale ρ . The coarse set E ρ has the left segment of the graph; inside a typical ρ -ball, magnification gives the right segment as the branching function of the local fine set. Richness factors accordingly: number of coarse balls hit by a fat tube times number of fine balls hit in each such ball. If both segments have slopes in the hard interval s < t I < 2 − s , both subproblems use the grid-regime bound and their product has the correct exponent. A steep first piece and shallow second piece instead require the Fourier and elementary bounds, whose product is too weak; merely splitting arbitrarily is therefore not enough.

One then repeatedly applies the coarse/fine factorization, controls each piece with its appropriate theorem, and multiplies the bounds. From many additive coincidences to a genuinely structured rectangle

A large set of graph edges with few sums does not itself force the whole ambient sumset to be small: a small “garbage” portion of the ambient sets may contribute many unrelated sums. The Balog–Szemerédi–Gowers theorem (BSG) is a cleaning statement. In its additive form, if A , B lie in an abelian group, | A | , | B | ≤ N , X ⊂ A × B , | X | ≥ K − 1 N 2 , and the restricted sum image π 1 ( X ) = { a + b : ( a , b ) ∈ X } has size at most K N , then one can find A ′ ⊂ A , B ′ ⊂ B such that X ′ = X ∩ ( A ′ × B ′ ) still has size at least K − O ( 1 ) N 2 while | A ′ + B ′ | ≤ K O ( 1 ) N . “Large” and “small” here mean polynomial losses in K ; the constants hidden in O ( 1 ) are absolute but not optimized. The key point is that the new sumset is the full sumset of the selected subsets, not only the restricted sums of the surviving edges. [P2-13]

View X as a bipartite graph, with left vertices A , right vertices B , and edge ( a , b ) when the pair belongs to X . A path of length three from a to b has form a − b 1 − a 1 − b . The three edge sums z 1 = a + b 1 , z 2 = a 1 + b 1 , z 3 = a 1 + b all belong to π 1 ( X ) , and a + b = z 1 − z 2 + z 3 . Thus each length-three path gives a representation of the endpoint sum using three elements of the restricted sumset. If every pair ( a , b ) ∈ A ′ × B ′ has at least P such paths, count pairs consisting of an endpoint sum and one of its representations. There are at least P | A ′ + B ′ | representations from paths, while there are at most | π 1 ( X ) | 3 triples ( z 1 , z 2 , z 3 ) . Therefore

| A ′ + B ′ | ≤ | π 1 ( X ) | 3 P .

This converts a graph-connectivity property into small additive structure. The hard part is to produce large vertex subsets on which every cross-pair has many paths.

For a vertex b ∈ B , write N ( b ) = { a : ( a , b ) ∈ X } . The number P 2 ( a 1 , a 2 ) of length-two paths between left vertices is exactly the number of common neighbors of a 1 and a 2 . If the edge density is at least K − 1 , then Cauchy–Schwarz gives

∑ a 1 , a 2 ∈ A P 2 ( a 1 , a 2 ) = ∑ b ∈ B | N ( b ) | 2 ≥ | X | 2 | B | ≥ K − 2 | A | 2 | B | .

This is only an average; some vertices could be isolated or some pairs could be bad. Fix a tolerance ε > 0 , and call ( a 1 , a 2 ) bad when P 2 ( a 1 , a 2 ) < ε K − 2 | B | . Let B P ε ( b ) count bad ordered pairs in N ( b ) 2 . Double-count triples ( a 1 , a 2 , b ) with both edges present and bad endpoints. For each bad pair, its common-neighbor count is less than ε K − 2 | B | , so averaging over b yields E b B P ε ( b ) ≤ ε K − 2 | A | 2 . Combining this with E b | N ( b ) | 2 ≥ K − 2 | A | 2 , choose b with a positive objective | N ( b ) | 2 − ( 2 ε ) − 1 B P ε ( b ) . Its neighborhood A 0 = N ( b ) has size at least a constant multiple of K − 1 | A | , and at most a 2 ε fraction of ordered pairs in A 0 2 are bad. Delete vertices of A 0 that have too many bad partners. The survivors A 2 remain a constant-power fraction of A , and for every a ∈ A 2 , all but at most 10 ε | A 2 | of the a 2 ∈ A 2 satisfy P 2 ( a , a 2 ) ≥ ε K − 2 | B | .

To obtain length-three paths, first prune A to A 1 = { a : | N ( a ) | ≥ ( 10 K ) − 1 | B | } ; this removes only a bounded fraction of the edges, since the total number of edges is at least K − 1 | A | | B | . Apply the length-two cleaning lemma to this graph to get A ′ = A 2 ⊂ A 1 . For each a ∈ A ′ , the set G ( a ) of its good partners in A ′ misses at most 10 ε | A ′ | . Now define B ′ as vertices with more than 20 ε | A ′ | neighbors in A ′ . For b ∈ B ′ , at least 10 ε | A ′ | of those neighbors lie in G ( a ) for each chosen a ∈ A ′ . Each such intermediate vertex contributes at least ε K − 2 | B | length-two paths from a ; adjoining its final edge to b gives

P 3 ( a , b ) ≳ ε 2 K − 3 | A | | B | .

The pruning retained each a ∈ A ′ with degree at least a constant times K − 1 | B | , so X ( A ′ , B ) has at least a constant times K − 2 | A | | B | edges. Vertices outside B ′ have at most 20 ε | A ′ | such edges, hence X ( A ′ , B ∖ B ′ ) ≤ 20 ε | A ′ | | B | . Choose ε as a sufficiently small negative power of K ; the discarded edges are then a small fraction of X ( A ′ , B ) , leaving | X ′ | ≥ K − O ( 1 ) | A | | B | . Every surviving cross-pair has the stated many-path lower bound, so the path-count inequality proves BSG. The proof is a sequence of explicit repairs to average information: discard low-degree vertices, select a neighborhood where most pairs share many neighbors, remove vertices with too many bad partners, and finally retain right vertices with enough links to the remaining good partners. Robust expansion is what makes the real argument iterate

For a nonconcentrated one-dimensional set A , the first real expansion lemma gives a fixed polynomial Q for which | Q ( A ) | δ ≥ δ − s − ε when | A | δ = δ − s . This alone does not permit iteration: Q ( A ) might be concentrated at intermediate scales. The stronger robust statement says, for some fixed polynomial Q : R k → R , if A is a ( δ , s , C ) set and Z ⊂ A k occupies a fixed power fraction of A k , then | Q ( Z ) | δ ≳ δ − s − ε . The notes use the concrete k = 3 map Q ( a 1 , a 2 , a 3 ) = a 1 + a 2 a 3 . This handles arbitrary dense subsets of the product, rather than only the entire product, and is the new input needed to recover a well-distributed subset of the expanded image. [P2-16]

Here is how robustness feeds iteration. First uniformize A . Uniformity and the scale-wise expansion argument imply Q ( A ) has large covering number at every coarser scale. But that is not enough: much of the coarse-scale image could come from a tiny part of the domain while the fine-scale covering number is contributed by another part. To prevent this split, examine the image in intervals at a sequence of nearby scales 1 ≥ ρ 1 > ρ 2 > ⋯ > ρ N = δ . At the first scale retain all image intervals; at each next scale call a parent interval bad if it captures more than ρ j s + ε − η | Q ( Z ) | ρ j + 1 of the next-scale image. Pull the bad intervals back to the parameter tuples in A k . If they occupied a substantial fraction of A k , the robust expansion lemma applied to that bad preimage would force their image to be large, contradicting the bound defining badness. Thus the bad preimage is small and can be removed while leaving enough parameter tuples for the robust estimate to remain applicable. Iterating the removal across the finite scale chain constructs a subset whose image obeys the nonconcentration inequality at each adjacent pair of scales; multiplying adjacent scale ratios gives the bound for separated scales, and choosing a sufficiently fine scale mesh controls intermediate radii. The resulting image contains a ( δ , s + ε / 2 , C ′ ) set, with tolerances reduced to absorb the accumulated losses. This is the detailed logic behind the official proof sketch; the transcript emphasizes that robustness, rather than a generic appeal to uniformity, is what eliminates the “large coarse part / different large fine part” enemy.

Why is the robust lemma true? Its proof reuses BSG rather than relying on a minor tweak of the earlier expansion argument. The first step gives some a ∈ A with | A + a A | δ ≥ δ − s − ε . A contradiction/exceptional-set argument upgrades this so almost every a has the property that every dense X ⊂ A × A still has | π a ( X ) | δ ≳ δ − s − ε . If not, a large set of bad a ’s would itself be a nonconcentrated subset to which the initial expansion applies. To prove the dense-subset claim, a restricted small projection creates high additive energy; Euclidean BSG at covering scale finds dense subsets with controlled full sumset, and the same symmetry injection used in the finite-field proof transfers expansion back to the chosen projection. Once this holds for most coefficients, apply it to a dense subset of A 3 : view Q ( a 1 , a 2 , a 3 ) = a 1 + a 2 a 3 as the projection ( x , y ) ↦ x + a y of the product pair ( a 1 , a 2 a 3 ) , use the robust two-coordinate estimate after a product/fiber decomposition, and absorb the constant-power losses in the small exponent ε . The lecture deliberately sketches these steps and says that some pruning and double-counting details are omitted; the supplied notes also label this a sketch. It would be inaccurate to report the complete technical proof as shown in these sources.

Once one expansion step returns a larger nonconcentrated subset inside Q ( A ) , iterate: the exponent s increases by a positive amount depending continuously on s , so for any target 1 − τ < 1 only finitely many steps are needed. Plünnecke–Ruzsa then simplifies the bounded-complexity polynomial growth to a one-coefficient expansion A + a A ; the product-set projection theorem follows by the same contagious-structure and double-counting mechanism as in the finite-field course. To pass from a general planar set, choose three well-separated directions and linearly normalize them to horizontal, vertical, and diagonal. The direction nonconcentration controls the condition number of this change of coordinates. Repeated BSG reductions replace the set by a dense subset of a product of its coordinate projections, and a robust projection estimate is needed at each passage. A final subtlety is that a large projection by itself is not enough: the projected coordinate set must also be nonconcentrated to serve as the next input. This “square-root baseline at every scale” is established by choosing two well-separated projections and using the injectivity of the paired projection map. Uniformization/double counting then upgrades scale-wise baseline size to the needed nonconcentration. Ruzsa, Plünnecke, Petridis, and BSG: explicit variables and losses

For finite sets in an abelian group, the Ruzsa triangle inequality

| A − C | | B | ≤ | A − B | | B − C |

has a short injection proof. For each z ∈ A − C , fix one representation z = a z − c z . Send ( z , b ) to ( a z − b , b − c z ) . The sum of the two output coordinates is a z − c z = z , so it recovers z exactly; the fixed representation then recovers a z , c z , and the first coordinate gives b = a z − ( a z − b ) . The map is injective into ( A − B ) × ( B − C ) . This inequality converts a small sumset into small difference sets by choosing the middle set as a reflected copy and checking the signs; no structural classification theorem is needed.

Petridis’ proof of Plünnecke makes clear where the exponent comes from. Given | A + B | ≤ K | A | , choose nonempty X ⊆ A minimizing | X + B | / | X | = K ′ ≤ K . For every finite C , prove | X + C + B | ≤ K ′ | X + C | by induction on | C | . For the inductive step add one translate c : put Y = { x ∈ X : x + c + B ⊂ X + C + B } . The new sums in X + ( C ∪ { c } ) + B are at most | X + B | − | Y + B | , and the new base sums in X + ( C ∪ { c } ) are at least | X | − | Y | . By minimality, | Y + B | ≥ K ′ | Y | , while | X + B | = K ′ | X | ; combining these with the induction hypothesis gives the desired ratio at most K ′ . Now take C = k B successively to get | X + k B | ≤ ( K ′ ) k | X | . Apply Ruzsa’s triangle inequality in the form | X | | m B − n B | ≤ | X + m B | | X + n B | ; this yields | m B − n B | ≤ K m + n | X | ≤ K m + n | A | . The conclusion is for the derived set m B − n B and is anchored by the minimizing subset X , not a claim that every subset of A expands by the same ratio.

For BSG, the quantitative input is a dense bipartite graph X ⊂ A × B . Suppose | A | , | B | ≤ N , | X | ≥ K − 1 N 2 , and the restricted sumset P = { a + b : ( a , b ) ∈ X } has | P | ≤ K N . z 1 = a + b 1 , z 2 = a 1 + b 1 , z 3 = a 1 + b .

They satisfy a + b = z 1 − z 2 + z 3 . Thus, if every pair ( a , b ) ∈ A ′ × B ′ has at least P 0 such paths, then counting representations of each sum gives | A ′ + B ′ | P 0 ≤ | P | 3 .

E b ∈ B | N ( b ) | 2 ≥ | B | − 1 ( ∑ b | N ( b ) | ) 2 ≥ K − 2 | A | 2 .

The expected number of bad pairs inside N ( b ) is at most η K − 2 | A | 2 , because each bad pair contributes for at most | B | choices of its common neighbor. Combining this with the lower bound on E | N ( b ) | 2 selects a b for which A ′ = N ( b ) has size ≳ K − 1 | A | and at most an O ( η ) fraction of its ordered pairs are bad. A further pruning (the lecture states and sketches this as its length-two lemma) produces A ″ ⊂ A ′ with | A ″ | ≳ K − 1 | A | such that each a ∈ A ″ has at most 10 η | A ″ | bad partners.

Each good pair ( a , a 1 ) has at least η K − 2 | B | common neighbors b 1 , so there are at least 10 η 2 K − 2 | A ″ | | B | ≳ η 2 K − 3 | A | | B | length-three paths from a to b . Finite groups: when a walk is stuck, look for an approximate subgroup

For a finite group G , a probability measure m u describes one random step. Its convolution is

( f ∗ g ) ( x ) = ∑ a b = x f ( a ) g ( b ) , ( μ ∗ ν ) ( x ) = ∑ a b = x μ ( a ) ν ( b ) .

If the walk multiplies on the right, its distribution after k independent steps, started at the identity, is μ ∗ k . The operator T μ f = f ∗ μ is a weighted average of right translations. Each translation preserves counting-measure ℓ 2 ( G ) , so the triangle inequality gives ‖ T μ f ‖ 2 ≤ ‖ f ‖ 2 . Constants are fixed and mean-zero functions stay mean-zero. Let σ 1 ( T μ ) be the largest singular value on that mean-zero subspace. Starting at g 0 , write δ g 0 = | G | − 1 1 + f 0 ; then ‖ f 0 ‖ 2 ≤ 1 , so

‖ T μ k δ g 0 − 1 | G | 1 ‖ 2 ≤ σ 1 ( T μ ) k .

Thus a fixed spectral gap 1 − σ 1 > 0 gives exponential ℓ 2 mixing, and since counting-measure ‖ f ‖ ∞ ≤ ‖ f ‖ 2 , also a pointwise error bound. Symmetry μ ( g ) = μ ( g − 1 ) makes T μ self-adjoint, which lets powers of the walk be analyzed through the same singular values.

The first obstacle is algebraic trapping. If a step set is contained in a proper subgroup, the walk never leaves that subgroup; on the full group there is an invariant nonconstant function and σ 1 = 1 . But failure to mix need not mean literal containment. The Bourgain–Gamburd proof begins with an inverse principle: if a symmetric walk on SL 2 ( F p ) has no spectral gap, repeated convolution must concentrate substantial mass on a set that behaves approximately like a subgroup. The lecture formulates this with a set H capturing a large portion of some bounded-length walk distribution, whose fixed product H 5 is at most p O ( δ ) | H | and whose size lies below the scale p 2.5 . This is a schematic lecture statement: the small exponents and mass constants depend on the parameters, and should not be silently replaced by a sharp classification theorem.

Here is why an approximate subgroup emerges from a stalled walk. Begin with uniform measure on a set A , so ‖ μ A ‖ 2 2 = 1 / | A | . Square the measure repeatedly, μ j + 1 = μ j ∗ μ j . A progress step decreases ‖ μ j ‖ 2 2 by a factor p − δ ; after boundedly many such steps the ℓ 2 norm is small enough to imply a spectral gap. The implication comes from the representation-dimension estimate established in the preceding lecture:

σ 1 ( T ν ) 2 ≤ C p 2 ‖ ν ‖ 2 2 .

For symmetric μ , T μ is self-adjoint, so applying this to a convolution power gives σ 1 ( T μ ) 2 k ≤ C p 2 ‖ μ ∗ k ‖ 2 2 . Therefore, unless the walk already mixes, some step must stall: its next squared ℓ 2 norm remains a large fraction of the previous one. Decompose the group into dyadic level sets of the point masses of μ j . There are only logarithmically many levels, so one level set H captures a substantial share of the probability and μ j is roughly uniform there. The stalled convolution inequality then forces many product collisions in H .

For finite subsets A , B ⊂ G , define the representation count r A , B ( g ) = # { ( a , b ) ∈ A × B : a b = g } and multiplicative energy

E ( A , B ) = ∑ g ∈ G r A , B ( g ) 2 = # { a 1 b 1 = a 2 b 2 : a i ∈ A , b i ∈ B } .

It counts pairs of factorizations of the same group element. For A = B , the diagonal choices alone give | A | 2 collisions; choosing three factors determines the fourth, so | A | 2 ≤ E ( A , A ) ≤ | A | 3 . Energy close to the upper scale means products have many representations, a sign of additive or multiplicative structure. In a noncommutative group the order of the factors matters: E ( A , B ) does not in general equal E ( B , A ) .

The stalled ℓ 2 inequality is exactly an energy lower bound after replacing the distribution by its heavy level set. Balog–Szemerédi–Gowers converts this average abundance of collisions into an actual structured subset: if E ( H , H ) ≥ K − 1 | H | 3 , then some H ′ ⊂ H has | H ′ | ≥ K − O ( 1 ) | H | and small difference-like product | H ′ H ′ − 1 | ≤ K O ( 1 ) | H ′ | . The graph proof is useful to remember. Draw a bipartite graph with left and right copies of H , joining ( a , b ) when a b is a popular product. High energy means many edges. A graph-cleaning lemma finds a large subset in which each pair of left vertices has many common neighbors. A length-four path between two vertices then writes their quotient in many ways as products of popular elements and inverses. Counting all possible popular factors and dividing by the multiplicity of these representations bounds | H ′ H ′ − 1 | . The inverse is natural here: unlike in an abelian sumset, a small H ′ H need not control later products. This is the noncommutative BSG mechanism behind “stuck implies structured.”

The second half identifies which approximate subgroups can occur in SL 2 ( F p ) . Actual proper subgroups are, up to small exceptional groups and conjugacy, largely contained in triangular subgroups. For approximate subgroups, one needs a robust analogue rather than a classification based on exact group order. The lecture’s theorem says, at schematic level, that a moderately large set H with slowly growing bounded products and | H | ≤ p 2.5 must have a positive fraction inside a coset of a Borel subgroup. A Borel here is a conjugate of the upper triangular subgroup. The prime field matters: in F p m , a proper subfield can support a large structured subgroup and becomes an additional obstruction.

The proof strategy analyzes how the set intersects simpler algebraic subgroups after moving to the algebraic closure, where matrices can be diagonalized. The diagonal torus and the unipotent subgroup expose scalar and additive coordinates. For example,

u ( t ) = ( 1 t 0 1 ) , b ( a , t ) = ( a t 0 a − 1 ) , b ( a , t ) b ( a ′ , t ′ ) = b ( a a ′ , a t ′ + t a ′ − 1 ) .

A set of many unipotents whose product set grows little yields a set of parameters with small additive growth. A large diagonal part with small product growth yields parameters with small multiplicative growth. The upper triangular multiplication law couples these two sets. Once the sets are large enough and not nearly all of F p , this would create an approximate subfield. But the prime field has no proper subfields, and the sum–product theorem rules out a substantial set that is simultaneously additively and multiplicatively structured. Therefore a non-Borel approximate subgroup cannot persist.

Putting the inverse theorem and classification together gives the mixing criterion. If a symmetric generating set A has size at least p ε and avoids concentration in every Borel coset, in the sense that | A ∩ g B | ≤ K ( ε ) p − ε | A | , then the walk has a uniform spectral gap σ 1 ( T A ) ≤ 1 − c ( ε ) . The logic is a contradiction: a nearly invariant walk produces an approximate subgroup; the classification forces that subgroup to place substantial mass in a Borel coset; the nonconcentration hypothesis forbids this. An arbitrarily small positive sum–product gain is enough because it rules out exact approximate subfields at every iteration. The lecture gives the mechanism and references the deep projection/product results as inputs; it does not provide complete proofs of the noncommutative inverse theorem or the robust Larsen–Pink classification.

Homogeneous dynamics: shear, diagonal renormalization, and projection geometry

Let G be a Lie group and Γ a discrete subgroup of finite covolume. The quotient X = G / Γ is a homogeneous space: G acts transitively, while a subgroup H can have periodic, dense, or more complicated orbits. For G = SL 2 ( R ) and Γ = SL 2 ( Z ) , the space parametrizes covolume-one lattices: g Γ corresponds to g Z 2 , and right multiplication by an integer determinant-one matrix changes the basis without changing the lattice. This quotient is not compact. The family ⟨ ( ϵ , 0 ) , ( 0 , ϵ − 1 ) ⟩ keeps area one while its shortest vector tends to zero and its other vector escapes. Mahler’s compactness criterion says precisely that the lattices whose shortest nonzero vector has length at least ϵ form a compact part of the space; the cusp records increasingly skinny lattices.

Two one-parameter subgroups control the picture:

u t = ( 1 t 0 1 ) , a r = ( e r 0 0 e − r ) .

The first shears a lattice horizontally by an amount proportional to height. Hedlund’s theorem says each unipotent orbit { u t x : t ∈ R } in SL 2 ( R ) / SL 2 ( Z ) is either periodic or dense. The geometric periodicity criterion is concrete: for a lattice Λ , a nonzero u T fixes it exactly when Λ contains a nonzero horizontal vector. Indeed, if ( x , 0 ) ∈ Λ , take any independent vector ( y , z ) ∈ Λ ; choosing T = x / z adds ( x , 0 ) to that vector and preserves the lattice. Conversely, if u T Λ = Λ for T ≠ 0 , then for any ( y , z ) ∈ Λ , the difference u T ( y , z ) − ( y , z ) = ( T z , 0 ) is a horizontal lattice vector (some z ≠ 0 ). Most lattices have no horizontal vector, so their unipotent orbit is not periodic; Hedlund supplies the nontrivial alternative, density. Diagonal orbits behave differently: they can be neither periodic nor dense, with closures of intermediate dimension.

To see why a projection theorem enters, compare how the two subgroups interact. Direct matrix multiplication gives

a r u t a r − 1 = u e 2 r t .

Thus a long segment 0 ≤ t ≤ T can be represented as a diagonal rescaling of a unit segment, with e 2 r = T . The dynamical question becomes: what does the diagonal action do to a short family of nearby unipotent orbits?

Put a right-invariant Riemannian metric on G by choosing an inner product at the identity and transporting it using right translations. This descends to the quotient because changing a lift of a point means right multiplication by Γ , an isometry. At the identity the tangent space is sl 2 ( R ) , the trace-zero matrices. An orthonormal basis can be chosen as U = ( 0 1 0 0 ) , U ~ = ( 0 0 1 0 ) , and D = 1 2 ( 1 0 0 − 1 ) . The right action is isometric, but the left action is not. To measure its derivative at the identity, follow it by the inverse right translation, which is an isometry; the resulting differential is conjugation, M ↦ a r M a r − 1 . It sends U to e 2 r U , U ~ to e − 2 r U ~ , and D to D . Consequently the singular values of the left action (under the lecture’s inverse action convention, L a r − 1 ) are e 2 r , 1 , e − 2 r , along expanding, neutral, and compressing directions. Their product is one, so the action distorts lengths but preserves volume. The orbit tangent U is exactly the expanding direction.

The key geometric subtlety is that the compressing direction is not fixed relative to a tube of unipotent orbits. A long stretched orbit is cut into unit-length pieces when it wraps through the quotient’s fundamental domain. Nearby orbit pieces might be packed close together after compression, so length alone does not imply distribution. But the direction of compression twists as one moves along a unit orbit. At any one height, some transverse pairs can collapse; across the full height interval, the collapsing direction sweeps through many slopes. Projection theory says a set of directions that is sufficiently spread out cannot collapse a substantial set of points at every slope: most slices retain large projected covering number. Applying this across the height parameter prevents too many orbit segments from being glued together. The result is a geometric “either spread or exceptional” principle: away from bad concentration directions, the long unipotent segment spreads through the quotient.

The simple picture is closest to a proof when the quotient is compact, where every unit tube has uniformly controlled geometry. For the modular surface the cusp cannot be ignored. A point a − r x may lie very deep in the cusp, corresponding to a lattice with an extremely short vector; then the compact-tube estimates do not apply. The correct conclusion is therefore conditional: either the orbit distributes, or the diagonal renormalization reaches the cusp, which means the original lattice was close to one with a horizontal vector and hence close to a periodic unipotent orbit. This explains why the naive “stretch plus many directions” argument would falsely predict every orbit dense if the cusp were omitted.

There is a useful bridge to number theory. For an indefinite quadratic form Q in at least three variables with coefficients not all proportional to integers, Oppenheim predicts and Margulis proved that Q ( Z n ) is dense in R . After a linear change of variables, the form becomes a standard one while the integer lattice becomes another covolume-one lattice Λ . The symmetry group SO ( Q ) preserves the form, so Q ( Λ ) = Q ( g Λ ) along its orbit in the space of lattices. Understanding whether this orbit is dense therefore controls the set of values of Q ; exceptional nondense orbits correspond to arithmetic structure in the form. The elementary SL 2 shear picture is a visual precursor to the higher-dimensional homogeneous orbit-closure theorems of Dani, Margulis, and Ratner, whose proofs require substantially more machinery.

Lattice-orbit spreading: expanding a segment is not enough

The second homogeneous-dynamics lecture asks how a long unipotent segment becomes spread through the lattice space. The identity a r u t a r − 1 = u e 2 r t turns a segment of length T into a unit segment seen through a diagonal rescaling, with e 2 r = T . This creates long and thin tubes in local coordinates. Their orbit direction expands, while one transverse direction contracts. Length by itself is inconclusive: many pieces could lie close together after the contraction.

The relevant twist is visible by comparing two nearby initial conditions. Let g 0 be a point in the group, and perturb it in a transverse tangent direction v 0 . The orbit points at time t are u t g 0 and u t ( g 0 + e p s i l o n v 0 ) , whose first-order separation is represented by u t v 0 . Under diagonal renormalization the compressed transverse direction changes relative to the unipotent orbit direction; the angle at which two orbit tubes can collapse is therefore not a single fixed slope. Measuring this angle requires a metric on the quotient and tangent vectors at the same base point: group-coordinate vectors at distinct points cannot simply be compared as if they were parallel Euclidean arrows. The twisting is the bridge to projection theory: as time runs, the bad projection direction sweeps through a family, and a point set cannot have tiny projections for all sufficiently varied directions unless it has exceptional structure.

A useful quantitative model tracks the cross-section of a tube. Move the starting point away from the cusp by a − R , split a long orbit into J pieces of time length r , and let X j denote the cross-section after the j th piece. At resolution d e l t a , covering the tube is essentially the number of cross-section balls times the d e l t a − 1 positions along its length: | U j | d e l t a ≍ δ − 1 | X j | d e l t a . Choose e 2 r = δ − 1 . One step induces a family of almost-projection maps f t on the cross-section. A planar projection estimate states, for X ⊂ B ( 0 , 1 ) and directions averaged over the circle,

E θ ∈ S 1 | π θ ( X ) | δ ≳ | X | δ 1 / 2 .

The exponent is forced by a disk: if X is a disk of radius ρ ≥ δ , then | X | δ ≍ ( ρ / δ ) 2 while a typical projected interval has covering number about ρ / δ . Since the dynamical maps imitate projections, this yields the schematic recurrence N j + 1 ≳ δ − 1 N j 1 / 2 for N j = | X j | δ . Starting with N 0 ≍ 1 , induction gives N j ≳ δ − 2 ( 1 − 2 − j ) , ignoring controlled losses. Indeed if N j ≥ δ − 2 ( 1 − 2 − j ) , then N j + 1 ≳ δ − 1 − ( 1 − 2 − j ) = δ − 2 ( 1 − 2 − ( j + 1 ) ) . The exponent approaches 2 , the full planar covering exponent. This says the section occupies nearly all available resolution after enough stages; it does not itself establish density of an orbit, because local coordinates, direction-distribution, cusp avoidance, and the exceptional homogeneous-orbit alternatives still need control.

The lecture then tests the geometry in SL 3 ( R ) . The group has dimension 8 . For a diagonal element with weights chosen to preserve determinant, conjugation has expanding, neutral, and contracting directions at several rates; the one-dimensional unipotent subgroup is not the only expanding direction. The transverse compression directions form a multiparameter family, but the orbit parameter supplies only one parameter. Thus the needed projection family is a curve in the sphere of directions rather than all directions on a sphere. A curve can fail badly: if its directions lie on the equator of S 2 , a thin slab with cross-section 1 × 1 and thickness δ can project to a δ × 1 rectangle, with only about δ − 1 cells instead of the δ − 2 one hopes for from a two-dimensional set. Curvature/nondegeneracy of the direction curve rules out that flat obstruction and permits a Fourier-decoupling estimate, typically with an arbitrarily small δ ϵ loss. This is a restricted-direction problem, not the ordinary planar projection theorem. The lecture’s final reference to quantitative orbit-density results is a research-level comparison; it is not derived by the recurrence alone. [P2-21]

Furstenberg sets: rich tubes, three regimes, and Beck’s theorem

For the sharp projection problem, let E be a set of approximately δ − t balls of radius δ in the unit square. At each x ∈ E , choose approximately δ − s essentially distinct δ -tubes through x . After pigeonholing, suppose a typical tube contains r balls of E . The incidence count is the number of pairs ( x , T ) with x ∈ T ; it is approximately | E | δ | T x | , and also approximately | T | r . Therefore

| T | ≍ | E | δ | T x | r .

The conjectural sharp bound has three competing constructions. A star gives many tubes through each point with little sharing; an integer-grid arrangement gives the Szemerédi–Trotter scale; random tubes through a large point set realize the third, purely thick-set regime. Precisely, for E a ( δ , t , C ) set, with δ -tube direction sets Dir T x each a ( δ , s , C ) subset of S 1 , let T = ⋃ x ∈ E T x be the essentially distinct union. For every ϵ > 0 , the course notes state

| T | ≥ c ϵ C − O ( 1 ) δ ϵ min { δ − t − s , δ − t / 2 − 3 s / 2 , δ − 1 − s } .

The first, second, third terms are regimes A, B, C. If a typical tube contains r balls and incidences are uniformized, then | E | δ ≍ δ − t , | T x | ≍ δ − s , and | T | r ≍ δ − t − s ; hence

r ≲ ϵ C O ( 1 ) δ − ϵ max { 1 , δ − ( t − s ) / 2 , δ − ( t − 1 ) } .

Comparing term exponents shows A is the minimum when s ≥ t , C when s + t ≥ 2 , and B when s < t < 2 − s . This precisely recovers which classical tool applies: double counting in A, Fourier in C, while B is the difficult grid-like interval.

The continuum Beck theorem is a robust way to get out of a one-scale trap. Suppose E has size about δ − u and satisfies a rectangle nonconcentration condition: for every rectangle of dimensions ρ × 1 , its intersection with E has at most a C ρ η fraction of the total δ -covering number. Then some point x ∈ E sees many directions to the rest of E :

| L x , E | δ ≳ ϵ , η min { δ − u , δ − 1 } .

This resembles the finite-point Beck theorem: either there are many distinct joining lines, or a large fraction of points lie on one line. The nonconcentration condition forbids the second alternative. It is important that the statement is real-geometric; the analogous assertion over C fails because a complex line has real dimension two, so a planar set can lie in one complex line without being concentrated in a real thin rectangle.

Here is the bootstrap mechanism behind the continuum form. For each point x , let L x , E be the direction set to points of E and use pigeonholing to retain a large subset of base points where the direction-set size is nearly uniform. Each L x , E inherits a nonconcentration estimate from the rectangle hypothesis: if many points viewed from x fall into a narrow angular interval, then those points lie in the associated narrow rectangle, contradicting the assumed bound. Counting point–line incidences in two ways makes a typical line rich in points and gives the elementary lower bound on the family of lines. The Orponen–Shmerkin epsilon-improvement theorem then upgrades a direction set of dimension s to size at least δ − s − ϵ in the difficult 0 < s < min ( u , 1 ) range. The same estimate applies after rescaling to subrectangles because the uniform direction sets have nonconcentration at coarser scales. Iterating the improvement increases the exponent by a fixed positive amount each time; after finitely many steps it reaches min ( u , 1 ) . This is why uniformization is not cosmetic: a fine-scale count alone would not imply that the rescaled subsets retain the same hypotheses. The lecture presents this as a proof architecture, while the full epsilon-improvement proof lies in the cited research work. [P2-22]

AD regularity turns the rich-tube count into a submultiplicative quantity

A set is AD regular at exponent t when every ball of radius ρ centered on the set contains about the fraction ρ t of the total mass, uniformly at every intermediate scale. In a discrete δ -model, a uniform set with branching factors B j is AD regular when the product of the first J branchings is comparable to δ − J t for every J . This is stronger than merely having | E | δ ∼ δ − t : it says the same dimension is visible inside every occupied ball and at every scale.

Let R A D ( δ ) be the largest typical number of δ -balls of an AD-regular set that can lie in one δ -tube, under the direction-set hypotheses of the Furstenberg problem. The crucial submultiplicative estimate is

R A D ( δ 1 δ 2 ) ≲ R A D ( δ 1 ) R A D ( δ 2 ) .

To see the counting behind it, thicken each fine ball and tube to scale δ 1 . A fine tube meets at most R A D ( δ 1 ) coarse balls. Inside each such ball, rescale by δ 1 − 1 ; it becomes a unit ball containing a δ 2 -configuration, and a short fine tube segment becomes a δ 2 -tube. AD regularity guarantees the rescaled set still has the required mass distribution, regardless of which coarse ball was selected. Thus at most R A D ( δ 2 ) fine balls occur in each coarse ball along the tube. Multiplying the two counts proves the estimate. For a merely ( δ , t ) set, a selected coarse ball may contain an atypically dense portion, so this rescaling step is not valid with uniform constants.

The projective variant assumes every base point uses the same tube directions. In the submultiplicative decomposition at δ 1 = δ 2 = δ , directions differing by less than δ cannot be distinguished after thickening, so the local problem inside a coarse ball is projective. Consequently a sharp estimate for projective AD-regular configurations propagates to general AD-regular ones. If the submultiplicative inequality is nearly an equality at every step, then typical coarse balls and typical tubes must also be nearly saturated. In a projective tube, choose coordinates with the coarse tube horizontal. The fine set is contained in a product A × B of transverse positions and longitudinal positions. Near-saturation means a positive fraction of the product rectangles are occupied at the expected density. Projecting at small slope c sends the product to a discretized sum A + c B . If all such projections remain small, an asymmetric Balog–Szemerédi–Gowers reduction extracts a genuine product-like subset; Plünnecke–Ruzsa then propagates small growth to sums with several slopes. The ABC sum-product theorem says that for nonconcentrated real sets of dimensions a , b , c , if every c ∈ C keeps A + c B no larger than A , then a ≥ b + c . The near-saturated geometry would force the opposite dimension inequality in the hard regime, contradiction. This is the source of the epsilon improvement: either the configuration already has more projected points than the extremal estimate permits, or submultiplicativity is strictly improved. The lecture and course notes outline this rigidity argument but explicitly omit the asymmetric BSG and spacing-case details. [P2-23]

The last scale-combination argument

The well-spaced theorem is a continuous analogue of Szemerédi–Trotter. Let E be N radius- δ balls in the unit disk, with at most a bounded number in any ball of radius N − 1 / 2 . This is the maximally spread regime: a tube can meet at most about N 1 / 2 points, which explains why the elementary N / R term in the point-line theorem is unnecessary. A random δ -tube meets about δ N balls on average, so the richness threshold must exceed this baseline by a small power. For R > δ − ϵ δ N , the theorem gives

| T R ( E ) | ≲ ϵ δ − ϵ N 2 R 3 .

The Fourier method alone proves the desired scale when R is near its minimum allowed value: it gives | T R ( E ) | ≲ δ − 1 N R − 2 , and substituting R ∼ δ N makes this N 2 R − 3 up to the small loss. If R is larger, set a thicker scale ρ by ρ N ∼ R . Well-spacing ensures | E ρ | ρ = N (up to constants): thickening each point to radius ρ does not merge distinct points, since the spacing scale N − 1 / 2 exceeds ρ when R ≤ N 1 / 2 . The Fourier estimate for ρ -tubes gives a bound for the number of rich fat tubes. But one fat tube may contain many rich thin tubes.

To count the thin tubes inside one fat tube, first impose a two-ends condition: each rich thin tube has a substantial portion of its incident points near each of its two ends. If the points were all concentrated in a much shorter sub-tube, an induction on scale handles that subproblem; otherwise the two-ends condition holds after decomposition. If a fat tube contains R ~ points, count triples ( T , x 1 , x 2 ) where T is a rich thin tube inside it and x 1 , x 2 are incident points near opposite ends. Each thin tube contributes on the order of R 2 ordered pairs. Conversely there are at most R ~ 2 choices of the pair, and two points separated along the tube determine at most one essentially distinct joining tube. Hence there are at most O ( R ~ 2 / R 2 ) rich thin tubes in that fat tube. The Fourier bound for fat tubes at richness R ~ is O ( N 2 / ( R R ~ 2 ) ) because ρ − 1 = N / R . Multiplication cancels R ~ 2 and yields O ( N 2 / R 3 ) ; dyadically summing over the logarithmically many values of R ~ is absorbed by the δ − ϵ loss. The well-spacing condition is used to preserve N after thickening; the lower richness threshold is needed to suppress the low-frequency Fourier contribution.

Finally, define the branching function of a uniform set E by

f ( x ) = log 1 / δ ⁡ | E δ x | δ x , 0 ≤ x ≤ 1.

Here x = 0 means unit scale and x = 1 means finest scale δ ; thus f ( 0 ) = 0 , f ( 1 ) = t when | E | δ = δ − t . The ( δ , t ) nonconcentration condition gives f ( x ) ≥ t x . Since a radius- ρ disk can be covered by O ( ( ρ / ρ ′ ) 2 ) disks of radius ρ ′ , one has f ( x + h ) ≤ f ( x ) + 2 h . The function is increasing and 2-Lipschitz. AD-regularity corresponds to a straight line of slope t . Well-spaced geometry has an initial slope close to 2 followed by a flat part. Ren–Wang’s semi-well-spaced condition relaxes that broken line: for 0 < s < 1 , the graph lies above the broken profile of slopes 2 − s and s . Fourier analysis controls this whole semi-well-spaced class.

Multiscale decomposition cuts the branching graph at a scale ρ . The coarse set E ρ has the left segment of the graph; inside a typical ρ -ball, magnification gives the right segment as the branching function of the local fine set. Richness factors accordingly: number of coarse balls hit by a fat tube times number of fine balls hit in each such ball. If both segments have slopes in the hard interval s < t I < 2 − s , both subproblems use the grid-regime bound and their product has the correct exponent. A steep first piece and shallow second piece instead require the Fourier and elementary bounds, whose product is too weak; merely splitting arbitrarily is therefore not enough.

The final decomposition theorem arranges the graph, apart from a small leftover set of scales, into intervals where either it is almost linear with slope in ( s , 2 − s ) , or its restriction lies above the semi-well-spaced broken profile. Lipschitz regularity is central: Rademacher’s theorem makes f differentiable almost everywhere, so sufficiently short intervals around points with derivative in the desired range look nearly linear and correspond to AD-regular pieces. The portions whose slopes fall outside that range are covered by the semi-well-spaced alternative. One then repeatedly applies the coarse/fine factorization, controls each piece with its appropriate theorem, and multiplies the bounds. The transcript and notes state this decomposition and give an illustrative graph but do not include its full combinatorial proof. Together with the AD-regular and well-spaced estimates, this completes the course’s proof outline for the sharp Furstenberg set theorem; it is a proof architecture built on those theorems, not a replacement for their omitted technical arguments. Finite-group mixing: norms, gap, and expansion

Let G be a finite group with uniform probability measure. A probability measure μ on G defines the right-convolution operator ( T μ f ) ( x ) = ∑ g μ ( g ) f ( x g − 1 ) . If μ ( g ) = μ ( g − 1 ) , the operator is self-adjoint. Constants are fixed, so the interesting invariant subspace is L 0 2 ( G ) = { f : E G f = 0 } . A spectral gap is a number γ > 0 such that ‖ T μ | L 0 2 ‖ 2 → 2 ≤ 1 − γ . Iterating gives ‖ T μ k f ‖ 2 ≤ ( 1 − γ ) k ‖ f ‖ 2 for every mean-zero f . For a walk started at x , its density relative to uniform is | G | 1 { x } , so its centered initial L 2 norm is | G | − 1 . Cauchy–Schwarz then gives total-variation distance at most 1 2 | G | ( 1 − γ ) k . Thus k ≳ γ − 1 log ⁡ ( | G | / ε ) steps suffice for error ε .

The same gap implies expansion. For A ⊂ G , put f = 1 A − | A | / | G | . Symmetry and the gap yield

⟨ 1 A , T μ 1 A ⟩ = | A | 2 | G | + ⟨ f , T μ f ⟩ ≤ | A | 2 | G | + ( 1 − γ ) ( | A | − | A | 2 | G | ) .

The weighted number of transitions leaving A is | A | − ⟨ 1 A , T μ 1 A ⟩ , hence at least γ | A | ( 1 − | A | / | G | ) ≥ γ | A | / 2 when | A | ≤ | G | / 2 . This is the precise bridge from contraction of fluctuations to combinatorial expansion.

For G = SL 2 ( F p ) , the group has order p ( p 2 − 1 ) ≍ p 3 . The nontrivial irreducible representations have dimension at least ( p − 1 ) / 2 : restrict a nontrivial representation to the upper-unipotent subgroup U ≅ ( F p , + ) . Some nontrivial additive character must occur, since a representation trivial on U and its conjugates is trivial on the group generated by them. The diagonal torus acts on character labels by multiplication by squares; a nonzero label has an orbit of size ( p − 1 ) / 2 , so all those distinct characters occur and the representation has at least that dimension. Noncommutative Plancherel then bounds convolution on mean-zero functions by the largest Fourier block: schematically ‖ T μ ‖ 2 ≤ | G | d min − 1 ‖ μ ‖ 2 2 ≲ p 2 ‖ μ ‖ 2 2 . This explains the p 2 scale and why a measure with ‖ μ ‖ 2 2 ≪ p − 2 gives contraction. The upper-triangular subgroup has size about p 2 and can support a walk with no escape from a proper subgroup, showing why that scale cannot simply be removed.

The Bourgain–Gamburd route in Lecture 19 is not a direct proof of a gap from representation dimensions alone. Flattening says that if convolution fails to reduce ‖ μ ‖ 2 after a bounded number of steps, then many products coincide; noncommutative Balog–Szemerédi–Gowers converts this high multiplicative energy into an approximate subgroup. A product theorem for SL 2 ( F p ) says a set of intermediate size either grows under multiplication or is concentrated in a proper algebraic subgroup, principally a Borel subgroup. Prime-field sum-product growth rules out persistent concentration there unless the original walk measure was trapped in an actual obstruction. Once flattening holds at each scale, repeated convolution lowers L 2 mass until the representation-theoretic estimate applies. The lecture does not prove the noncommutative BSG or product theorem; these remain named deep inputs.

Homogeneous dynamics: hypotheses behind the lattice picture

The quotient SL 2 ( R ) / SL 2 ( Z ) is the space of unimodular lattices: g Z 2 has covolume | det g | = 1 , and right multiplication by γ ∈ SL 2 ( Z ) changes only the lattice basis. It is noncompact. A sequence leaves every compact set exactly when its shortest nonzero lattice vector tends to zero; this is Mahler’s compactness criterion. The cusp is therefore a geometric failure of uniform injectivity radius, not an incidental picture.

For u t = ( 1 t 0 1 ) , a r = diag ( e r , e − r ) , the conjugation identity a r u t a r − 1 = u e 2 r t follows by multiplying the matrices. A period T ≠ 0 for the unipotent orbit of a lattice Λ is equivalent to a nonzero horizontal vector in Λ . If ( x , 0 ) ∈ Λ and ( y , z ) is independent, then u x / z ( y , z ) = ( y + x , z ) differs by a lattice vector, so u x / z Λ = Λ . Conversely, if u T Λ = Λ , subtracting ( y , z ) from u T ( y , z ) gives ( T z , 0 ) ∈ Λ for any lattice vector with z ≠ 0 . Hedlund’s theorem says the unipotent orbit is periodic or dense; hence the absence of a horizontal vector forces density. This dichotomy is special to unipotent flow and should not be transferred to diagonal orbits, which can have intermediate-dimensional closures.

For a longer orbit segment, choose e 2 r = T and conjugate the unit-time segment. The expanding orbit tangent and contracting transverse tangent create long thin tubes, while twist varies the collapse direction. The projection recurrence from the previous section operates only after orbit pieces remain in controlled local charts. Mahler compactness provides exactly the missing condition: restrict to a compact part by excluding lattices with a too-short vector. In the full quotient, one must separately account for segments entering the cusp; a quantitative density theorem therefore has an “either spread or near a proper periodic/homogeneous obstruction” alternative. The transcript’s recurrence is a model for that mechanism, not a stand-alone proof of orbit density.
