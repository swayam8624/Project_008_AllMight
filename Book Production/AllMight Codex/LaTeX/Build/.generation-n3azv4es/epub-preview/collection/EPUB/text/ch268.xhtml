5. Waiting times, event counts, and covariance geometry

Exponential distribution

The exponential distribution models a nonnegative waiting time in a memoryless event process.

Let:

T ∼ Exponential ( λ ) ,

where:

λ > 0

is the rate parameter.

Its PDF is:

p T ( t ) = { λ e − λ t , t ≥ 0 , 0 , t < 0.

The parameter λ has units of inverse time if T is measured in time.

1 Deriving the CDF

For t ≥ 0 :

F T ( t ) = ∫ 0 t λ e − λ s d s .

Integrate:

F T ( t ) = [ − e − λ s ] 0 t .

Therefore:

F T ( t ) = 1 − e − λ t .

For t < 0 , the CDF is zero.

The survival function is:

S T ( t ) = P ( T > t ) .

For t ≥ 0 :

S T ( t ) = e − λ t .
2 Deriving the mean: exponential distribution

The mean is:

E [ T ] = ∫ 0 ∞ t λ e − λ t d t .

Integration by parts gives:

E [ T ] = 1 λ

because the boundary term vanishes and the remaining exponential integral evaluates to 1 / λ .

Thus:

E [ T ] = 1 λ .

The second moment is:

E [ T 2 ] = 2 λ 2 .

Therefore:

Var ( T ) = 2 λ 2 − 1 λ 2 = 1 λ 2 .

The standard deviation is also:

σ T = 1 λ .
3 Memorylessness

The defining property is:

P ( T > s + t ∣ T > s ) = P ( T > t )

for s , t ≥ 0 .

Let’s derive it.

Because:

{ T > s + t } ⊆ { T > s } ,

conditional probability gives:

P ( T > s + t ∣ T > s ) = P ( T > s + t ) P ( T > s ) .

Using the exponential survival function:

= e − λ ( s + t ) e − λ s = e − λ t .

But:

e − λ t = P ( T > t ) .

Therefore the exponential distribution is memoryless.

Knowing that no event has happened during the first s seconds does not change the distribution of the additional waiting time.

This is a special property and is not true for most waiting-time distributions.

4 Numerical example: exponential waiting times

Suppose events arrive at an average rate of:

λ = 2  events per second .

The mean waiting time is:

E [ T ] = 0.5  seconds .

The probability of observing an event within 0.1 seconds is:

P ( T ≤ 0.1 ) = 1 − e − 2 ( 0.1 ) = 1 − e − 0.2 ≈ 0.181269 .

The probability of waiting longer than one second is:

P ( T > 1 ) = e − 2 ≈ 0.135335 .
5 Numerical stability of the CDF

The formula:

1 − e − λ t

can lose precision when λ t is very small, because e − λ t is close to one.

C++ provides:

std::expm1(x)

which evaluates e x − 1 accurately for small x .

Therefore a stable exponential CDF can use:

return -std::expm1(-lambda * t);

rather than:

return 1.0 - std::exp(-lambda * t);

This is an example of mathematically equivalent formulas having different numerical behavior.

6 Inverse-transform sampling

Let:

U ∼ U ( 0 , 1 ) .

Set:

U = F T ( t ) = 1 − e − λ t .

Then:

1 − U = e − λ t .

Take logarithms:

log ⁡ ( 1 − U ) = − λ t .

Thus:

T = − log ⁡ ( 1 − U ) λ .

In floating-point code, -log1p(-u)/lambda can be preferable when u is small.

This is a concrete example of inverse-CDF sampling, which we will generalize in the sampling and Monte Carlo chapters.

Poisson distribution

The Poisson distribution models counts of events under an idealized Poisson process or other situations satisfying the appropriate count law.

A Poisson random variable takes values:

K ∈ { 0 , 1 , 2 , … } .

Write:

K ∼ Poisson ( λ )

where λ ≥ 0 is the expected count over the specified observation interval or region.

Its PMF is:

P ( K = k ) = e − λ λ k k ! .

For λ = 0 , the distribution is concentrated at K = 0 .

1 Derivation as a limit of binomial distributions

Suppose an interval is divided into n small subintervals.

Assume each subinterval contains an event with probability:

p = λ n ,

and trials are independent.

The total count is:

K n ∼ Binomial ( n , λ n ) .

Therefore:

P ( K n = k ) = ( n k ) ( λ n ) k ( 1 − λ n ) n − k .

Rewrite the first two factors:

( n k ) ( λ n ) k = n ( n − 1 ) ⋯ ( n − k + 1 ) k ! λ k n k .

For fixed k , as n → ∞ :

n ( n − 1 ) ⋯ ( n − k + 1 ) n k → 1.

Therefore:

( n k ) ( λ n ) k → λ k k ! .

The remaining factor satisfies:

( 1 − λ n ) n − k → e − λ .

Thus:

P ( K = k ) = e − λ λ k k ! .

This is the Poisson limit of the binomial distribution.

2 Deriving the mean: Poisson distribution

Start with:

E [ K ] = ∑ k = 0 ∞ k e − λ λ k k ! .

The k = 0 term vanishes.

For k ≥ 1 :

k k ! = 1 ( k − 1 ) ! .

Therefore:

E [ K ] = e − λ ∑ k = 1 ∞ λ k ( k − 1 ) ! = λ e − λ ∑ j = 0 ∞ λ j j ! = λ e − λ e λ .

Thus:

E [ K ] = λ .
3 Deriving the variance: Poisson distribution

First calculate the factorial second moment:

E [ K ( K − 1 ) ] .

Using the PMF:

E [ K ( K − 1 ) ] = ∑ k = 2 ∞ k ( k − 1 ) e − λ λ k k ! .

Because:

k ( k − 1 ) k ! = 1 ( k − 2 ) ! ,

we obtain:

E [ K ( K − 1 ) ] = λ 2 e − λ ∑ j = 0 ∞ λ j j ! = λ 2 .

Now use:

K 2 = K ( K − 1 ) + K .

Thus:

E [ K 2 ] = λ 2 + λ .

Therefore:

Var ( K ) = λ 2 + λ − λ 2 .

Hence:

Var ( K ) = λ .

The Poisson distribution has equal mean and variance.

This equality is an important model diagnostic, although finite-sample estimates will not generally be exactly equal.

4 Numerical example: Poisson event counts

Suppose:

K ∼ Poisson ( 2 ) .

What is the probability of exactly three events?

P ( K = 3 ) = e − 2 2 3 3 ! .

Therefore:

P ( K = 3 ) = e − 2 8 6 ≈ 0.180447 .

The probability of zero events is:

P ( K = 0 ) = e − 2 ≈ 0.135335 .
5 Poisson process and exponential waiting times

Suppose events occur according to a homogeneous Poisson process with rate r events per unit time.

The count in an interval of duration t satisfies:

N ( t ) ∼ Poisson ( r t ) .

Thus:

E [ N ( t ) ] = r t .

The probability of no events during the interval is:

P ( N ( t ) = 0 ) = e − r t .

Let T be the waiting time until the first event.

The event T > t means no event occurred during the first t units of time.

Therefore:

P ( T > t ) = P ( N ( t ) = 0 ) = e − r t .

This is exactly the survival function of an exponential distribution with rate r .

Hence:

T ∼ Exponential ( r ) .

This establishes the connection between Poisson counts and exponential waiting times.

6 Poisson counts in physical simulation

Poisson distributions can model idealized event arrivals, emission counts, radioactive decay counts, and photon detection under appropriate independence and rate assumptions.

But not every light-related or sensor-related count is Poisson.

Dead time, saturation, correlations, varying event rates, and detector processing can produce different distributions.

In rendering research, such distinctions matter when constructing physically motivated noise models or benchmarking stochastic estimators.

Multivariate Gaussian distribution

We now extend the Gaussian distribution from one uncertain scalar to an entire uncertain vector.

Suppose a reconstructed point has uncertain position:

X = [ X Y Z ] .

We need to describe not only how uncertain each coordinate is, but also how coordinate errors are coupled.

A multivariate Gaussian uses a mean vector:

μ ∈ R n

and covariance matrix:

Σ ∈ R n × n .

We write:

X ∼ N ( μ , Σ ) .

For a nonsingular covariance matrix, its PDF is:

p ( x ) = exp ⁡ [ − 1 2 ( x − μ ) T Σ − 1 ( x − μ ) ] ( 2 π ) n / 2 det Σ .

This formula is dense, so we will derive it from transformations and explain every component.

1 Begin with independent standard normals

Let:

Z = [ Z 1 ⋮ Z n ]

where each Z i ∼ N ( 0 , 1 ) , and the components are independent.

Their joint density is the product of the scalar densities:

p Z ( z ) = ∏ i = 1 n 1 2 π e − z i 2 / 2 .

Multiply the normalizing factors:

∏ i = 1 n 1 2 π = 1 ( 2 π ) n / 2 .

Combine the exponents:

∏ i e − z i 2 / 2 = e − 1 2 ∑ i z i 2 .

Since:

∑ i z i 2 = z T z ,

the joint density becomes:

p Z ( z ) = 1 ( 2 π ) n / 2 e − 1 2 z T z .

This is the standard multivariate Gaussian with zero mean and identity covariance.

Its equal-density surfaces are spheres because the exponent depends only on:

‖ z ‖ 2 .
2 Transform the standard Gaussian

Let:

X = μ + A Z

where A is an invertible n × n matrix.

The mean is:

E [ X ] = μ + A E [ Z ] = μ .

The covariance is:

Cov ( X ) = E [ ( A Z ) ( A Z ) T ] = A E [ Z Z T ] A T = A I A T .

Therefore:

Σ = A A T .

This says an arbitrary nonsingular linear transformation of an independent standard Gaussian produces a correlated Gaussian.

We can interpret A as combining rotation, stretching, and shearing of the standard spherical distribution.

3 Derive the density with a change of variables

We have:

x = μ + A z .

Solve for z :

z = A − 1 ( x − μ ) .

The Jacobian of this inverse transformation is:

J = A − 1 .

The density transformation formula is:

p X ( x ) = p Z ( A − 1 ( x − μ ) ) | det A − 1 | .

Substitute the standard Gaussian density:

p X ( x ) = | det A − 1 | ( 2 π ) n / 2 exp ⁡ [ − 1 2 ‖ A − 1 ( x − μ ) ‖ 2 ] .

Now expand the squared norm:

‖ A − 1 d ‖ 2 = ( A − 1 d ) T ( A − 1 d ) = d T A − T A − 1 d .

Because:

Σ = A A T ,

we have:

Σ − 1 = A − T A − 1 .

Thus:

‖ A − 1 d ‖ 2 = d T Σ − 1 d .

For the normalization, use:

det Σ = det ( A A T ) = ( det A ) 2 .

Therefore:

| det A | = det Σ .

Since:

| det A − 1 | = 1 | det A | ,

we obtain:

p ( x ) = 1 ( 2 π ) n / 2 det Σ exp ⁡ [ − 1 2 ( x − μ ) T Σ − 1 ( x − μ ) ] .

That is the full multivariate Gaussian density, derived rather than memorized.

4 The Mahalanobis distance

The quantity:

d M 2 = ( x − μ ) T Σ − 1 ( x − μ )

is the squared Mahalanobis distance.

Ordinary Euclidean squared distance is:

d E 2 = ( x − μ ) T ( x − μ ) .

Mahalanobis distance accounts for the distribution’s scale and correlations.

If one direction has large variance, moving along that direction contributes less to Mahalanobis distance.

If another direction has small variance, a comparable physical displacement can produce a much larger Mahalanobis distance.

5 Geometric interpretation using eigenvectors

Because a covariance matrix is symmetric, it can be eigendecomposed:

Σ = Q Λ Q T .

For positive-definite covariance:

Λ = diag ( λ 1 , … , λ n )

with every λ i > 0 .

Then:

Σ − 1 = Q Λ − 1 Q T .

Let:

d = x − μ .

Express the displacement in the covariance eigenbasis:

z = Q T d .

The squared Mahalanobis distance becomes:

d M 2 = ∑ i = 1 n z i 2 λ i .

A constant-density surface satisfies:

d M 2 = c

for some c > 0 .

In 2D, this describes an ellipse. In 3D, it describes an ellipsoid.

The eigenvectors identify the principal directions. The square roots of eigenvalues determine the standard-deviation scale along those directions.

For the contour d M 2 = c , the semi-axis lengths are:

a i = c λ i .

Thus covariance is not merely a table of correlations. It encodes the geometry of an uncertainty ellipsoid.

6 Numerical 2D Gaussian example

Consider a random vector with mean:

μ = [ 0.5 − 1 ]

and covariance:

Σ = [ 4 1.2 1.2 9 ] .

The first coordinate has variance 4, so its standard deviation is:

σ X = 2.

The second has variance 9:

σ Y = 3.

The covariance between them is:

Cov ( X , Y ) = 1.2 .

Their correlation is:

ρ = 1.2 ( 2 ) ( 3 ) = 0.2 .

The positive correlation causes the distribution’s equal-density contours to be tilted relative to the coordinate axes.

7 Determinant and density at the mean

The determinant is:

det Σ = ( 4 ) ( 9 ) − ( 1.2 ) 2 = 36 − 1.44 = 34.56 .

For a two-dimensional Gaussian:

p ( μ ) = 1 2 π det Σ ,

because the Mahalanobis distance at the mean is zero.

Thus:

p ( μ ) = 1 2 π 34.56 ≈ 0.027072806 .

The units are inverse square units of the random coordinates. This is a density value, not the probability that X equals the mean exactly.

8 Cholesky factorization and Gaussian sampling

We can generate a correlated Gaussian from independent standard normals using:

X = μ + L Z

where:

Σ = L L T .

For our covariance, choose lower-triangular:

L = [ a 0 b c ] .

Then:

L L T = [ a 2 a b a b b 2 + c 2 ] .

Match this with:

Σ = [ 4 1.2 1.2 9 ] .

First:

a 2 = 4 ⟹ a = 2.

Then:

a b = 1.2 ⟹ b = 1.2 2 = 0.6 .

Finally:

b 2 + c 2 = 9.

Thus:

c 2 = 9 − 0.36 = 8.64 ,

so:

c = 8.64 .

Therefore:

L = [ 2 0 0.6 8.64 ] .

If:

Z 1 , Z 2 ∼ iid N ( 0 , 1 ) ,

then:

X = 0.5 + 2 Z 1

and:

Y = − 1 + 0.6 Z 1 + 8.64 Z 2 .

The shared Z 1 component creates the desired correlation.

Verify the covariance:

Cov ( X , Y ) = Cov ( 2 Z 1 , 0.6 Z 1 + 8.64 Z 2 ) .

By bilinearity:

= 1.2 Var ( Z 1 ) + 2 8.64 Cov ( Z 1 , Z 2 ) .

The standard normals are independent, so their covariance is zero. Also Var ( Z 1 ) = 1 .

Therefore:

Cov ( X , Y ) = 1.2 .

The variance of Y is:

0.6 2 + 8.64 = 9.

The transformation reproduces the required covariance exactly in the mathematical model.

9 Conditional Gaussian distributions

An especially important result is that conditioning one part of a jointly Gaussian vector on another produces a Gaussian conditional distribution, under the usual nonsingular covariance assumptions.

Partition the random vector:

X = [ X a X b ]

with mean:

μ = [ μ a μ b ]

and covariance:

Σ = [ Σ a a Σ a b Σ b a Σ b b ] .

If Σ a a is positive definite, then:

E [ X b ∣ X a = a ] = μ b + Σ b a Σ a a − 1 ( a − μ a )

and:

Cov ( X b ∣ X a ) = Σ b b − Σ b a Σ a a − 1 Σ a b .

For any vector v , set u = − Σ a a − 1 Σ a b v . Then

[ u T v T ] Σ [ u v ] = v T ( Σ b b − Σ b a Σ a a − 1 Σ a b ) v ≥ 0 ,

because the joint covariance is PSD. Thus the conditional covariance is PSD; if the joint covariance is PD, this Schur complement is PD. The second expression is a Schur complement.

This directly connects probability to the Schur-complement linear algebra used in optimization.

10 Numerical conditional Gaussian example

Return to:

μ X = 0.5 , μ Y = − 1 , Var ( X ) = 4 , Var ( Y ) = 9 , Cov ( X , Y ) = 1.2 .

The conditional mean of Y given X = x is:

E [ Y ∣ X = x ] = − 1 + 1.2 4 ( x − 0.5 ) .

Thus:

E [ Y ∣ X = x ] = − 1 + 0.3 ( x − 0.5 ) .

If we observe:

X = 2.5 ,

the conditional mean becomes:

− 1 + 0.3 ( 2 ) = − 0.4 .

The conditional variance is:

Var ( Y ∣ X ) = 9 − 1.2 2 4 .

Therefore:

Var ( Y ∣ X ) = 8.64 .

Before observing X , the variance of Y was 9.

After conditioning, it becomes 8.64.

The reduction reflects information gained from observing the correlated variable.

For a jointly Gaussian model, the conditional covariance does not depend on the specific observed value of x , although the conditional mean does.

That property is one reason Gaussian models are convenient for estimation and filtering.

11 Important geometry: a 2D one-sigma ellipse is not a 68% region

For a scalar Gaussian:

P ( | Z | ≤ 1 ) ≈ 0.6827 .

It is tempting to assume that the corresponding two-dimensional one-sigma ellipse contains 68.27% probability.

That is incorrect.

For:

X ∼ N ( μ , Σ )

in two dimensions with positive-definite covariance, the squared Mahalanobis distance:

D 2 = ( X − μ ) T Σ − 1 ( X − μ )

follows a chi-squared distribution with two degrees of freedom.

Therefore:

P ( D 2 ≤ c ) = 1 − e − c / 2 .

For the ellipse with:

D 2 ≤ 1 ,

the enclosed probability is:

P ( D 2 ≤ 1 ) = 1 − e − 1 / 2 ≈ 0.393469 .

So the one-sigma ellipse contains only about 39.3% probability.

To enclose 95% probability, solve:

1 − e − c / 2 = 0.95 .

Then:

e − c / 2 = 0.05 , c = − 2 log ⁡ 0.05 ≈ 5.991465 .

The ellipse semi-axis lengths are therefore:

5.991465 λ i

along the covariance eigenvectors.

This distinction is extremely important when drawing uncertainty ellipses in SLAM, tracking, reconstruction, robotics, and statistics.

Covariance matrices in probability

We have already introduced covariance matrices, but now we will study their full structure.

For a random vector X ∈ R n :

Σ = E [ ( X − μ ) ( X − μ ) T ] .

Write the centred random vector as:

Z = X − μ .

Then:

Σ = E [ Z Z T ] .

Each matrix entry is:

Σ i j = E [ Z i Z j ] .
1 Covariance is symmetric

Take the transpose:

Σ T = E [ ( Z Z T ) T ] .

But:

( Z Z T ) T = Z Z T .

Therefore:

Σ T = Σ .

This is an exact mathematical property of covariance matrices.

A nonsymmetric matrix cannot be the exact covariance of a real-valued random vector under the conventional definition.

Small numerical asymmetries may arise from independent calculations or rounding, but they should be diagnosed or handled explicitly.

2 Variance in an arbitrary direction

Choose any deterministic vector:

a ∈ R n .

Form the scalar random variable:

Y = a T X .

Its mean is:

E [ Y ] = a T μ .

Its variance is:

Var ( Y ) = E [ ( a T ( X − μ ) ) 2 ] = E [ a T Z Z T a ] = a T E [ Z Z T ] a .

Therefore:

Var ( a T X ) = a T Σ a .

This is one of the most powerful covariance identities.

It says the uncertainty of a linear measurement is obtained by projecting the covariance matrix onto that measurement direction.

3 Affine uncertainty propagation

Let:

Y = A X + b ,

where A is a deterministic matrix and b is a deterministic translation.

The mean is:

μ Y = A μ X + b .

The centred output is:

Y − μ Y = A ( X − μ X ) .

Its covariance becomes:

Σ Y = E [ A ( X − μ X ) ( X − μ X ) T A T ] = A Σ X A T .

Therefore:

Σ Y = A Σ X A T .

Translation changes the mean but does not change covariance.

4 Connection to rotations

If R is a rotation matrix:

Y = R X + t ,

then:

Σ Y = R Σ X R T .

This rotates the covariance ellipsoid without changing its eigenvalues.

A rigid rotation changes the orientation of the uncertainty but not its principal variance magnitudes.

By contrast, a nonuniform scale or general affine transform changes those variance magnitudes.

5 Nonlinear uncertainty propagation

Suppose:

Y = f ( X )

with differentiable f .

For small uncertainty around the mean, linearize:

f ( X ) ≈ f ( μ X ) + J f ( μ X ) ( X − μ X ) .

The approximate covariance is:

Σ Y ≈ J f Σ X J f T .

This is the first-order covariance propagation formula derived through Jacobians in the geometry and Jacobian discussion.

The approximation becomes less reliable when uncertainty is large relative to local curvature, when the function is singular, or when the input distribution crosses discontinuities.

A second-order Taylor expansion can also introduce a correction to the predicted mean:

E [ f i ( X ) ] ≈ f i ( μ ) + 1 2 tr ( H f i Σ ) .

Here H f i is the Hessian of output component i .

Thus nonlinear transformations can change both the covariance and the mean in ways that first-order propagation does not fully capture.

6 The connection to Gaussian splatting

A 3D Gaussian representation may have a mean position:

μ 3 D

and covariance:

Σ 3 D .

A camera rotation maps its covariance into camera coordinates:

Σ c = R Σ 3 D R T .

A local perspective-projection Jacobian then gives an approximate image-space covariance:

Σ 2 D ≈ J π Σ c J π T .

Combining:

Σ 2 D ≈ J π R Σ 3 D R T J π T .

This formula is directly relevant to projected Gaussian footprints.

But there is an important distinction between a normalized probability density and a Gaussian-shaped rendering kernel.

A probability density contains the normalization factor involving det Σ . Many Gaussian rendering formulations use kernels of the form:

G ( x ) = exp ⁡ ( − 1 2 ( x − μ ) T Σ − 1 ( x − μ ) )

together with learned opacity or amplitude terms.

This Gaussian-shaped kernel is not automatically a normalized PDF.

Confusing the two can lead to incorrect interpretations of opacity, spatial mass, and covariance normalization.

The mathematical covariance transformation is closely related, but the full rendering model and its compositing semantics must be treated separately.

7 The rank of propagated covariance

Let:

Σ Y = J Σ X J T .

The rank satisfies:

rank ( Σ Y ) ≤ min ( rank ( J ) , rank ( Σ X ) ) .

If a transformation loses dimensions, the output covariance cannot recover them.

For a 2 × 3 perspective-projection Jacobian:

J π : R 3 → R 2 ,

the output covariance has rank at most two.

If the projected Gaussian has sufficient spread in two independent image directions and the point lies in a valid projection region, the resulting 2 × 2 covariance may be positive definite.

But degenerate 3D uncertainty or a rank-deficient effective mapping can produce a singular 2D covariance.

A renderer must handle or regularize such cases deliberately rather than blindly inverting every covariance.

Why covariance must be positive semidefinite

This is one of the most important results of the distribution and covariance chapters because it connects probability directly to symmetric matrices, eigenvalues, Cholesky factorization, and numerical robustness.

A covariance matrix cannot be arbitrary.

It must be symmetric and positive semidefinite, abbreviated PSD.

We write:

Σ ⪰ 0 .

The mathematical definition is:

a T Σ a ≥ 0 for every  a ∈ R n .

Why must this hold?

From the covariance quadratic-form section:

a T Σ a = Var ( a T X ) .

A variance is an expectation of a square:

Var ( Y ) = E [ ( Y − E [ Y ] ) 2 ] .

A square is nonnegative.

Therefore variance cannot be negative.

Hence:

a T Σ a = Var ( a T X ) ≥ 0 .

That proves the PSD requirement.

1 Eigenvalue interpretation

Because Σ is real symmetric, it has real eigenvalues and an orthonormal eigenbasis.

Let:

Σ v i = λ i v i .

Choose a = v i , with ‖ v i ‖ = 1 .

Then:

v i T Σ v i = λ i .

But PSD requires this quadratic form to be nonnegative.

Therefore:

λ i ≥ 0 .

Every eigenvalue of a valid covariance matrix must be nonnegative.

Conversely, a real symmetric matrix with all nonnegative eigenvalues is PSD.

Thus these are equivalent descriptions.

2 Positive definite versus positive semidefinite

A matrix is positive definite, or PD, if:

a T Σ a > 0

for every nonzero a .

It is positive semidefinite if the result is allowed to equal zero.

A PD covariance has strictly positive variance along every nonzero direction.

A PSD but singular covariance has at least one direction with zero variance.

That means some linear combination of the random variables is deterministic.

3 Example of a singular but valid covariance

Consider:

Σ = [ 1 2 2 4 ] .

The determinant is:

det Σ = 4 − 4 = 0.

The eigenvalues are:

5 , 0.

Both are nonnegative, so the matrix is PSD.

But it is singular.

What physical uncertainty could produce it?

Let X be a scalar random variable with variance one, and let:

Y = 2 X .

Then:

Var ( X ) = 1 , Var ( Y ) = 4 , Cov ( X , Y ) = 2.

The covariance matrix is exactly:

[ 1 2 2 4 ] .

The variables have perfect linear dependence.

The combination:

Y − 2 X

has zero variance.

Thus the distribution occupies a one-dimensional line in the two-dimensional plane.

It does not have an ordinary nonsingular 2D Gaussian density with respect to area measure.

4 Example of an invalid covariance

Consider:

A = [ 1 2 2 1 ] .

Its eigenvalues are:

3 , − 1.

The negative eigenvalue makes it indefinite.

Choose:

a = [ 1 − 1 ] .

Then:

a T A a = − 2.

If this matrix were a covariance, it would imply:

Var ( X − Y ) = − 2 ,

which is impossible.

Therefore A cannot be a valid covariance matrix.

5 A 2D covariance validity condition

Consider a symmetric covariance matrix:

Σ = [ σ X 2 c c σ Y 2 ] .

For it to be PSD, we require:

σ X 2 ≥ 0 , σ Y 2 ≥ 0 ,

and:

σ X 2 σ Y 2 − c 2 ≥ 0 .

Equivalently:

| c | ≤ σ X σ Y .

If both standard deviations are positive:

| c σ X σ Y | ≤ 1.

Thus:

| ρ | ≤ 1 .

The familiar correlation bound is therefore also a matrix positive-semidefiniteness condition.

6 Cholesky factorization and positive definiteness

For a symmetric positive-definite matrix:

Σ = L L T

with L lower triangular and positive diagonal.

This is Cholesky factorization.

It is useful for sampling, Gaussian density evaluation, whitening, Mahalanobis-distance calculations, and stable linear solves.

For a singular PSD matrix, an ordinary non-pivoted Cholesky implementation that assumes strictly positive pivots may fail.

That failure does not necessarily mean the covariance is invalid. It may be valid but singular.

To handle singular covariance, use an eigendecomposition, an SVD, a rank-revealing factorization, or an appropriate pivoted method, depending on the task.

Original bridge: whiten a covariance ellipse

This worked connection links covariance geometry to Cholesky factorization. It is an added example for this volume, not a claim about Strang’s lectures. Let

Σ = [ 4 1.2 1.2 1 ] , L = [ 2 0 0.6 0.8 ] , L L T = Σ .

For mean μ = ( 3 , − 1 ) and standard-normal coordinates z = ( 1 , 1 ) ,

x = μ + L z = ( 5 , 0.4 ) .

Whitening solves z = L − 1 ( x − μ ) , so the squared Mahalanobis distance is d M 2 = z T z = 2 . The squared Euclidean distance from the mean is

‖ x − μ ‖ 2 2 = ( 5 − 3 ) 2 + ( 0.4 + 1 ) 2 = 5.96 .

The determinant is det Σ = ( det L ) 2 = 2.56 ; the bivariate Gaussian density at x is

p ( x ) = exp ⁡ ( − d M 2 / 2 ) 2 π det Σ = e − 1 3.2 π ≈ 0.0366 .

This assumes an SPD covariance and full two-dimensional Lebesgue measure. A singular PSD Gaussian is confined to a lower-dimensional affine subspace and does not have this full-area density.

7 Numerical covariance repair

In practical code, a covariance estimate can contain a tiny negative eigenvalue due to floating-point error.

One simple repair for a symmetric matrix is to eigendecompose:

A = Q Λ Q T ,

replace negative eigenvalues by zero:

Λ _ + = diag ( max ( λ i , 0 ) ) ,

then reconstruct:

A _ + = Q Λ _ + Q T .

For a real symmetric matrix, this is a nearest PSD projection in the Frobenius norm when no additional constraints are imposed.

But if the diagonal variances must remain fixed, or the result must be a correlation matrix with unit diagonal, simple eigenvalue clipping may not satisfy all requirements.

More sophisticated nearest-PSD or nearest-correlation methods may be necessary. Nicholas Higham’s work establishes important matrix-nearness formulations and algorithms for these problems.

Most importantly, a covariance repair modifies the model.

If a matrix has a significantly negative eigenvalue, do not simply clip it and claim everything is correct. First investigate whether the cause is numerical roundoff, incorrect covariance assembly, invalid parameterization, or an actual modeling mistake.

Singular directions explain reconstruction and variation

Use SVD to separate input directions, gains and output directions. Least squares, minimum norm, regularization, PCA and polar decomposition then become connected applications of maps already understood.

Why a matrix factorization is a change in how we see the map

A matrix is first a rule that transforms an input, not a rectangular block of numbers. If A = B C , then A x = B ( C x ) : the input passes through C and then through B . A factorization is useful when it exposes simpler actions whose composition equals the original one. This is the right starting point for singular value decomposition (SVD), because SVD is a coordinate choice that makes a complicated map look like independent one-dimensional channels.

Consider the two-coordinate map A = [ 2 1 1 2 ] . It sends ( x , y ) T to ( 2 x + y , x + 2 y ) T . Each output depends on both input coordinates: the coordinates are coupled in this basis. A diagonal map such as D = diag ( 3 , 1 ) instead sends ( p , q ) to ( 3 p , q ) ; each coordinate evolves independently. Coupling is not always an intrinsic property of the physical transformation. It can be a consequence of how we chose coordinates.

For the symmetric example, the orthonormal directions q 1 = ( 1 , 1 ) T / 2 and q 2 = ( 1 , − 1 ) T / 2 form the columns of Q . In the original basis, A mixes x and y ; in the Q basis it has the diagonal representation Q T A Q = diag ( 3 , 1 ) . Coordinates p = ( x + y ) / 2 and q = ( x − y ) / 2 reveal the independent modes: p is multiplied by three and q is unchanged. The transformation itself did not change. We changed the frame in which we describe it.

An orthogonal matrix changes between orthonormal frames while preserving lengths and angles. In two dimensions a determinant- + 1 orthogonal matrix is a rotation; determinant − 1 also includes a reflection. “Rotate, scale, rotate” is an intuitive reading of SVD, but the precise description is “change to an orthonormal input basis, scale each coordinate independently, then express the result in an orthonormal output basis.” The input and output bases can differ because a rectangular map can take one space into another.

Eigenanalysis asks a square map to return a direction to itself up to scalar: A v = λ v . That is a useful but restrictive demand. SVD asks the more flexible question: can we choose an orthonormal input direction v i whose image is a scalar multiple of some orthonormal output direction u i ? The relation is A v i = σ i u i , with σ i ≥ 0 . The input and output directions need not coincide. This distinction makes SVD available for every real rectangular matrix, even when eigenvectors are missing, complex, or numerically awkward.

Singular value decomposition covers every rectangular map

Eigenvectors are tied to square maps. A graphics transform may instead map an n -dimensional input to an m -dimensional measurement, and its input and output directions live in different spaces. singular value decomposition (SVD) handles that general case:

A = U Σ V T .

For real A ∈ R m × n , U and V are orthogonal (or have orthonormal columns in a thin factorization), and Σ is rectangular diagonal with nonnegative entries σ 1 ≥ σ 2 ≥ ⋯ ≥ 0 . In a complex problem transpose becomes conjugate transpose. The right singular vector v i is an input direction; A v i = σ i u i sends it to the paired output direction. The singular value is the stretch. Unlike an eigenvector, this does not require input and output spaces to be the same.

The geometric story is “rotate or reflect the input coordinates, stretch along perpendicular axes, then rotate or reflect in the output space.” Orthogonal stages preserve length; the diagonal stage exposes the map’s true principal stretches. The singular values are square roots of eigenvalues of A T A , but computing SVD by explicitly forming A T A is often a poor numerical shortcut: it squares the condition number and may erase small singular information. Use this identity to understand, not automatically to implement.

Full SVD uses U ∈ R m × m and V ∈ R n × n . Thin/economy SVD keeps only the columns needed to represent A , saving storage and work. If r = rank ( A ) , compact rank-revealing forms retain r nonzero singular directions. For rank-deficient matrices, zero singular values identify null directions. Singular vectors corresponding to repeated singular values are not individually unique: any orthonormal basis of the repeated subspace is valid. A sign flip of a paired pair ( u i , v i ) also leaves the product unchanged.

The SVD equation as independent input-output channels

For A ∈ R m × n , a full SVD is

A = U Σ V T ,

where U ∈ R m × m and V ∈ R n × n are orthogonal, and Σ ∈ R m × n is rectangular diagonal. Its diagonal singular values are nonnegative and conventionally sorted as σ 1 ≥ σ 2 ≥ ⋯ ≥ 0 . Multiplying by V on the right gives A V = U Σ . Reading this equality column by column yields A v i = σ i u i . That vector equation is the atomic meaning of the factorization.

For an arbitrary input x , its coordinates in the right-singular-vector basis are z = V T x . Then the map acts as w = Σ z , and the output in ordinary coordinates is y = U w . Thus

x → V T z → Σ w → U y = A x .

In singular coordinates each surviving channel follows w i = σ i z i : no input coefficient spills into a different output coefficient. The right singular vectors are in the domain R n ; the left singular vectors are in the codomain R m . This makes the two-basis structure explicit and avoids treating the factors as unexplained symbols.

The unit sphere in input space remains a sphere through the orthogonal coordinate change V T . The diagonal stage turns it into an axis-aligned ellipsoid whose semiaxis lengths are the singular values. The final orthogonal change U orients that ellipsoid in output space. Consequently σ i = ‖ A v i ‖ 2 for unit v i , the largest singular value is the largest possible 2-norm stretch, and v 1 is a direction that attains it:

σ 1 = max ‖ x ‖ 2 = 1 ‖ A x ‖ 2 = ‖ A ‖ 2 .

A zero singular value collapses an input direction completely. A small positive singular value preserves that direction mathematically but nearly erases its magnitude, which makes reversal sensitive to noise. Singular values are nonnegative because a sign can be absorbed by changing the sign of a paired singular vector. A simultaneous sign flip of u i and v i leaves σ i u i v i T unchanged. When a singular value is repeated, its singular subspace is determined, while the particular orthonormal basis chosen inside that subspace is not unique.

Deriving singular directions through a Gram matrix

The Gram matrix A T A is the algebraic bridge between SVD and symmetric eigenanalysis. Starting from an SVD and using U T U = I gives

A T A = V Σ T Σ V T .

The middle matrix is diagonal with entries σ i 2 , so v i is an eigenvector of A T A with eigenvalue σ i 2 . Likewise A A T = U Σ Σ T U T , so the u i are eigenvectors of A A T with the same squared singular values. This explains why eigenvalues of a Gram matrix are nonnegative and why singular values are their square roots.

The existence argument can be read in the other direction. Since A T A is symmetric positive semidefinite, choose an orthonormal eigenbasis v i with nonnegative eigenvalues λ i . For a unit eigenvector,

‖ A v i ‖ 2 2 = v i T A T A v i = λ i .

Set σ i = λ i . For each positive σ i , define u i = A v i / σ i . These output vectors are orthonormal: u i T u j = v i T A T A v j / ( σ i σ j ) , which is zero for distinct orthogonal eigenvectors and one when i = j . Complete the bases orthonormally in any unused directions. The resulting factors satisfy A v i = σ i u i and reconstruct A .

For any x , the quadratic form makes the positive-semidefinite fact immediate:

x T A T A x = ( A x ) T ( A x ) = ‖ A x ‖ 2 2 ≥ 0.

It is positive for every nonzero x exactly when A x ≠ 0 for every nonzero x , which means A has full column rank. Thus A T A is positive definite if and only if Null ( A ) = { 0 } . This derivation is valuable for understanding geometry and rank. It is not a recommendation to compute an SVD by explicitly forming A T A : the operation squares the condition number, κ 2 ( A T A ) = κ 2 ( A ) 2 when A has full column rank, and can erase information about small singular values. Stable SVD algorithms work with orthogonal transformations and bidiagonal forms rather than relying on that numerically damaging shortcut.

Full, thin, and compact shapes for tall and wide matrices

Shape is part of the SVD contract. For A of shape m × n , the full factors have U of shape m × m , Σ of shape m × n , and V T of shape n × n . The product has shape ( m × m ) ( m × n ) ( n × n ) = m × n . The diagonal of Σ has length p = min ( m , n ) ; values beyond the rank are zero in exact arithmetic.

For a tall matrix with m ≥ n , the economy or thin factorization normally returns U t ∈ R m × n , Σ t ∈ R n × n , and V ∈ R n × n , so A = U t Σ t V T . Full SVD would also store m − n extra columns of U completing the output-space basis. Those columns describe directions perpendicular to the image of A , and are unnecessary when the task only needs reconstruction or application of the map. Example shapes for a 5 × 2 input are full U : 5 × 5 , Σ : 5 × 2 , V : 2 × 2 ; thin U t : 5 × 2 , Σ t : 2 × 2 , V : 2 × 2 .

For a wide matrix with m < n , a common economy form uses U ∈ R m × m , a square diagonal Σ t ∈ R m × m , and V t T ∈ R m × n , giving A = U Σ t V t T . It contains the p = m paired singular directions. A full SVD adds n − m additional columns to V ; those complete the input basis and, when rank is full row rank, span the nullspace of A . For a 2 × 5 matrix, full shapes are U : 2 × 2 , Σ : 2 × 5 , V : 5 × 5 ; economy shapes can be U : 2 × 2 , Σ t : 2 × 2 , V t : 5 × 2 . The economy product is dimensionally ( 2 × 2 ) ( 2 × 2 ) ( 2 × 5 ) = 2 × 5 . Libraries vary in the precise “economy” return convention, so a result type or API must state its shapes rather than rely on that word alone.

When the exact rank is r , the compact rank- r SVD retains only the nonzero paired directions: U r ∈ R m × r , Σ r ∈ R r × r , and V r ∈ R n × r , with A = U r Σ r V r T . This is the smallest exact factor representation, but exact rank is a mathematical concept and numerical rank requires a tolerance. If A has dimensions 1,000,000 × 64 , a full U would require a million-square array, while thin U t needs only 1,000,000 × 64 . The choice between full, thin, and compact factors changes whether storage is feasible and which subspaces are explicitly available.

A rectangular diagonal map also has a direct geometric reading. For example, Σ = [ 4 0 0 2 0 0 ] maps ( a , b ) T to ( 4 a , 2 b , 0 ) T . It embeds a two-dimensional input into a plane in three-dimensional output space; the output cannot fill the third dimension. The two input singular directions receive independent stretches, and the unused output direction lies perpendicular to the range.

Rank, both nullspaces, and the four fundamental subspaces

If rank ( A ) = r , exactly r singular values are positive in exact arithmetic. The first r right singular vectors span the row space, while the remaining n − r right singular vectors span Null ( A ) , since A v i = 0 for each zero singular value. The first r left singular vectors span Col ( A ) . The remaining m − r left singular vectors span Null ( A T ) because A T u i = σ i v i = 0 . Thus SVD places all four fundamental subspaces in paired orthogonal bases: row space with nullspace in the domain, column space with left nullspace in the codomain.

For A = [ 1 1 2 2 ] the second column duplicates the first, so rank is one. Here A T A = [ 5 5 5 5 ] has eigenvalues 10 and 0 , hence singular values 10 and 0 . The zero right singular vector points along ( 1 , − 1 ) T , a change to the input that the matrix cannot observe. The surviving right vector points along ( 1 , 1 ) T and the surviving left vector spans the column direction ( 1 , 2 ) T . Rank deficiency is not an SVD failure: it is precisely the information SVD reveals.

Floating-point computations rarely produce a perfect zero for a theoretically rank-deficient matrix. A numerical rank rule may declare σ i negligible when it is below a scale-relative cutoff, often related to max ( m , n ) ϵ machine σ 1 , but the appropriate tolerance depends on measurement noise and application meaning. Multiplying all entries by a unit conversion factor should not arbitrarily change a relative rank decision. Conversely, a tiny singular value can encode a real but weakly measured direction rather than a dimension that is truly absent. Keep algebraic rank, numerical rank, and domain-specific confidence distinct.

Pseudoinverse makes least squares and minimum norm one operation

If A is square and invertible, A − 1 b solves exactly. Real problems may be rectangular, inconsistent, or rank-deficient. The Moore–Penrose pseudoinverse generalizes inversion while respecting least squares and minimum norm. Its exact mathematical definition uses every strictly positive singular value:

A + = V Σ + U T , Σ i i + = { 1 / σ i , σ i > 0 , 0 , σ i = 0.

In finite precision we often choose a threshold τ and reciprocate only singular values above it. Call that result A τ + , the truncated or numerical pseudoinverse. If a positive singular value is discarded, A τ + b solves the retained-rank approximation of the problem; it need not minimize the original residual over every direction. The threshold is a policy tied to scale, precision, and application. Tiny singular values correspond to directions where inversion would magnify noise; discarding them states that those directions are not trusted at the selected resolution.

Take the rank-one matrix A = [ 3 0 0 0 ] and target b = ( 6 , 5 ) T . Its SVD is already visible: U = V = I and Σ = A . The exact equation would require 3 x 1 = 6 and 0 x 2 = 5 , so no exact solution exists. Least squares sets x 1 = 2 and cannot change the second residual; every ( 2 , t ) has residual ( 0 , − 5 ) . The minimum-norm member is ( 2 , 0 ) , exactly what A + b returns. This small example keeps three facts distinct: rank deficiency, inconsistency, and the extra minimum-norm rule.

Then x = A + b is a least-squares minimizer of ‖ A x − b ‖ 2 . If many minimizers have the same residual, it is the one with smallest Euclidean norm. For a consistent underdetermined system, that chooses the solution closest to zero. This is a principled choice, not proof that the minimum-norm answer is the only physically meaningful one; a graphics application may need regularization, constraints, or a prior.

The 2-norm condition number for a full-rank matrix is κ 2 ( A ) = σ max / σ min . For rank-deficient A , it is infinite in the ordinary inverse sense. A large condition number means small data perturbations can cause large solution changes. Residual and solution error are different: a solver can produce a small residual while the solution remains highly sensitive. Report both when the distinction matters.

The truncated SVD also gives the best rank- k approximation to A in both spectral and Frobenius norms. Keeping the leading singular directions preserves the most energy under those measures; discarding the tail compresses information. Eckart–Young is the theorem that makes “keep the largest k singular values” optimal for this specific approximation objective. It does not say the approximation is best for every perceptual, semantic, or downstream-engine objective.

The Moore–Penrose inverse and its four identities

For a full-column-rank square or rectangular matrix, inverse intuition still has limits: a rectangular matrix has no two-sided ordinary inverse, and a singular matrix cannot be inverted. SVD supplies the Moore–Penrose pseudoinverse. Reverse the nonzero channels in reverse order: U T returns output coordinates to singular coordinates, Σ + reciprocates positive scales, and V returns to the input basis:

A + = V Σ + U T , Σ i i + = { 1 / σ i , σ i > 0 , 0 , σ i = 0.

The exact definition uses every strictly positive singular value, however small. In a full factorization the pseudoinverse has shape n × m . For invertible square A , it equals A − 1 . Zero singular directions are assigned zero in Σ + ; division by zero is never attempted.

The four Moore–Penrose identities are

A A + A = A , A + A A + = A + , ( A A + ) T = A A + , ( A + A ) T = A + A .

The first two express inverse-like consistency on the portions of the map that can be reached and recovered. The symmetry conditions make A A + and A + A orthogonal projections rather than oblique projections. Specifically, A A + projects output vectors onto Col ( A ) ; A + A projects input vectors onto Row ( A ) . For the SVD, these are U r U r T and V r V r T respectively. These projection meanings are more useful than memorizing the identities without context.

A small positive singular value makes its reciprocal large. If σ i = 10 − 12 , exact A + multiplies the corresponding output coefficient by 10 12 . That is mathematically correct for the exact map but can magnify measurement noise catastrophically. This is why the distinction between exact pseudoinverse and truncated pseudoinverse matters. Given a threshold τ , define A τ + by reciprocating only singular values satisfying σ i > τ and setting the rest to zero. This is a rank decision and a modeling policy. If it discards any positive singular values, A τ + b does not in general minimize the residual ‖ A x − b ‖ 2 over all x for the original matrix: it solves using the retained singular subspace and may leave a residual component that an omitted positive direction could have reduced. Exact A + , by contrast, uses all positive directions and produces an original-problem least-squares minimizer. Thresholding may be more useful in noisy settings, but it trades residual fit for stability and must be named accurately.

Least squares from decoupling, then minimum norm

Consider A x ≈ b . Insert the SVD and use orthogonality, which preserves the Euclidean norm. Let z = V T x and c = U T b . Then

‖ A x − b ‖ 2 = ‖ Σ z − c ‖ 2 .

The least-squares problem has become independent scalar problems, one per singular direction. For every positive singular value, choose z i = c i / σ i , which matches that output coordinate. A zero singular direction cannot affect the output, so its coefficient does not change residual size. Among all minimizers, setting each such free coefficient to zero gives the smallest input norm because V is orthogonal and ‖ x ‖ 2 = ‖ z ‖ 2 . Therefore z = Σ + c , x = V z = V Σ + U T b = A + b . This proves both claims: exact pseudoinverse solution minimizes the original Euclidean residual, then chooses the minimum-norm solution among residual minimizers.

The same logic also explains the projection residual. The component of b in Col ( A ) is matched; the orthogonal component is unreachable and remains as residual. In exact arithmetic, the least-squares residual r = A x − b obeys A T r = 0 , so it is perpendicular to every column of A . This geometry is the least-squares normal condition, derived without needing to solve normal equations.

For an inconsistent rank-deficient example, let A = diag ( 3 , 0 ) and b = ( 6 , 5 ) T . The second output coordinate cannot be produced, so no exact solution exists. Any x = ( 2 , t ) T gives the same residual ( 0 , − 5 ) T ; the pseudoinverse selects ( 2 , 0 ) T because a nullspace component only increases norm. For an underdetermined consistent example, let A = [ 1 1 ] and b = 2 . Every solution satisfies x 1 + x 2 = 2 . Write x = ( 1 , 1 ) T + t ( 1 , − 1 ) T . Its squared norm is ( 1 + t ) 2 + ( 1 − t ) 2 = 2 + 2 t 2 , minimized at t = 0 . Thus A + b = ( 1 , 1 ) T , the shortest solution. These are distinct decisions: least squares minimizes residual first; minimum norm breaks ties between residual minimizers.

A minimum-norm answer is a mathematical convention based on the Euclidean metric, not automatic proof of physical appropriateness. If variables have different units, costs, or prior plausibility, rescaling, constraints, or regularization may be needed. The pseudoinverse gives a precise baseline whose assumptions can be inspected.

Conditioning: weak singular directions amplify uncertainty

For invertible square A , the largest stretch is σ max and the largest stretch of A − 1 is 1 / σ min . Therefore

κ 2 ( A ) = ‖ A ‖ 2 ‖ A − 1 ‖ 2 = σ max σ min .

A rank-deficient matrix has zero smallest singular value and infinite ordinary condition number. The same ratio of largest to smallest positive singular value describes the conditioning on the nonzero subspace for full-rank rectangular problems. Geometrically this is the long-axis to short-axis ratio of the ellipsoid: a nearly spherical image is well-conditioned, a very thin pancake is sensitive, and a flattened dimension is noninvertible.

A large condition number says that small perturbations in data can create large changes in a recovered solution. It does not say every particular residual is large. A solve can fit the supplied measurements with a tiny residual while its coefficients remain highly sensitive to a small measurement perturbation. Residual error and solution sensitivity are different quantities. Condition numbers also depend on units and parameterization: scaling one input variable changes the numerical singular spectrum, so sensible nondimensionalization may be important.

Because the eigenvalues of A T A are squared singular values, its condition number is the square of A ’s. This is another way to understand why the Gram-matrix route is risky in floating-point arithmetic. The identity is explanatory; robust numerical routines should avoid constructing the Gram matrix as a shortcut when small singular values matter.

Low-rank approximation and why the largest directions win

Expanding the factorization by columns gives

A = ∑ i = 1 r σ i u i v i T .

Each summand is rank one. Acting on x , it first measures the component v i T x , scales it by σ i , and emits it along u i . A matrix is therefore a sum of independent rank-one input-output channels. Keeping the first k terms creates A k = ∑ i = 1 k σ i u i v i T = U k Σ k V k T , with rank at most k . This is useful for compression when k is much smaller than both dimensions: dense storage costs m n values, while the factors cost approximately m k + k + n k values.

The Eckart–Young result says that this truncation is not merely plausible: it is a best rank- k approximation under two important norms. In spectral norm,

min rank ( B ) ≤ k ‖ A − B ‖ 2 = σ k + 1 ,

and in Frobenius norm,

‖ A − A k ‖ F 2 = ∑ i = k + 1 r σ i 2 .

The spectral error is the strongest discarded channel; the Frobenius error combines squared energy across all discarded channels. Here is the dimension argument for the spectral lower bound. For k < r and any B with rank ( B ) ≤ k , its null space has dimension at least n − k . If k ≥ r , the truncated approximation is exact and both lower bounds are zero. The span S = span ( v 1 , … , v k + 1 ) has dimension k + 1 , so S ∩ Null ( B ) contains a nonzero vector. Normalize one to x . Then B x = 0 , while x ∈ S implies ‖ A x ‖ 2 ≥ σ k + 1 ; hence ‖ A − B ‖ 2 ≥ ‖ ( A − B ) x ‖ 2 = ‖ A x ‖ 2 ≥ σ k + 1 . Truncation attains this bound.

For the Frobenius lower bound, choose an orthonormal matrix W ∈ R n × ( n − k ) whose columns lie in Null ( B ) . Then ( A − B ) W = A W . Multiplication by an orthonormal-column matrix cannot increase Frobenius norm, so ‖ A − B ‖ F 2 ≥ ‖ A W ‖ F 2 = tr ( W T A T A W ) . In right-singular coordinates, this trace is ∑ i σ i 2 w i , where w i is the squared length of row i of V T W . Because V T W has orthonormal columns, 0 ≤ w i ≤ 1 and ∑ i w i = n − k . The smallest weighted sum assigns weight one to the n − k smallest values of σ i 2 and zero to the others, giving at least ∑ i = k + 1 r σ i 2 (pad with zeros when m < n ). The truncated SVD attains this Frobenius bound too.

The guarantee is tied to the chosen matrix norm and low-rank objective. It does not promise best perceptual quality, best downstream rendering, or best prediction accuracy. A domain-specific weighting can change which directions matter. Frobenius energy retained after k components is ∑ i = 1 k σ i 2 / ∑ i σ i 2 , a common summary for PCA or compression, but that ratio is not a universal quality score.

Thresholding and regularization are different choices

A rank-based truncation keeps exactly k leading singular values. An absolute cutoff retains values above τ ; a relative cutoff can retain values satisfying σ i / σ 1 > τ . These choices answer different questions. A fixed rank can meet a storage budget. A scale-relative threshold can mark directions too weak relative to the dominant one. A noise model may imply a different cutoff. Numerical rank is never solely a property of a floating-point array without a precision and tolerance policy.

Truncated SVD pseudoinversion sets weak reciprocals to zero. This removes unstable directions completely: it reduces noise amplification but introduces bias and may increase the original residual because omitted positive directions are no longer used. Smooth regularization uses a different filter. For example, Tikhonov/ridge regularization solves a penalized problem min x ‖ A x − b ‖ 2 2 + λ 2 ‖ x ‖ 2 2 . In singular coordinates its coefficient filter is σ i / ( σ i 2 + λ 2 ) applied to c i , rather than either 1 / σ i or a hard zero/reciprocal switch. Small directions are damped continuously instead of abruptly discarded. Both methods express a preference for stability over exact inversion of weakly observed information, but they encode different assumptions and objectives.

For SVD compression, truncating small values approximates the matrix itself. For solving inverse problems, truncating singular values modifies how measurements map back to parameters. Those operations share a spectrum but are not the same task. State whether the goal is best rank- k approximation, a numerical-rank solve, or a regularized inverse before interpreting a cutoff.

SVD in a graphics sensitivity picture

A local graphics transform or Jacobian maps small perturbations δ x to δ y = A δ x . SVD tells which input perturbations are amplified, which are suppressed, and in which output directions the effect appears. A small input sphere becomes an ellipsoid. The v i axes are sensitive input directions, σ i are gains, and u i axes show the response directions. This interpretation applies to deformation gradients, inverse problems, camera sensitivity, mesh processing, optimization Jacobians, covariance analysis, and shape variation.

The singular basis also explains why SVD connects so many topics. Rank counts surviving channels. Nullity counts erased input channels. The row and column spaces are the input and output spans of surviving directions. Pseudoinversion reverses surviving channels. Least squares projects onto reachable outputs. Minimum norm removes arbitrary nullspace components. Conditioning compares the strongest and weakest channels. Low-rank approximation discards selected channels under a stated error measure. Each concept is a different question about the same geometry, so the equations, data, and implementation can be checked against one another.

Why the pseudoinverse identities follow from projections

The four Moore–Penrose relations become almost mechanical in compact SVD coordinates. Let A = U r Σ r V r T with all entries of the square Σ r positive, and let A + = V r Σ r − 1 U r T . Then

A A + = U r U r T , A + A = V r V r T .

These are symmetric idempotent matrices because U r T U r = I r and V r T V r = I r . They project onto the column and row spaces. Applying A A + to A keeps every column-space component, so A A + A = A . Applying A + A to A + keeps every row-space component, so A + A A + = A + . Symmetry gives the remaining two identities. This derivation shows what the properties guarantee: the operator behaves like an inverse on the rank- r subspaces and like zero on orthogonal complements. For a full-column-rank tall matrix, A + A = I n ; for a full-row-rank wide matrix, A A + = I m . In the opposite products, the identity is only a projection unless the map is square and invertible.

This is also a useful dimensional check. With A : m × n , its pseudoinverse is n × m , so A A + is m × m and acts on outputs, while A + A is n × n and acts on inputs. Accidentally reversing U and V can produce products with plausible square shapes while projecting onto the wrong space; naming each factor’s domain and codomain catches that error.

PCA turns a cloud of points into measured variation

Principal component analysis begins with data, not with a mysterious covariance matrix. Put N samples in the rows of a data table X ∈ R N × d . Compute each feature mean and subtract it from every sample. Without centering, the dominant direction may point toward the cloud’s offset from the origin instead of along the cloud’s variation.

For centered X , sample covariance is

C = 1 N − 1 X T X .

The divisor may be N in a population convention; state which convention you use. For a unit direction v , the projected scores are X v and their sample variance is v T C v . Maximizing this quadratic form under ‖ v ‖ 2 = 1 gives an eigenvector of C for the largest eigenvalue. Requiring the next component to be orthogonal gives the next eigenvector. Eigenvalues are variances along those principal directions.

There is a direct SVD route. If X = U Σ V T , the columns of V are principal directions and the scores are X V = U Σ . Covariance eigenvalues are σ i 2 / ( N − 1 ) . This avoids explicitly forming X T X , which can improve numerical behavior for data with a wide range of scales. PCA is not automatically scale invariant: changing units of one feature changes its variance and therefore its influence. Standardization is a separate modeling decision that changes the question.

For graphics, PCA can estimate a point-cloud plane: the eigenvector for the smallest covariance eigenvalue is a candidate normal, while the other two span the best-fit plane. If the cloud is nearly a line, two small eigenvalues make the plane normal ambiguous. If the eigenvalues are close, small perturbations can rotate individual principal axes substantially even while the subspace remains stable. A useful application should reason about the eigengap and the subspace, not just print three axes.

For a minimal worked cloud, take centered samples ( − 1 , 0 ) , ( 0 , 0 ) , ( 1 , 0 ) . With divisor N − 1 = 2 , the covariance is diag ( 1 , 0 ) . The first principal direction is horizontal and carries variance one; the perpendicular direction carries zero variance. If small vertical noise is added, the second eigenvalue becomes small rather than exactly zero. Whether it is treated as signal or discarded is a modeling decision supported by noise scale, not an algebraic truth hidden in the word “PCA.”

Centered measurements reveal principal directions

Principal component analysis (PCA) asks a geometric question about a cloud of samples: along which directions does it vary most, second most, and so on? Let there be N samples with d measured features. Use the row-sample convention X ∈ R N × d , so row i is x i T . Samples must be finite. The sample-covariance path requires N ≥ 2 : reject empty input because the mean is undefined and reject a singleton as insufficient for an unbiased sample covariance. An API may instead explicitly choose population covariance with divisor N ; that permits N = 1 and returns zero covariance, but still must define empty-input behavior. The mean is μ = 1 N ∑ i = 1 N x i . Center each sample, x ~ i = x i − μ , and place those rows in X c . Centering ensures ∑ i x ~ i = 0 . This removes translation: a cloud shifted far from the origin has the same shape and variation after centering. Without centering, the offset itself can dominate squared coordinates, causing the first component to describe location instead of spread.

A direction must be normalized before comparing its variance with another direction. For unit v ∈ R d , the scalar coordinate of centered sample i along that direction is z i = v T x ~ i . Its sample variance, using the sample convention N − 1 , is

Var ( z ) = 1 N − 1 ∑ i ( v T x ~ i ) 2 = v T ( 1 N − 1 ∑ i x ~ i x ~ i T ) v .

The bracketed matrix is the covariance C = X c T X c / ( N − 1 ) . Thus variance in unit direction v is the Rayleigh quotient v T C v . Maximizing this subject to v T v = 1 gives an eigenvector of C for its largest eigenvalue: use a Lagrange multiplier on v T C v − λ ( v T v − 1 ) to obtain C v = λ v . The largest eigenvalue is the greatest attainable variance. The second component maximizes variance subject to perpendicularity to the first; continuing gives orthonormal eigenvectors of the symmetric covariance. Eigenvalues are variances along those axes.

For a direct computation, consider the centered 2D samples ( 1 , 1 ) , ( − 1 , − 1 ) , ( 1 , − 1 ) , and ( − 1 , 1 ) . Their sample mean is zero. Summing outer products gives X c T X c = [ 4 0 0 4 ] , so with divisor N − 1 = 3 , C = 4 3 I . Every direction has the same variance and no unique principal axis exists: the two eigenvalues are repeated. If the second coordinates are instead ( 0.5 , − 0.5 , − 0.5 , 0.5 ) , the sum of outer products is [ 4 0 0 1 ] and covariance is diag ( 4 / 3 , 1 / 3 ) . The horizontal axis carries four times the variance of the vertical. These calculations make the meaning of the eigenvalues concrete and show why equal or close eigenvalues make individual axes ambiguous.

The covariance entry C j k measures co-variation between features j and k . Diagonal entries are individual feature variances; positive off-diagonal entries mean deviations tend to have the same sign, while negative values mean opposite signs. These terms are coordinate coupling. If C = Q Λ Q T and transformed sample coordinates are y = Q T ( x − μ ) , then their covariance is Q T C Q = Λ . The eigenbasis removes cross-covariance because all off-diagonal coupling vanishes in those coordinates. Covariance is positive semidefinite: for any v , v T C v = 1 N − 1 ∑ i ( v T x ~ i ) 2 ≥ 0 . A zero eigenvalue therefore means there is no measured variation along its eigenvector. If points lie in a plane in 3D, the normal direction has zero variance; the two large-eigenvalue directions span the best-fit plane. With noise, the smallest-eigenvalue eigenvector remains the least-variance normal estimate, and its reliability depends on the gap between that small eigenvalue and the next one.

PCA can instead use a singular value decomposition (SVD) of the centered data, X c = U Σ V T . Substitute this into covariance:

C = X c T X c N − 1 = V Σ T Σ N − 1 V T .

Because U T U = I , the right singular vectors (columns of V ) are covariance eigenvectors, and covariance eigenvalues are λ i = σ i 2 / ( N − 1 ) . Keeping the first k directions in V k , the principal scores are Z = X c V k = U k Σ k . An approximate reconstruction is X ^ = Z V k T + 1 μ T , where the mean is added back to every row. By the Eckart–Young theorem this is the best rank- k approximation in Frobenius norm. A point-cloud plane fit is the same recipe: subtract the centroid, form a 3-by-3 covariance or use data SVD, then take the eigenvector of that covariance, equivalently the right singular vector of the centered N × 3 sample matrix, associated with its smallest eigenvalue/singular value as the normal. Left singular vectors live in sample space R N , so they are not the 3D feature-space normal. A thin, noisy, or nearly collinear cloud may not determine a stable plane; the eigengap and noise level matter.

Feature units alter the result. If one coordinate is in millimeters and another in meters, a numerical rescaling changes covariance and therefore PCA. Standardizing each feature by a scale produces correlation-based PCA and asks a different question: relative variation after unit normalization instead of absolute physical variance. Neither convention is automatically correct. Record whether the data was centered only, centered and standardized, or weighted, since the output axes depend on that modeling decision.

Plane fits, eigengaps, and interpretation of uncertain components

For centered 3D points x i − μ , a plane through the centroid with unit normal n has signed residual distance d i = n T ( x i − μ ) . The sum of squared distances is ∑ i d i 2 = ( N − 1 ) n T C n . Minimizing it under ‖ n ‖ = 1 selects the eigenvector for the smallest covariance eigenvalue. This is the same direction that PCA describes as having the least variance. The two other eigenvectors span the fitted plane. For example, a flat tabletop cloud might have covariance eigenvalues 0.9 , 0.4 , 0.0002 : the last direction is a clear normal candidate. If instead they are 0.9 , 0.4 , 0.39 , the two low directions are close, and the estimated normal is sensitive to small noise; there is no strong evidence separating one normal from another within that plane-like subspace. Eigenvalue magnitudes tell variance, while the gap measures axis identifiability. Reporting a normal without examining this gap can give false confidence.

The sample divisor is a convention with consequences. The unbiased sample covariance estimator uses N − 1 when the mean is estimated from the same samples; population covariance uses N . This changes eigenvalues and score variance by a scalar factor but does not change eigenvectors when all features share the same divisor. Weights also change the geometric question: a weighted covariance gives more influence to selected observations. For large data, a streaming mean and covariance algorithm can avoid storing every sample, but the same centered-data interpretation still applies. If the stored matrix is rows=features rather than rows=samples, transpose formulas accordingly; writing the shape next to each product prevents accidental computation of X X T when the intended feature covariance is X T X .

Polar decomposition separates rotation-like motion from stretch

SVD also gives the polar decomposition of a real square matrix:

A = Q H , H = ( A T A ) 1 / 2 ,

where H is positive semidefinite and Q is orthogonal when A is nonsingular. For singular A , an orthogonal completion may not be unique. This is the right polar form: first apply stretch H , then orthogonal motion Q under column-vector composition. A left polar form A = H L Q uses H L = ( A A T ) 1 / 2 .

The symmetric stretch can include shear in the original basis; “symmetric” does not mean “diagonal scale in the current coordinates.” If det A < 0 , the orthogonal factor may include a reflection. It is therefore not always a pure rotation in S O ( n ) . This distinction matters in graphics where a mirrored transform changes handedness and normal orientation.

In an SVD, H = V Σ V T and Q = U V T for the nonsingular case. This makes polar decomposition a concise way to ask: what orthogonal part and what symmetric stretch combine to produce this deformation? For a deformation gradient, it separates the local rigid-like motion from strain-like change, though the exact interpretation depends on the physical model and frame.

Polar decomposition separates frame dependent stretch from orientation

The polar decomposition separates a linear map into an orthogonal factor and a symmetric positive-semidefinite stretch. For square A , the right polar form is A = R S , where R is orthogonal and S is the right stretch. For rectangular maps the analogous orthogonal factor is a partial isometry, not a square orthogonal matrix; the square case is the one used for rotation extraction below. If A is square and invertible, derive S by multiplying the equation by its transpose: A T A = ( R S ) T ( R S ) = S T R T R S = S 2 , since S = S T and R T R = I . The positive-semidefinite square root is therefore S = ( A T A ) 1 / 2 , and then R = A S − 1 . The symmetric stretch has orthonormal principal axes: in its eigenbasis it scales each axis by a nonnegative amount, without a net rotation. The orthogonal factor carries the remaining orientation, including a possible reflection.

There is also a left polar form A = P R with P = ( A A T ) 1 / 2 . The right stretch is measured in the input or material frame; the left stretch is measured in the output or spatial frame. They are generally different matrices because the frames differ. For a concrete check, let S = diag ( 2 , 0.5 ) and let R be a 30-degree rotation. Then R S = [ 3 − 0.25 1 3 / 4 ] : the first coordinate is stretched by 2 and the second by one half in the principal frame, then the result is rotated. A shear can also have a nonidentity polar orthogonal factor: although the matrix is described as a shear, it changes the orientation of vectors, and polar decomposition assigns part of that change to the best orthogonal component. In deformation gradients, this split lets a model remove rigid rotation before measuring elastic strain.

From SVD, A = U Σ V T , regroup factors as A = ( U V T ) ( V Σ V T ) . Hence R = U V T and S = V Σ V T . The first is orthogonal; the second is symmetric PSD. Also A T A = V Σ 2 V T , so its positive square root is exactly V Σ V T . The analogous left stretch is P = U Σ U T , yielding A = P R . For nonsingular square A , the right polar orthogonal factor is unique. In singular directions, A collapses vectors to zero, so its action cannot determine how an orthogonal factor should map those unobserved directions; completions can differ while the product remains valid.

An orthogonal matrix has determinant either + 1 or − 1 . Only determinant + 1 belongs to S O ( n ) , the group of proper rotations. If U V T has determinant − 1 , it includes a reflection. Applications that require a proper rotation, such as rigid pose alignment, need an explicit nearest- S O ( n ) rule, commonly a sign correction on a singular direction with smallest singular value; this changes the optimality problem to constrain orientation and must be stated. In this determinant-correction case, if the least singular value is repeated, multiple choices tie and the nearest proper rotation is nonunique; a zero least singular value also permits freedom in its null direction. Repeated singular values alone do not make the nearest proper rotation nonunique when no determinant correction is needed. Never label every orthogonal factor “rotation” without checking determinant.

Two-sided rotations, nearest proper rotation, and nonunique directions

Two-sided Jacobi can be understood by looking at a local 2 × 2 block D . First choose a right rotation J R that diagonalizes D T D ; this makes the two columns of D J R orthogonal. Then choose a left rotation J L that aligns those perpendicular columns with coordinate axes, equivalently diagonalizing ( D J R ) ( D J R ) T . The updated local block J L T D J R is diagonal up to signs. Embedded in the full identity, these rotations act on selected column and row pairs. The right transformations accumulate into V and the left transformations into U . A sweep repeats across pairs. This local 2-by-2 SVD view explains both sides of the algorithm: right rotations remove input-direction coupling; left rotations align the corresponding output directions. Unlike one-sided Jacobi, the working matrix itself is driven toward diagonal form rather than merely toward mutually orthogonal columns.

For a square nonsingular matrix, the orthogonal polar factor R = U V T is the closest orthogonal matrix to A in Frobenius norm. To see why, for any orthogonal W , expand ‖ A − W ‖ F 2 = ‖ A ‖ F 2 + ‖ W ‖ F 2 − 2 tr ( W T A ) . The first two terms do not depend on W , so minimizing distance maximizes tr ( W T A ) . Substitute A = U Σ V T and let Z = U T W V , also orthogonal. Then the trace is tr ( Z T Σ ) = ∑ i σ i z i i ≤ ∑ i σ i , because each diagonal entry of an orthogonal matrix is at most one. Equality is attained by Z = I , giving W = U V T .

If the requirement is a proper rotation with determinant + 1 , then when det ( U V T ) = − 1 one must force det Z = − 1 . The best trace is then obtained by assigning the required sign reversal to a direction with smallest singular value. With singular values in descending order, let D = diag ( 1 , … , 1 , det ( U V T ) ) ; the constrained minimizer is R S O = U D V T . Its stretch/error cost reflects the smallest direction. In this determinant-correction case, a repeated least singular value gives tied sign-reversal directions and a nonunique nearest proper rotation; a zero least singular value permits freedom in its null direction. Repeated singular values alone do not imply nonuniqueness when U V T already has determinant + 1 . This is a constrained Procrustes choice, not the same unconstrained polar orthogonal factor when that factor reflects.

How numerical software computes and checks an SVD

Reliable SVD algorithms do not usually diagonalize A T A directly. A common route first uses Householder transformations to reduce a dense matrix to bidiagonal form: nonzeros remain only on the main diagonal and one neighboring diagonal. These orthogonal transformations preserve singular values while concentrating the work into a simpler structure. Golub–Kahan bidiagonalization names this reduction process; it should not be confused with every later iterative bidiagonal solver.

Jacobi SVD methods repeatedly rotate column pairs toward orthogonality. In one-sided Jacobi, the working matrix columns are orthogonalized directly and their norms become singular values; the accumulated rotations build right singular vectors. This can provide excellent relative accuracy for small singular values, but sweep counts and stopping tests must be explicit. A maximum sweep count is essential: failure to converge is an outcome to return, not a loop to hide.

After computation, sort singular values in descending order and permute corresponding columns of U and V together. Choose a sign convention only for presentation consistency; no sign convention removes the nonuniqueness of repeated singular subspaces. Temporal applications may need to align signs or subspaces between frames to avoid visually jumping axes.

Validation checks reconstruction and orthogonality. For a computed A ≈ U Σ V T , use a scaled residual such as

‖ A − U Σ V T ‖ F max ( ‖ A ‖ F , safe scale ) ,

and check ‖ U T U − I ‖ and ‖ V T V − I ‖ with dimensions appropriate to full or thin output. A zero input needs a defined denominator policy. Checking only column lengths is insufficient: columns can each have unit length and still fail to be mutually perpendicular. Reconstruction alone is also insufficient if factors are nonorthogonal but happen to multiply to a close matrix. Both classes of invariant matter.
