LU factorization and reusable solves

LU stores elimination as triangular factors. With row pivoting in this vault’s convention, P A = L U ; apply the same permutation to each right-hand side, then solve one lower- and one upper-triangular system. Factorization cost is amortized across repeated solves.

Use it when: solving square general systems, especially with multiple right-hand sides.

Developed in Phase 8: The multipliers used to eliminate entries become the lower factor, while the remaining upper triangle records the reduced system; with row exchanges the convention is P A = L U .
