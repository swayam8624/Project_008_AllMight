Recall question: How do boundary conditions change the modes available to a discrete heat problem?

Heat on a rod: why boundaries, modes, and mesh operators belong together

Take a straight metal rod of length L . Its sides are insulated, its ends are held at prescribed temperatures, and someone briefly warms one small region near the middle. The temperature field u ( x , t ) changes smoothly: the hot spot spreads and its peak falls. We want a model that tells us how the end conditions affect that spreading, how a triangle mesh can approximate it on a curved surface, and what numerical evidence would show that our computation is behaving as intended.

For a uniform rod with no internal heat source, the one-dimensional heat equation is

∂ u ∂ t = κ ∂ 2 u ∂ x 2 , 0 < x < L ,

where u is temperature and κ is thermal diffusivity. For a material with conductivity k , density ρ and specific heat capacity c , κ = k / ( ρ c ) . Conductivity is measured in watts per metre per kelvin, volumetric heat capacity in joules per cubic metre per kelvin, so κ has units m 2 / s . The second spatial derivative has units temperature per square metre; multiplying by diffusivity gives temperature per second, as required by the left side.

The differential equation describes the interior. It does not specify what the ends do. Those conditions are part of the model, because they determine which temperature patterns can persist and which can appear as independent modes. A simulation without its boundary conditions is an incomplete physical problem.

Boundary conditions choose the modes

First hold both ends at a reference temperature and subtract that reference so the boundary values are zero: u ( 0 , t ) = u ( L , t ) = 0 . Seek one separable solution u ( x , t ) = X ( x ) T ( t ) . Substitution gives

X T ′ = κ X ″ T ⟹ 1 κ T ′ T = X ″ X .

The left side depends only on time; the right side depends only on position. For the equality to hold for every x and t , each side must equal one constant. Choose it to be − λ so that the spatial solutions can be oscillatory while the time solutions decay:

X ″ + λ X = 0 , T ′ + κ λ T = 0.

The general spatial solution for λ = μ 2 > 0 is X = A cos ⁡ ( μ x ) + B sin ⁡ ( μ x ) . The boundary at x = 0 forces A = 0 ; the boundary at x = L then requires sin ⁡ ( μ L ) = 0 . Nonzero solutions exist only when μ L = n π for positive integer n . Thus the allowed eigenvalues and eigenfunctions are

λ n = ( n π L ) 2 , X n ( x ) = sin ⁡ ( n π x L ) , n = 1 , 2 , …

and the matching time factor is T n ( t ) = e − κ λ n t . A boundary condition has turned a continuum of possible spatial frequencies into a discrete family. The first mode has one broad arch; higher modes have more zero crossings and shorter wavelengths. Their decay rate grows like n 2 : fine ripples disappear much faster than broad temperature differences.

The rod’s initial temperature f ( x ) = u ( x , 0 ) is expanded in this sine family:

f ( x ) = ∑ n = 1 ∞ b n sin ⁡ ( n π x L ) , b n = 2 L ∫ 0 L f ( x ) sin ⁡ ( n π x L ) d x .

Orthogonality makes this projection possible: the integral of the product of two different sine modes over [ 0 , L ] is zero, while the squared norm of each mode is L / 2 . By linearity, the complete solution is

u ( x , t ) = ∑ n = 1 ∞ b n sin ⁡ ( n π x L ) e − κ ( n π / L ) 2 t .

Each term solves the same PDE and boundary conditions; adding solutions remains a solution because the equation is linear. The coefficients encode the initial pattern; the boundary-selected modes and exponential factors encode how it evolves. The series is not merely a symbolic trick: it says every resolved initial pattern is a weighted sum of independently decaying shapes.

Other endpoint physics changes the spectrum. If the ends are insulated, there is no heat flux through them, so u x ( 0 , t ) = u x ( L , t ) = 0 . The spatial modes become X n ( x ) = cos ⁡ ( n π x / L ) for n = 0 , 1 , 2 , … , including a constant mode. That zero mode does not decay: in an insulated rod the average temperature stays fixed. If one end is held at zero and the other insulated, the eigenfunctions are shifted half-wave patterns such as sin ⁡ ( ( n + 1 / 2 ) π x / L ) . Robin conditions, which model heat exchange with a surrounding medium, lead to a different eigenvalue equation. Boundary conditions therefore define the operator and its modes together.

The zero mode is not an annoying exception. It carries the conserved average under no-flux conditions. For a uniform rod, integrating the heat equation gives

d d t ∫ 0 L u ( x , t ) d x = κ ∫ 0 L u x x ( x , t ) d x = κ [ u x ( L , t ) − u x ( 0 , t ) ] .

Insulated endpoints make the right side zero. The rod redistributes heat internally, but its total excess heat—and, for constant heat capacity and cross-section, its spatial average—does not change. Fixed-temperature ends can exchange heat with their reservoirs, so that same integral need not be conserved.

Derivatives act on modes by multiplying their frequency

Why are sine waves so useful? Differentiation does not create a new spatial frequency. For a complex wave e i k x ,

d d x e i k x = i k e i k x , d 2 d x 2 e i k x = − k 2 e i k x .

A derivative is therefore multiplication by i k in the frequency representation, and the second derivative is multiplication by − k 2 . For finite-interval Dirichlet modes, differentiating the sine once gives a cosine, then twice returns the original sine with multiplier − ( n π / L ) 2 . That is exactly the spatial eigenvalue relation X n ″ = − λ n X n . The heat equation consequently becomes a separate scalar decay equation for every mode: a ˙ n = − κ λ n a n .

This makes the “high frequencies decay faster” statement precise. If the initial temperature contains only a low mode and a high mode, after elapsed time t their amplitudes are multiplied by e − κ k 2 t . When the high mode has four times the wavenumber, it has sixteen times the decay exponent. Smoothing is thus a low-pass operation. It removes oscillations because second derivatives penalize rapid spatial variation.

A Fourier series describes periodic patterns; a sine expansion on [ 0 , L ] can be understood by extending a function oddly outside the interval and then periodically. A cosine expansion corresponds to an even extension. The chosen extension matters at the endpoints. If the interior initial temperature does not agree with the fixed end values at t = 0 , the odd periodic extension has a jump. The series still represents the interior in a limiting sense, but convergence near that jump oscillates. This is one way that boundary assumptions show up as ringing rather than disappearing behind the algebra.

From a mesh Laplacian to a heat operator

The mesh-topology spine introduced a cotangent Laplacian for vertex values. We can now give it a clear evolution meaning. Let u i ( t ) be a temperature stored at mesh vertex i . Build a stiffness matrix S from the surface geometry and a mass matrix M from the areas represented by the vertices. For a common cotangent convention, each interior edge ( i , j ) has weight w i j = 1 2 ( cot ⁡ α i j + cot ⁡ β i j ) . Set S i j = − w i j off the diagonal and choose S i i = ∑ j ≠ i w i j . Then S is symmetric and, for a suitable mesh, positive semidefinite. A lumped mass matrix is diagonal with M i i = A i , a local area; a consistent finite-element mass matrix can include off-diagonal terms.

With this positive stiffness convention, the discrete heat equation is

M u ˙ = − κ S u .

If the previous mesh note uses Δ = − M − 1 S , this is the same statement u ˙ = κ Δ u . Signs vary across libraries, so test the constant field and a known mode before wiring a new matrix into an update. For a constant vector 1 , every edge difference vanishes, giving S 1 = 0 when there is no imposed-temperature boundary. Thus an isolated closed surface or natural no-flux boundary has a zero mode, just like the insulated rod.

The mass matrix is not bookkeeping overhead. It turns an integrated stiffness balance into a rate per unit area or length. On a triangulated surface, M has units square metres and cotangent entries in S are dimensionless; therefore M − 1 S has units inverse square metres. Multiplying by surface diffusivity κ in square metres per second gives a rate in inverse seconds. In a one-dimensional finite-element rod, the mass entries instead have units metres and the stiffness entries have units inverse metres, so M − 1 S still has units inverse square metres. The matrix dimensions depend on the domain dimension, but the discrete operator approximating a second spatial derivative always carries inverse-length-squared units.

Under a coordinate scaling by factor s , areas on a surface scale as s 2 while cotangent weights are invariant. Thus M − 1 S scales as s − 2 . The diffusivity must be expressed in the same physical length units as the geometry. A mesh stored in millimetres paired with κ in square metres per second is inconsistent until one representation is converted. Dimensional checks catch this error even when every number in the code looks plausible.

The generalized eigenproblem

S ϕ n = λ n M ϕ n

is the mesh counterpart of the rod’s spatial mode equation. Its eigenvectors are discrete temperature patterns; its eigenvalues measure how rapidly each pattern bends across the surface. The evolution of a mode amplitude is a n ( t ) = a n ( 0 ) e − κ λ n t . Because S is symmetric and M is positive definite, these modes can be chosen orthogonal in the mass-weighted inner product ⟨ u , v ⟩ M = u T M v . This is the finite-dimensional version of the orthogonality that made the sine-series coefficients independent.

Explicit steps have a mesh-dependent stability limit

For the standard centered second difference on a uniform 1D grid with spacing h , an interior value has discrete Laplacian

( L h u ) j = u j − 1 − 2 u j + u j + 1 h 2 .

Dirichlet endpoints are held fixed; consider the unknown interior values. A discrete sine mode u j = sin ⁡ ( k π j / ( N + 1 ) ) , with h = L / ( N + 1 ) , is an eigenvector of L h with eigenvalue

μ k = − 4 h 2 sin 2 ⁡ ( k π 2 ( N + 1 ) ) .

The magnitude is largest for the most rapidly alternating grid pattern and approaches 4 / h 2 . Forward Euler updates u n + 1 = u n + κ Δ t L h u n . A mode is multiplied each step by g k = 1 + κ Δ t μ k . For no growth in magnitude we need | g k | ≤ 1 for every mode. The most restrictive eigenvalue gives

0 ≤ κ Δ t h 2 ≤ 1 2 , or Δ t ≤ h 2 2 κ .

This is a stability bound for the stated standard 1D grid and explicit forward Euler scheme. It is not a universal bound for every mesh, boundary condition, or time integrator. In an unstructured mesh, use the largest eigenvalue of the mass-normalized stiffness operator or a proven bound for the chosen discretization; the spectral scale still behaves like inverse length squared.

A numerical witness makes the instability visible. Let h = 0.25 m and κ = 0.1 m 2 / s . The limit is 0.25 2 / ( 2 ⋅ 0.1 ) = 0.3125 s . If we take Δ t = 0.375 s , then r = κ Δ t / h 2 = 0.6 . For a unit-length rod with three interior vertices, the highest Dirichlet mode has g = 1 − 4 ( 0.6 ) sin 2 ⁡ ( 3 π / 8 ) ≈ − 1.048528 . Its sign flips and its magnitude grows by about 4.85 % per step. On an even periodic grid, the exact alternating mode instead has g = 1 − 4 r = − 1.4 , giving 40 % growth. Distinguish the finite-boundary eigenvalue from this limiting or periodic case. At the threshold r = 0.5 , that limiting mode has amplification − 1 : it does not grow, but it is not damped and remains a poor practical choice near the stability edge.

Implicit Euler uses the new-time temperature in the Laplacian:

u n + 1 − u n Δ t = − κ M − 1 S u n + 1 , ( M + κ Δ t S ) u n + 1 = M u n .

For a generalized eigenmode with λ n ≥ 0 , its amplification is 1 / ( 1 + κ Δ t λ n ) , which lies between zero and one for any positive step. This gives unconditional linear stability for diffusion with a positive semidefinite stiffness and positive mass matrix. It requires a linear solve, and a large step can still erase detail or be inaccurate even though it does not blow up. Stability and fidelity are different questions.

On a 2D mesh with area mass matrix, the explicit stability limit is controlled by a largest eigenvalue of order 1 / h 2 , where h is a representative edge length. Refining edge length by two can therefore require roughly four times as many explicit steps for the same simulated duration. This cost is one reason implicit diffusion is attractive in geometry processing. It does not follow that every mesh flow should be implicit: intended feature behavior, accuracy, solver conditioning and cost still matter.

A Green function is an impulse response

A Green function answers a concrete experiment: what field is produced by a unit point source, subject to the same boundaries as the original problem? For a linear operator L with homogeneous boundary conditions, define G ( x , ξ ) by

L x G ( x , ξ ) = δ ( x − ξ ) ,

where the subscript reminds us that L differentiates in the observation coordinate x . A distributed source f ( ξ ) is a superposition of point sources, so the solution is

u ( x ) = ∫ G ( x , ξ ) f ( ξ ) d ξ .

For time-dependent heat flow, the impulse response depends on elapsed time. With the rod’s normalized Dirichlet eigenfunctions ϕ n ( x ) = 2 / L sin ⁡ ( n π x / L ) , the heat kernel is

H D ( x , ξ , t ) = ∑ n = 1 ∞ ϕ n ( x ) ϕ n ( ξ ) e − κ ( n π / L ) 2 t , t > 0.

A point of heat inserted at ξ spreads according to H D ; an initial field evolves as u ( x , t ) = ∫ 0 L H D ( x , ξ , t ) u ( ξ , 0 ) d ξ . A time-varying source s ( ξ , τ ) contributes through a space-time convolution, integrating H D ( x , ξ , t − τ ) s ( ξ , τ ) over earlier times τ and source positions ξ . This is the continuous analogue of repeatedly applying a linear diffusion update to source inputs.

The kernel is symmetric in x and ξ for a self-adjoint diffusion operator with the same homogeneous boundary conditions on both arguments. In the rod case this follows term by term because each factor is ϕ n ( x ) ϕ n ( ξ ) . More generally, Green-function reciprocity follows from self-adjointness and the boundary terms vanishing under the chosen domain and boundary conditions. If coefficients, boundary conditions, or the operator make the problem non-self-adjoint, do not assume G ( x , ξ ) = G ( ξ , x ) . For a weighted Sturm–Liouville problem, symmetry may be with respect to the appropriate weighted inner product or measure rather than plain coordinate integration.

There is a subtle zero-mode case. With insulated boundaries, the Laplacian has a constant eigenfunction with eigenvalue zero. The steady Poisson equation − u x x = f with pure Neumann conditions cannot have a solution for arbitrary nonzero-mean f : integrating both sides shows the source must satisfy the net-flux compatibility condition. Even when compatible, the solution is defined only up to an added constant until a mean or reference value is fixed. The transient heat kernel remains meaningful; the zero mode simply preserves the average instead of decaying. A numerical inverse that silently divides by a zero eigenvalue is not a valid Green-function construction.

Sampling, truncation, and ringing

A continuous field becomes finite data only after sampling. On a regular 1D grid, the highest alternating mode is near the Nyquist frequency, roughly one half-cycle per sample spacing. Shorter wavelengths cannot be represented uniquely: they alias into lower-frequency patterns. On irregular triangle meshes there is no single global Nyquist number, but local edge length and element shape limit which oscillations are resolved. If the initial hot spot is narrower than the sampling scale, the mesh may miss its peak or encode it as a misleading pattern. Subsequent heat flow smooths the samples it received; it cannot reconstruct the lost sub-grid event.

A truncated Fourier or eigenfunction sum introduces another approximation. Keeping only the first N modes reconstructs the broad structure well when the field is smooth, but a sharp jump needs many modes. Near a discontinuity, partial sums can overshoot and oscillate (Gibbs behavior); increasing N narrows the affected region but does not remove the limiting overshoot at the jump. In heat flow, each mode is additionally multiplied by an exponential decay. At positive time, high-frequency terms are strongly damped, but at time zero the series must still represent the initial/boundary data correctly. If initial temperature and fixed endpoint temperatures disagree at a corner in space-time, a rapid boundary layer is physically implied, not a failure of the series method.

For a finite mesh, eigenvalue truncation and timestep are separate resolution controls. Dropping small-scale eigenvectors discards spatial detail; taking a large implicit-Euler step changes each mode’s decay relative to the continuous evolution (its factor 1 / ( 1 + x ) exceeds e − x for x > 0 ); taking an unstable explicit step amplifies the highest modes. A visually smooth result is not proof of accuracy because excessive smoothing can hide aliasing, poor mesh quality, or a wrong boundary condition. Report sample spacing, kept modes or timestep, and error against a known field when making a quantitative claim.

Manufactured fields make the solver testable

A manufactured solution gives an analytic answer for a problem with known boundaries and coefficients. For fixed-zero endpoints choose one sine mode

u ( x , t ) = A sin ⁡ ( π x L ) e − κ ( π / L ) 2 t .

It satisfies both the PDE and u ( 0 , t ) = u ( L , t ) = 0 . With L = 1 m , κ = 0.1 m 2 / s , A = 100 K and t = 1 s , the center temperature is

u ( L / 2 , 1 ) = 100 e − 0.1 π 2 K ≈ 37.27 K .

For a second, independently decaying mode at twice the wavenumber, the decay exponent is four times larger. A two-mode initial field tests that the solver handles superposition and does not accidentally mix modes in a uniform rod with homogeneous endpoints. Compare grid values to the analytic field at fixed physical times while halving h and reducing Δ t consistently; measure error rather than relying on a plot.

For a no-flux test choose

u ( x , t ) = 20 + 5 cos ⁡ ( π x L ) e − κ ( π / L ) 2 t .

Its derivative is zero at x = 0 and x = L , and its spatial mean is 20 at every time. A discrete solver should preserve the corresponding mass-weighted mean up to rounding and linear-solver tolerance. For fixed-temperature endpoints, instead measure boundary flux. Fourier’s law gives heat flux q = − k u x ; integrating the temperature equation yields the net heat change from inflow at one boundary minus outflow at the other. The rod’s interior energy need not be conserved when reservoirs hold its ends at fixed temperature.

On the mesh, the matching tests are: S 1 = 0 for a no-flux/closed setting; symmetry S = S T ; nonnegative generalized eigenvalues; exponential decay of each measured eigenmode at rate κ λ n ; and conservation of 1 T M u when no heat crosses the boundary and no source is present. For Dirichlet vertices fixed to a reservoir, remove or constrain those degrees of freedom and verify the change in total heat matches integrated boundary flux. A matrix can be symmetric and still have the wrong units, scale, boundary rows, or source signs, so keep the analytic rod and unit checks beside the structural matrix checks.

The rod story now carries through to a curved triangle mesh. Material and boundary conditions define a differential operator; its self-adjoint eigenmodes form a basis; spatial derivatives multiply modes by their squared frequencies; the mesh stiffness and mass matrices approximate that operator; and time integration advances its modes according to their decay rates. Green functions express how localized heat sources propagate under those same boundaries. Sampling and truncation set what detail can be represented, while manufactured solutions and flux balances tell us whether the computed field matches the stated model.

What the boundary means to the discrete solver

Boundary data must be encoded in the discrete unknowns and matrix, not merely displayed as a condition in a comment. With fixed-temperature Dirichlet endpoints, the endpoint values are known and are removed from the unknown vector or incorporated into the right-hand side. If a known endpoint value is nonzero, its neighboring stencil contains a source contribution proportional to that value. A common error is to drop the endpoint neighbor term when constructing the reduced matrix, thereby solving a different rod with an insulated or shortened boundary.

For an insulated endpoint, the Neumann condition u x = 0 says the normal heat flux vanishes. A finite-volume view writes heat balance in terms of fluxes through cell faces; the boundary face contributes zero flux. A finite-difference view can use a ghost value reflected across the endpoint, such as u − 1 = u 1 , so the centered derivative ( u 1 − u − 1 ) / ( 2 h ) is zero. Either construction should leave the constant vector in the nullspace and conserve the weighted sum. Dirichlet and Neumann are not interchangeable “edge handling” options: one couples the rod to a reservoir; the other isolates it.

For a curved mesh, an open boundary has an analogous choice. A natural finite-element boundary on the diffusion problem usually represents zero flux unless a boundary term is supplied. Pinning boundary temperatures imposes a Dirichlet constraint. A Robin boundary can represent transfer to an ambient temperature, with flux proportional to the difference between the surface temperature and ambient. If the application actually intends a heat bath but the implementation leaves the natural no-flux condition, total mesh heat will be conserved incorrectly. Boundary semantics are part of the physics API.

Self-adjointness explains why a clean mode decomposition exists. For the one-dimensional operator A = − d 2 / d x 2 with homogeneous Dirichlet conditions, integration by parts gives

∫ 0 L f ∗ A g d x − ∫ 0 L ( A f ) ∗ g d x = [ − f ∗ g ′ + ( f ′ ) ∗ g ] 0 L = 0.

The boundary term vanishes because both functions are zero at each end. For homogeneous Neumann conditions, it vanishes because both derivatives are zero. Other boundary conditions may also yield a self-adjoint operator, but this must be checked rather than assumed. The eigenvalues are real, distinct-eigenvalue modes are orthogonal, and the operator can be diagonalized in that basis. This is the continuum reason the heat equation reduces to independent exponential decays.

The same fact has a discrete energy witness. If S is symmetric positive semidefinite and M is positive definite, then

d d t ( 1 2 u T M u ) = u T M u ˙ = − κ u T S u ≤ 0.

This quadratic norm is not the total heat; it measures squared temperature variation around the chosen zero reference. It decreases under diffusion. Total heat in the no-flux case is instead 1 T M u , and it stays constant because S 1 = 0 . Keeping these two quantities separate prevents the false claim that “heat is conserved” means every norm or every boundary case is conserved.

Spatial and temporal error have different signatures

For a smooth sine mode with wavenumber k , the centered difference approximates the second derivative by the discrete eigenvalue

μ h = − 4 h 2 sin 2 ⁡ ( k h 2 ) = − k 2 + k 4 h 2 12 + O ( h 4 ) .

The leading error is proportional to h 2 for a fixed resolved mode. Since | μ h | is slightly less than k 2 at small but finite k h , the discrete mode decays a little more slowly than the continuum mode. Near the grid’s highest frequency, the approximation is no longer close to − k 2 ; the grid cannot represent finer structure. This is spatial discretization error, distinct from the forward-Euler time error and its stability limit.

A convergence experiment should separate them. Fix a smooth analytic initial field, hold temporal error small while refining h , and compare at a fixed time to estimate spatial convergence. Then fix a sufficiently fine spatial grid and reduce Δ t to measure temporal convergence. Finally sweep the ratio r = κ Δ t / h 2 toward the stability edge to verify the predicted highest-mode amplification. If both h and Δ t change arbitrarily in one experiment, a smaller error cannot be attributed to either change.

A practical manufactured solution can include a source term as well. Choose a smooth field u ∗ ( x , t ) satisfying the desired boundary values, then define

s ( x , t ) = ∂ t u ∗ ( x , t ) − κ ∂ x x u ∗ ( x , t ) .

The field u ∗ is now an exact solution of u t = κ u x x + s by construction. For example, let u ∗ = e − t sin ⁡ ( π x / L ) + t sin ⁡ ( 2 π x / L ) , whose endpoints remain zero. Differentiate it analytically to construct s . This tests the source assembly, boundary treatment, spatial operator and time stepping together without needing a complicated closed-form solution to an unrelated physical problem. Report a normed error, such as ‖ u h − u ∗ ‖ M , at stated times.

The mode formulas also support an impulse-response check. A sharply localized initial heat pulse can be projected onto the sine basis; its coefficient for mode n is the pulse’s inner product with ϕ n . At later times, each coefficient must be multiplied by e − κ λ n t . Compare direct time stepping against this truncated spectral reference on a fine grid. The two methods will not match exactly because one has grid and timestep error and the other has truncation error, but their discrepancy should shrink under the declared refinements. This test exercises the same linear evolution from two independent representations.

For a self-adjoint problem with a zero Neumann mode, the steady Green function for an inverse Laplacian is singular because constants are annihilated. One must project out the constant mode, enforce a zero-mean source, and choose a gauge such as zero-mean solution. For the transient heat kernel, the constant mode is retained: it is the long-time average left after all nonconstant modes decay. This distinction matters in mesh processing too. Solving a Poisson equation for geometry may need a pinned vertex or mean constraint; evolving heat on a closed surface should generally preserve the mean rather than accidentally delete it.

The continuous and discrete models therefore have matching but not identical contracts. In the continuum, the boundary condition defines the operator domain and Green identity. In the mesh, it determines constrained rows, boundary flux terms and the nullspace. In the spectrum, it selects modes and eigenvalues. In the time step, it controls stability and decay. Verifying one layer with the appropriate witness makes it possible to localize a bad result instead of compensating for it with an arbitrary damping factor or a smaller timestep.

PDEs, fields, and discrete solvers

Fields and PDEs express spatial behavior; discretization and boundary conditions determine the numerical system.

PDE discretization and variational structure

A partial differential equation includes derivatives along several spatial axes. The 2D Laplacian is u x x + u y y . A regular-grid finite difference approximates each second derivative from neighboring samples. On a mesh, a discrete Laplace operator uses connectivity and geometry weights. The heat equation moves a value toward neighboring values; the wave equation uses acceleration proportional to spatial curvature. Boundary conditions affect the solution everywhere because waves or diffusion interact with the boundary.

Explicit diffusion on a grid has a stability limit roughly proportional to ( Δ x ) 2 / κ , where Δ x is grid spacing and κ diffusivity. Refining the grid by two can require about four times smaller time steps in 2D explicit schemes, rapidly increasing cost. Implicit discretization leads to a sparse linear system. Matrix sparsity reflects local neighborhood connectivity; numerical linear algebra is therefore part of the simulation pipeline.

Optimization connects to PDEs through energy minimization. A continuous energy functional E [ u ] = ∫ L ( x , u , u ′ ) d x is stationary when it satisfies the Euler-Lagrange condition

∂ L ∂ u − d d x ( ∂ L ∂ u ′ ) = 0.

After discretization, the field becomes a finite vector and the functional becomes a finite objective. Its gradient can be minimized with the same methods used for curve fitting. The same field equation can describe very different behavior

A PDE describes a field u ( x , t ) whose value depends on location x and time t . The derivatives say how the field changes. For a ripple height, u is vertical displacement at each point of a pond. For heat, it is temperature at each point of a surface. For smoke, it might be velocity, density, or vorticity. The equation is an implicit rule: it constrains the field, but the field must still be computed from initial data, boundary data, and a numerical method.

The Laplacian is Δ u = ∇ ⋅ ( ∇ u ) , the divergence of the gradient. Equivalently in Cartesian coordinates it is the sum of second derivatives, u x x + u y y in 2D. A useful intuition is “difference from the local average”: it is near zero where the field matches its neighborhood and large where the field has a local bump or dip. The coordinate formula looks tied to axes, but the Laplacian itself is unchanged under a rigid rotation of coordinates.

Three equations provide contrasting mental models:

Laplace: Δ u = 0 , Heat: u t = κ Δ u , Wave: u t t = c 2 Δ u .

The Laplace equation is elliptic. With boundary values fixed, it finds a harmonic field that smoothly interpolates them. The heat equation is parabolic: an initial temperature distribution spreads and smooths; at steady state, u t = 0 , so it becomes the Laplace equation. Diffusion also acts as a model of damping or viscosity. The wave equation is hyperbolic: an initial bump propagates as a wave rather than simply disappearing. This matters numerically, because wave errors can travel for a long time instead of being averaged away. Burgers’ equation, u t + u u x = α u x x , adds a nonlinear transport term and a diffusion term; transport can steepen a wave toward a shock while diffusion softens it. A PDE is linear when the unknown field and its derivatives appear linearly; products such as u u x or nonlinear functions of u make it nonlinear. Its order is the highest derivative order present. Discretize the space with a representation that fits

Finite differences replace derivatives by differences of samples. For equally spaced 1D samples separated by spacing h , the centered approximation to the second derivative follows by differencing neighboring first slopes:

u ″ ( x i ) ≈ u i + 1 − 2 u i + u i − 1 h 2 .

In a regular 2D grid with equal horizontal and vertical spacing, the five-point Laplacian is

( Δ h u ) i , j = u i + 1 , j + u i − 1 , j + u i , j + 1 + u i , j − 1 − 4 u i , j h 2 .

The center has weight − 4 and each immediate neighbor has weight + 1 . The numerator is the sum of neighbor values minus four times the center value. It measures local non-flatness and gives a simple update for ripples or heat diffusion.

A grid is an Eulerian representation: values are stored at fixed spatial locations while material passes through them. A Lagrangian representation follows particles or mesh vertices as they move. Particle methods adapt naturally to moving material and unbounded domains, but a good particle distribution is difficult to maintain and local derivative estimates require neighbor searches. Fixed grids have regular, cache-friendly operations and straightforward finite differences, but they impose a domain and a resolution; fine features blur or alias when the grid is coarse. Hybrid methods such as FLIP, material point methods, and particle level sets mix moving samples with fixed grids to keep useful properties from both.

On a triangle mesh, the cotangent Laplacian replaces grid-neighbor weights with geometry-dependent weights. For scalar values u i at mesh vertices, a common unnormalized form is

( Δ h u ) i ∝ ∑ j ∈ N ( i ) ( cot ⁡ α i j + cot ⁡ β i j ) ( u j − u i ) ,

where N ( i ) is the set of vertices connected to i , and α i j , β i j are the two angles opposite edge i j . Implementations may divide by a local area or mass matrix, so normalization conventions must be checked. On a regular triangulated grid, the cotangent construction agrees with the familiar grid stencil up to its chosen scale. The lesson is broader than this one formula: express the spatial operator in a representation appropriate to the problem, and the same time integrator can often be reused across a grid, a mesh, or a hybrid domain. Boundary data is part of the equation

The Laplace equation alone does not determine a unique interpolated field. A constant is harmonic because its Laplacian is zero; indeed, on a periodic grid with no fixed values, both the all-zero field and every constant field solve Δ u = 0 . To define an interesting solution, state what happens at the boundary.

Dirichlet boundary conditions fix the value of the field, such as temperature around a plate or height around a domain. Neumann conditions fix the derivative in the outward normal direction, ∂ u / ∂ n = ∇ u ⋅ n , which is related to heat or fluid flux across the boundary. Robin conditions prescribe a linear combination of value and normal derivative. These choices are physically meaningful: fixed temperature, insulated boundary, or exchange with an environment are different problems.

Boundary values and derivatives cannot always be chosen independently. In 1D, a harmonic function satisfies u ″ = 0 , so it is a line u ( x ) = a x + b . Any pair of endpoint values determines a line, but two endpoint slope conditions must agree because a line has one slope. In a 2D harmonic Neumann problem, the divergence theorem gives a compatibility condition. Integrating the normal derivative around the boundary equals integrating Δ u over the interior. Since Δ u = 0 , the net boundary flux must be zero:

∫ ∂ Ω ∇ u ⋅ n d s = 0.

Even with compatible flux, adding a constant leaves both the Laplacian and normal derivatives unchanged, so one value or a mean-value constraint must be fixed to choose a unique representative. This is a simple example of a well-posedness check: verify a solution exists and is sufficiently determined before trusting a numerical solver. After solving a linear system A x = b , compute the residual r = b − A x ; a large residual may reveal a bad setup or incompatible boundary data, not merely a weak solver. Turn the discretized equations into a solver

For a grid Laplace problem, the equation at each interior cell says that its value equals the average of its four neighbors. Repeatedly replacing each value with that average is Jacobi iteration. It eventually spreads boundary information inward, but it is slow on large grids: distant parts of the domain communicate only through many neighbor-to-neighbor updates. Instead, assign a single index to every unknown grid value and assemble all local equations into one matrix system A u = b . Each row has a small number of nonzero entries because each cell couples only to nearby cells. The resulting matrix is sparse; use a sparse linear solver rather than storing and multiplying all the zeros in a dense matrix.

For heat diffusion, explicit Euler updates the current field using the current Laplacian:

u k + 1 = u k + Δ t κ Δ h u k .

Each cell moves toward the neighborhood average. But explicit diffusion is conditionally stable: for a regular grid the safe step scales like h 2 / κ . Halving the grid spacing can require about four times as many time steps in 2D, making fine grids expensive. An implicit step evaluates the diffusion at the new field and solves a sparse linear system; it allows larger stable steps at the cost of a solve.

The wave equation has a second time derivative. It can be rewritten with a velocity field v = u t as two first-order equations, u t = v and v t = c 2 Δ u . Alternatively, a centered second difference uses two previous time slices:

u k + 1 − 2 u k + u k − 1 ( Δ t ) 2 = c 2 Δ h u k .

This needs an initial displacement and initial velocity (or two compatible initial frames). The spatial Laplacian may be the grid stencil or a cotangent mesh operator (Geometry, Cameras, and Image Formation, Part 1, Reference notes: PDE fields and discrete Laplacians). The same time-stepping code can therefore propagate a ripple on a regular grid or waves over a triangle mesh, provided the boundary and operator are correctly specified. A low-resolution thin-shell wave can also be upsampled with Loop subdivision for an interactive visual result; interpolation adds surface detail, but it does not replace the underlying simulation. Discrete field equations and their stability conditions

From a PDE to a sparse system and a stable update

A partial differential equation (PDE) constrains a function that varies over space, time, or both. A numerical method must choose (1) what values represent the field, (2) how to approximate spatial derivatives, (3) how to advance in time if time is present, and (4) what boundary behavior is imposed. The same physical equation can therefore produce different algorithms on a fixed grid and on a moving triangle mesh. The examples below use the Laplace and heat equations to make each choice explicit. CMU-23 (Vision, XR, and Playable Worlds, Part 1, Ch. 5) (PDF pp. 30–46; video 00:36:00–00:54:00)

Derive the five-point grid stencil

For a one-dimensional function u ( x ) sampled at equally spaced locations x i = i h , the spacing h is the distance between adjacent samples and u i means u ( x i ) . A forward difference estimates the first derivative:

u ′ ( x i ) ≈ u i + 1 − u i h .

Apply the same difference to the neighboring slopes. The change between the slope to the right and the slope to the left is

u ″ ( x i ) ≈ ( u i + 1 − u i ) / h − ( u i − u i − 1 ) / h h = u i + 1 − 2 u i + u i − 1 h 2 .

The center coefficient is − 2 because the center value appears in both slopes. In two dimensions, add the horizontal and vertical second differences. If the horizontal and vertical spacing are both h , then

( Δ h u ) i , j = u i + 1 , j + u i − 1 , j + u i , j + 1 + u i , j − 1 − 4 u i , j h 2 .

Here i , j are integer grid indices, u i , j is the field at that grid location, and Δ h is the finite-difference approximation to the Laplacian Δ = ∂ x x + ∂ y y . The four neighbors each receive weight 1 / h 2 and the center receives − 4 / h 2 . If all four neighbors equal the center, the stencil is zero. If the center is higher than its neighbors, the result is negative; if it is lower, the result is positive. This sign agrees with the continuous Laplacian’s role as local deviation from the average. Poisson and Laplace equations become sparse linear systems

The Poisson equation is Δ u = f , where f is a prescribed source field. Laplace’s equation is the special case f = 0 . For the common positive-diagonal matrix convention, multiply the stencil by − h 2 :

4 u i , j − u i − 1 , j − u i + 1 , j − u i , j − 1 − u i , j + 1 = − h 2 f i , j .

This equation has one row for each unknown grid value. Each row touches only the center and its four immediate neighbors, so the matrix has mostly zeros: it is sparse. Number the unknown cells from 1 to N , put the center coefficient 4 on the diagonal, put − 1 in a neighbor’s column for each grid neighbor, and put zero elsewhere. The right side holds − h 2 f plus contributions from any known boundary values. Then solve A u = b with a sparse linear solver. If instead one defines the matrix to approximate Δ directly, its diagonal is negative and neighbor coefficients positive; both conventions are equivalent if the right side and signs are changed consistently.

For example, take one unknown interior cell with spacing h = 1 , zero on all four neighboring boundary cells, and constant source f = − 1 . The Poisson equation Δ u = − 1 becomes

0 + 0 + 0 + 0 − 4 u = − 1 ,

so u = 1 / 4 . The positive-diagonal form gives 4 u = 1 , the same answer. For a source-free Laplace cell with fixed neighbor values 1 , 2 , 3 , 2 , the equation is 4 u = 1 + 2 + 3 + 2 , hence u = 2 . The harmonic value is exactly the average of the four neighbors. The second trace is the local equation that Jacobi iteration applies: replace each unknown with its neighbor average, repeat, and allow boundary data to propagate inward. Jacobi is simple but may converge slowly on large grids because distant locations communicate only through repeated local updates. A sparse solve attacks all equations together. CMU-23 (Vision, XR, and Playable Worlds, Part 1, Ch. 5) (PDF pp. 34–36; video 00:43:00–00:49:00)

Boundary conditions are part of the mathematical problem, not a software afterthought. Dirichlet data fixes the field value at the boundary, such as a prescribed temperature. In matrix assembly, substitute that known value into the adjacent interior equation and move its contribution to the right-hand side; the boundary value is not an unknown. Neumann data fixes the derivative along the outward normal, which represents a flux. It changes the boundary stencil or supplies a flux contribution. Robin data combines a value and a normal derivative. Periodic wraparound is another choice: a neighbor on the right edge is identified with a cell on the left edge.

For a harmonic solution with Neumann boundary data, the net prescribed flux must be zero. Integrate Δ u = 0 over the domain and apply the divergence theorem:

∫ Ω Δ u d A = ∫ ∂ Ω ∇ u ⋅ n d s = 0.

Here Ω is the 2D region, d A is area measure, ∂ Ω is its boundary, d s is boundary length measure, and n is the outward unit normal. Thus inward and outward flux must balance. There is a second issue: adding a constant to a harmonic function leaves its derivatives and Neumann data unchanged. The solution is therefore only defined up to a constant unless one value or the average is pinned. In a linear system this appears as a nullspace (a nonzero vector mapped to zero). Check compatibility and constrain the nullspace before solving. Afterward, compute the residual r = b − A x ; its norm measures how closely the computed vector x satisfies the assembled equations. A small residual cannot prove the boundary model is correct, but a large residual can reveal an incompatible or poorly solved system. Explicit heat flow and its stability limit

The heat equation is u t = α Δ u . The symbol u t means change of the field per unit time; α > 0 is thermal diffusivity, controlling how quickly heat spreads. Forward Euler estimates the time derivative by ( u k + 1 − u k ) / Δ t , where k is a time-step index and Δ t is the time interval. Combine it with the five-point stencil. With equal grid spacing h in both directions, define r = α Δ t / h 2 . Then

u i , j k + 1 = u i , j k + r ( u i + 1 , j k + u i − 1 , j k + u i , j + 1 k + u i , j − 1 k − 4 u i , j k ) .

Every superscript k denotes the old time, and k + 1 denotes the new time. The center’s resulting coefficient is 1 − 4 r ; each neighbor’s coefficient is r . If r ≤ 1 / 4 , all five coefficients are nonnegative and sum to one. The update is then a weighted local average, which avoids making a new value overshoot the current local range for this diffusion stencil. The standard 2D stability condition for this explicit scheme is therefore

α Δ t h 2 ≤ 1 4 or equivalently Δ t ≤ h 2 4 α .

For instance, with h = 0.1 and α = 1 , the time step must be at most 0.01 / 4 = 0.0025 . Halving the grid spacing to 0.05 cuts the safe step to 0.0025 / 4 = 0.000625 . A finer grid resolves smaller spatial detail, but this explicit update then needs about four times as many steps over the same duration. If r > 1 / 4 , the center coefficient becomes negative; high-frequency grid patterns can grow instead of decay, producing numerical instability even though physical heat should smooth them. CMU-23 (Vision, XR, and Playable Worlds, Part 1, Ch. 5) (PDF pp. 44–45; video 00:58:00–01:05:00)

If horizontal spacing h x and vertical spacing h y differ, the discretization is

( Δ h u ) i , j = u i + 1 , j − 2 u i , j + u i − 1 , j h x 2 + u i , j + 1 − 2 u i , j + u i , j − 1 h y 2 .

The coefficients on the two pairs of neighbors are now different. Nonnegative weights require

α Δ t ( 1 h x 2 + 1 h y 2 ) ≤ 1 2 , Δ t ≤ 1 2 α ( 1 / h x 2 + 1 / h y 2 ) .

Setting h x = h y = h recovers Δ t ≤ h 2 / ( 4 α ) . A narrow cell spacing imposes the smaller stable time step because the corresponding second derivative has the larger 1 / h 2 scale. An implicit heat step evaluates the Laplacian at the new time, producing a sparse linear solve; it costs more per step but avoids this explicit stability restriction for diffusion. The cotangent mesh Laplacian and what “positive” means

On a triangle mesh, vertices replace grid samples and connectivity replaces the four regular neighbors. For an interior edge i j shared by two triangles, let α i j and β i j be the angles opposite that edge. The cotangent weight is

w i j = 1 2 ( cot ⁡ α i j + cot ⁡ β i j ) .

The cotangent of an angle is adjacent-side length divided by opposite-side length, equivalently cosine divided by sine. For scalar vertex values u i , define the stiffness matrix C by off-diagonal entries C i j = − w i j for adjacent vertices, zero for non-neighbors, and diagonal C i i = ∑ j ∈ N ( i ) w i j . Then

( C u ) i = ∑ j ∈ N ( i ) w i j ( u i − u j ) .

This convention makes C approximate the negative Laplacian contribution. With a diagonal lumped mass matrix M , whose diagonal entry M i i is the area assigned to vertex i (often one third of each incident triangle’s area summed around the vertex), the pointwise operator is approximately

Δ h u ≈ − M − 1 C u .

The mass division converts an area-integrated stiffness contribution into an area-normalized value. Other texts and libraries use the opposite sign, a different factor, or a different mass matrix; compare definitions before reusing a formula. For a single equilateral triangle of side length one, each angle is 60 degrees and each cotangent is 1 / 3 . A boundary edge has only one incident face, so its edge weight under the one-sided boundary convention is w = 1 / ( 2 3 ) . Each vertex has lumped area M i i = 1 3 ( 3 / 4 ) = 3 / 12 . Assign values ( u 0 , u 1 , u 2 ) = ( 0 , 1 , 0 ) to the three vertices. At vertex 0, only edge 01 contributes a nonzero difference, so ( C u ) 0 = w ( 0 − 1 ) = − 1 / ( 2 3 ) . Therefore

( Δ h u ) 0 ≈ − ( C u ) 0 M 00 = 1 2 3 12 3 = 2.

The positive value is consistent with vertex 0 being below its high-valued neighbor. This example also shows why normalization matters: without M − 1 , the result scales with local area and is not a pointwise second derivative. Boundary edges have one opposite angle rather than two; the exact discrete boundary operator depends on the chosen boundary condition and mass convention. For a Neumann-like natural boundary, the missing exterior contribution is not invented as a second triangle. For a Dirichlet boundary, fixed boundary values are instead imposed in the linear system.

The matrix C is symmetric positive semidefinite for the standard finite-element cotangent construction: its quadratic energy is a sum of nonnegative per-triangle gradient energies. It has a constant null vector on each connected component because a constant field has zero gradient. Individual cotangent weights need not all be nonnegative: an obtuse opposite angle has negative cotangent and can produce a negative edge weight. That does not by itself mean the whole stiffness matrix has negative energy; matrix positivity concerns the sum of all coupled contributions, not every entry separately. Negative weights can still affect local maximum-principle behavior or produce overshoot, so mesh quality and the particular application matter. This distinction is essential when interpreting cotangent stencils on irregular meshes. CMU-23 (Vision, XR, and Playable Worlds, Part 1, Ch. 5)

A wave needs two initial conditions and a different time update

Heat relaxes an initial field. A wave carries both a displacement and a velocity. For a scalar displacement u ( x , t ) , the one-dimensional wave equation is u t t = c 2 u x x , where c > 0 is propagation speed. Knowing the initial displacement alone cannot tell us whether a point is moving upward or downward, so we also supply u t ( x , 0 ) . A grid stores both pieces of information, either as position and velocity or as two consecutive displacement fields.

Let u i n approximate the displacement at position x i = i h and time t n = n Δ t . Centered differences in both time and space give

u i n + 1 = 2 u i n − u i n − 1 + r 2 ( u i − 1 n − 2 u i n + u i + 1 n ) , r = c Δ t h .

c 2 Δ t 2 ( 1 h x 2 + 1 h y 2 ) ≤ 1.

Optical flow and motion from images

Optical flow infers image motion from brightness measurements, but local constraints often leave important directions ambiguous.

Brightness constancy is a measurement equation, not a universal law

Assume a small image patch moves at velocity ( u , v ) without changing its brightness pattern. Brightness constancy means

E ( x ( t ) , y ( t ) , t ) = constant .

The chain rule yields

E x u + E y v + E t = 0 ,

where E x = ∂ E / ∂ x , E y = ∂ E / ∂ y , and E t = ∂ E / ∂ t . This is the optical-flow constraint equation. The spatial gradient ( E x , E y ) gives one equation for two unknowns, u and v . So one pixel cannot determine the full motion; it limits the answer to a line of possible velocities. This is the aperture problem: local brightness changes reveal motion across an edge but not along it. Eigenvectors expose directional noise gain

The 2-D flow fit supplies a real symmetric matrix M whose inverse maps measured brightness changes into velocity. Determinant zero says the solve fails, but the eigenvectors show which direction fails and by how much. An eigenvector e i and eigenvalue λ i satisfy M e i = λ i e i . the eigenvalues are

λ ± = a + c ± ( a − c ) 2 + 4 b 2 2 .

For each root, the rows of M − λ I are perpendicular to the eigenvector. A convenient vector perpendicular to the first row ( a − λ , b ) is ( b , λ − a ) ; normalize it to unit length. When the eigenvalues differ, symmetry makes the two eigenvectors orthogonal. If they are repeated, choose any orthogonal basis for that eigenspace.

An orthonormal eigenbasis expands any measurement perturbation as δ y = ∑ i α i e i . Applying the inverse gives M − 1 δ y = ∑ i ( α i / λ i ) e i . Thus small | λ i | means large noise amplification along eigenvector e i . Flow: why one bright edge cannot reveal full motion

Suppose the local image is a straight vertical edge whose brightness varies with horizontal coordinate x but not vertical coordinate y . Then E y = 0 . The optical-flow equation reduces to E x u + E t = 0 , which determines u if E x ≠ 0 , but it contains no v . Sliding the edge up or down leaves every local brightness value unchanged. This is a concrete aperture problem: the data constrain motion normal to the edge and say nothing about motion parallel to it. A patch with two differently oriented edges gives rows in A that span more directions, so A T A may become invertible. The distinction is not “no motion versus motion”; the image contains real motion evidence, but only one component is observable. MITV-04 (Vision, XR, and Playable Worlds, Part 1, Ch. 5)

If each derivative observation has independent noise variance σ 2 , the least-squares covariance under the simple linear model is proportional to σ 2 ( A T A ) − 1 . When gradients point in nearly the same direction, one eigenvalue of A T A is small and the corresponding motion uncertainty grows. A useful implementation therefore reports a conditioning or confidence measure and may reject poorly textured patches. Smoothing can reduce derivative noise, but too much smoothing blurs edges and merges distinct motions. This is an estimation tradeoff, not a parameter that can be optimized without regard to scale.

Edges, contours, and subpixel localization

Edges and contours provide geometric evidence whose localization, linking, and voting methods must account for noise and blur.

Edges and blobs: image geometry without a full 3-D model

An edge is a rapid brightness transition. In one dimension, a simple model is a step from dark level a to bright level b at unknown position x 0 . Differentiation produces a peak near x 0 , but sampled pixels rarely land exactly on the physical transition. A subpixel estimate fits or interpolates the local response around the maximum. It can improve precision beyond one pixel spacing when the blur/noise model and sampling are adequate; it cannot restore detail lost through severe blur, aliasing, or low signal-to-noise ratio. MITV-11 (Vision, XR, and Playable Worlds, Part 1, Ch. 5) (notes pp. 59–65)

In two dimensions the gradient is ( E x , E y ) and its direction estimates the local edge normal. Quantized direction bins cause orientation bias. The course discusses CORDIC, a shift-add procedure for estimating angles and vector rotations through a sequence of elementary rotations. Its appeal in hardware is that shifts and additions can be cheaper than general trigonometric operations. The line-detection patent example emphasizes calibrated edge measurement and line geometry as a deterministic industrial vision problem. A line is supported by many local edge points; its global parameters can be estimated more stably than treating every pixel independently.

The notes put a numerical scale on this engineering problem. The subpixel-edge patent cited in class claims accuracy as high as one-fortieth of a pixel for its apparatus. Its pipeline estimates gradients using local filters, converts Cartesian gradient components to magnitude and direction with CORDIC, selects neighbors along the estimated normal, performs non-maximum suppression, and interpolates the peak. A simple three-sample parabolic fit has three degrees of freedom and is described as reaching about one-tenth pixel. Better accuracy needs compensation for how gradient varies with position and for camera optics, sensor fill factor, focus, and smoothness of the edge transition. Thus a fractional-pixel output is meaningful only relative to an image-formation model and a calibration of systematic bias. MITV-11 (Vision, XR, and Playable Worlds, Part 1, Ch. 5) (notes pp. 60–63)

The lecture compares several derivative stencils rather than presenting one universal gradient filter. Roberts Cross estimates derivatives in axes rotated by 45 degrees using 2 × 2 neighborhoods. Sobel uses 3 × 3 neighborhoods with extra weight on the middle row or column; the averaging effect makes it more robust to noise but spreads the response. A “silver” operator is designed for a hexagonal grid, which has geometric advantages in some sampling arrangements but is incompatible with ordinary square-pixel cameras. Operator design must match the sampling lattice. The notes also point out that an ideal infinitely thin step has unbounded frequency content and cannot be sampled without aliasing; a soft sigmoid edge is a more realistic local model. For u ( x ) = 1 / ( 1 + e − x ) , the derivative peaks at the inflection point, and the second derivative crosses zero there. This gives two related edge-location criteria, though discrete noise and blur alter their estimators. MITV-11 (Vision, XR, and Playable Worlds, Part 1, Ch. 5) (notes pp. 60–64)

Thresholding an image creates a binary region, or blob. Its area and moments describe size, centroid, and orientation. For binary indicator B ( x , y ) , area is A = ∬ Ω B d x d y ; centroid coordinates are x ¯ = A − 1 ∬ Ω x B d x d y and y ¯ = A − 1 ∬ Ω y B d x d y . Subpixel edge localization as a complete industrial pipeline

The Cognex patent studied in class begins from a practical model: many parts have broad, nearly uniform regions, so a compact description of a part can be built from its boundaries. This is why semiconductor mask alignment and conveyor-belt measurement need reliable edge coordinates. A pixel-level boundary is not enough for precision metrology; the patent claims roughly 1 / 10 -pixel localization as attainable and describes pushing toward 1 / 40 pixel after calibration. The overall pipeline has three linked stages: estimate the brightness-gradient magnitude and direction, suppress all but local maxima across that direction, then interpolate the surviving peak to a subpixel coordinate. Gradient operators are not interchangeable labels: their sample geometry determines where the estimate lives and how it responds to noise. What defocus does to an edge, and where interpolation bias comes from

Defocus turns a point into a blur disk. In the lecture’s simple geometric model, a point source would focus to one point in the image plane, but if that plane is displaced by δ , rays from an aperture of diameter D spread over a circle. Similar triangles give blur radius R ≈ D | δ | / ( 2 F ) , where F is the lens-to-focus-plane distance. Conservation of light makes the point-spread function a uniform disk of value 1 / ( π R 2 ) inside radius R and zero outside. This box-shaped 2D blur suppresses high spatial frequencies, so a physical black-to-white step becomes a smooth transition over approximately 2 R pixels. The blur is useful: a perfect step sampled on a pixel grid can shift by almost a full pixel without changing any sample, making subpixel location unobservable. MITV-12 (Vision, XR, and Playable Worlds, Part 1, Ch. 5) (video 00:55:20–01:00:30)

For an ideal straight edge, the blurred brightness at offset x is the fraction of the blur disk lying on the bright side. The circular-segment area gives, for | x | < R ,

E ( x ) = 1 π [ arccos ⁡ ( − x R ) + x R 1 − x 2 R 2 ] .

It rises from zero to one between − R and R and is symmetric about x = 0 . Its first derivative is proportional to the chord length, E ′ ( x ) = 2 R 2 − x 2 / ( π R 2 ) , which peaks at the true edge; its second derivative changes sign there. Comparing this known profile with a three-sample parabola or triangle fit predicts a small systematic subpixel bias. Calibrating a simple power-law correction s ′ = | s | 1 + B (with sign retained) is usually sufficient; use separate B values for axial and diagonal sampling because their neighbor distances differ. More elaborate calibration is not always better, since slight focus changes or a damaged part edge change the blur profile itself. The lecture then removes the patent’s eight-direction quantization in two ways. First, choose the two sampling points directly along the measured gradient direction and interpolate their brightness from the pixel grid. One-dimensional linear interpolation suffices along that line; cubic interpolation can use more samples for a smoother estimate. This puts the suppression and peak fit on the true normal direction and eliminates the later plane-position correction. It also makes sample spacing vary continuously, so the calibration curve must account for a continuum of distances; interpolation error itself matters at 1 / 40 -pixel targets. Second, sample at a fixed radius around the candidate point. The three samples then have a consistent physical spacing for every gradient direction, but off-grid values require two-dimensional interpolation. Bilinear interpolation is cheap but less accurate; bicubic interpolation uses a wider neighborhood (roughly a 5 × 5 support) and costs more. The patent’s quantized design is therefore a deliberate balance between geometric consistency, interpolation error, memory, and arithmetic. The lecture also reviews how CORDIC turns Cartesian gradient components into magnitude and angle. Conceptually, rotate the vector until its vertical component is near zero; the accumulated rotation angle is the direction and the final horizontal component approximates the magnitude. General rotations require sine, cosine, and four multiplications. CORDIC chooses a sequence of progressively smaller angles θ i = arctan ⁡ ( 2 − i ) . Then sin ⁡ θ i and cos ⁡ θ i are close to powers of two, so multiplication becomes a bit shift; each step uses shifts and additions/subtractions, and accepts the sign that reduces the remaining vertical component. The fixed gain from the sequence of rotations is precomputed and corrected if absolute magnitude matters. First inspect signs and swap axes as needed to bring the vector into the first octant; then vectoring iterations converge rapidly. This explains both CORDIC’s historical appeal in fire-control computers and why the best choice depends on whether a modern chip’s multipliers or memory lookups are cheaper. Hough voting turns weak local evidence into a global hypothesis

The classical Hough transform was motivated by bubble-chamber photographs. A particle track appears as separated bubbles of unequal size and spacing, so ordinary edge linking cannot reliably trace one continuous contour. For a line y = m x + c , each observed point ( x i , y i ) constrains possible parameters by c = y i − m x i —a line in slope-intercept parameter space. Every bubble votes along its parameter-space line; bubbles belonging to the same physical track produce votes that intersect near one common ( m , c ) . An accumulator array bins those votes, and peaks identify likely lines. One noisy point does not say which line is correct; it reduces the possibilities to a one-dimensional family. MITV-14 (Vision, XR, and Playable Worlds, Part 1, Ch. 5) (video 00:53:31–01:06:25)

The same construction generalizes. If a circle’s radius r is known, a point ( x i , y i ) says the center ( a , b ) must lie on the circle ( a − x i ) 2 + ( b − y i ) 2 = r 2 in center-parameter space. The LTE time-advance example gives an intuitive ranging analogue: a measured round-trip delay fixes a phone-to-tower distance, so the unknown tower lies on a circle around that phone position; several measurements accumulate evidence at their common center. If radius is unknown too, the parameters ( a , b , r ) form a three-dimensional space, and each measured point votes for a cone of possible circles. Noise spreads votes across neighboring bins, but a good hypothesis still collects more evidence than alternatives. The cost is that quantizing a high-dimensional parameter space requires a large accumulator, so Hough voting is most useful when local evidence is incomplete and the global parameterization is compact. Orthogonal line fitting is the right geometry for edge fragments

Represent a line by its unit normal angle θ and signed distance ρ from the origin:

x sin ⁡ θ − y cos ⁡ θ + ρ = 0.

This form has no infinite-slope singularity and its left side is a signed perpendicular distance. For measured points ( x i , y i ) , minimizing squared perpendicular errors is a coordinate-independent fit. Differentiating with respect to ρ shows that the fitted line passes through the centroid ( x ¯ , y ¯ ) , so

ρ = − x ¯ sin ⁡ θ + y ¯ cos ⁡ θ .

Center the points, X i = x i − x ¯ and Y i = y i − y ¯ . Then minimizing residual sum of squares reduces to choosing the normal angle that minimizes ∑ i ( X i sin ⁡ θ − Y i cos ⁡ θ ) 2 . Differentiation yields the double-angle relation

2 θ = atan 2 ( 2 ∑ i X i Y i , ∑ i X i 2 − ∑ i Y i 2 ) ,

with the equivalent line orientation selected consistently modulo π . This is the principal-component result: the line direction is the covariance eigenvector with greatest spread, and the normal is the least-spread direction. Ordinary least squares of y = m x + c instead treats x as error-free and minimizes only vertical residuals; rotating the same cloud changes that fit. Use it only when the measurement process truly gives x a different, effectively exact status. MITV-15 (Vision, XR, and Playable Worlds, Part 1, Ch. 5) (video 00:48:49–00:58:48)

Recognition, templates, and industrial matching

Recognition compares image evidence against transformed templates, choosing scores and search spaces suited to expected variation.

Industrial recognition: templates, transforms, and tolerances

Industrial machine vision often has a known object family, controlled lighting, and a need for reliable pose measurement. This is a different setting from unconstrained semantic classification. A binary template or edge template stores geometric evidence from a reference object. At runtime, the system searches for a transformation that aligns template evidence with image evidence. Normalized correlation compensates for scale/offset changes in measured intensity, while edge-based matching can be less sensitive to uniform brightness shifts. MITV-13 (Vision, XR, and Playable Worlds, Part 1, Ch. 5) (notes pp. 73–78)

The course begins this topic with a careful contrast between raw image correlation and gradient-based matching. For template image E 1 and runtime image E 2 , minimizing the squared difference ∬ ( E 1 ( x − δ x , y − δ y ) − E 2 ( x , y ) ) 2 d x d y is equivalent to maximizing cross-correlation when the two self-energy terms do not vary with translation. A first-order Taylor expansion for small shift ( δ x , δ y ) leads back to the brightness-constancy flow residual. This makes local optical flow a small-displacement approximation to template alignment. Correlation handles larger translation searches directly, but global occlusion or missing object regions can badly affect the score. Mean subtraction removes intensity offset; dividing by the norms yields a normalized correlation that is less sensitive to contrast scaling. It still cannot make an occluded region informative. PatQuick is presented in the lectures as a fast, robust multidimensional object-detection and pose method. The key perspective is geometric: detection means finding a location and transformation whose predicted template features agree with measured features. Its industrial focus makes repeatability, inspection tolerances, and computational cost central. The method’s patent title is “Method for Fast, Robust, Multidimensional Object Detection and Pose Determination” (US 7,016,539), as named by the course. MITV-13 (Vision, XR, and Playable Worlds, Part 1, Ch. 5) · MITV-14 (Vision, XR, and Playable Worlds, Part 1, Ch. 5)

PatQuick does not need to keep and rescan a full template image at every possible pose. Its training stage finds boundary points, connects neighbors with consistent directions into chains, removes short or weak chains, splits chains near high-curvature corners, and places evenly spaced probes along retained low-curvature segments. It stores probe positions, gradient directions, weights, pattern contrast, and a selectable granularity that defines the resolution below which image variation becomes unresolved. Probe points can lie between pixels. At runtime, transformed probes sample only selected image locations; the system accumulates their direction or magnitude agreement into a multidimensional score surface. A peak in that surface proposes object pose. This sparse evidence design trades exhaustive pixel comparison for a compact model, but its accuracy remains limited by pose-space quantization and probe placement. The pose search spans translation, rotation, scale, skew, and aspect ratio. In the lecture’s generalized affine view, x ′ = a 11 x + a 12 y + a 13 and y ′ = a 21 x + a 22 y + a 23 encode six independent 2-D affine degrees of freedom. More degrees of freedom make the match family more expressive while causing the configuration count to grow rapidly at fixed quantization. Coarse-to-fine search is therefore a computational strategy, not just a display convenience: coarse levels find candidate basins; finer levels spend effort where evidence supports a match. The notes describe hexagonal sampling and peak detection for translation; a hexagonal neighborhood improves spatial sampling efficiency over a square grid for comparable resolution, with tie-breaking rules needed to avoid ambiguous peaks. MITV-14 (Vision, XR, and Playable Worlds, Part 1, Ch. 5) (notes pp. 78–81)

Scoring itself has a statistical interpretation. Random background texture can coincidentally provide a probe gradient in the expected direction. The course computes a baseline random-match contribution and discusses subtracting it, rather than treating any high raw score as meaningful. Direction matching is often more robust than gradient magnitude because magnitude changes with contrast and lighting; magnitude can still be used with saturation and weights. Normalized scores cost more but reduce dependence on the number or strength of probes; raw weighted scores are cheaper for fine scanning after a coarse candidate is already found. The system also compensates for whether a transformation changes gradient direction: pure translation, rotation, and uniform scale preserve it, while shear and aspect-ratio changes transform isophote orientation. The Hough transform handles noisy or incomplete local evidence by letting each observation vote for global parameter values consistent with it. For example, an edge pixel with a known normal may vote for line parameters; peaks in an accumulator indicate parameter combinations supported by many pixels. This trades direct combinatorial search for a discretized parameter-space histogram. Resolution matters: coarse bins merge distinct hypotheses; fine bins increase memory and sensitivity to noise.

A homography is a 3 × 3 projective matrix H that maps homogeneous image coordinates between views of a plane: λ x ′ = H x , where λ is a nonzero scale and x , x ′ are three-component homogeneous coordinates. It can represent planar perspective changes, but a single homography does not describe arbitrary 3-D scenes with parallax. Multi-scale search reduces cost by locating a candidate at a coarse resolution before refining translation, scale, or orientation at finer levels. PatMax is another industrial alignment method emphasized through distance fields. Given template edges, compute for each image location the distance to the nearest observed edge (or an equivalent signed/unsigned distance representation). A transformed template can then be scored by summing those distances at its expected edge points. This makes small edge localization errors degrade the score smoothly instead of causing a hard pixel mismatch. The method still depends on sensible edge extraction, a good transform search, and a tolerance appropriate to the inspection task. It is not invariant to arbitrary deformation; the allowable transformations encode what “same part, different pose” means. MITV-15 (Vision, XR, and Playable Worlds, Part 1, Ch. 5) (notes pp. 84–93)

PatMax is specifically positioned as a refinement stage after PatQuick. PatQuick searches a quantized pose space broadly and can start without an initial estimate; PatMax assumes an approximate pose and iteratively improves it without quantizing pose space, enabling subpixel refinement. Its training data include edge fragments and a vector field that attracts runtime edge evidence toward the template field. Unlike the earlier direction-quantized pipeline, PatMax avoids CORDIC and quantized gradient directions when high precision is the goal. A mechanical-spring analogy is more accurate than literal electrostatics: runtime dipoles experience forces, and a small set of allowed pose changes turns those forces into parameter updates. A 2-D translation contributes two degrees of freedom, rotation one, and scale one; affine refinement can add skew and aspect effects for six degrees total. Local linearization yields a weighted least-squares update, accumulated efficiently, but no general closed-form answer exists for all edge configurations. The cascade is therefore coarse global capture followed by local, continuous optimization. MITV-15 (Vision, XR, and Playable Worlds, Part 1, Ch. 5) (notes pp. 84–89)

For the simplified line-fitting example, rotate image points by angle θ and shift the origin by signed distance ρ . The perpendicular residual of point ( x i , y i ) is r i = x i sin ⁡ θ − y i cos ⁡ θ + ρ . Minimize J ( ρ , θ ) = ∑ i r i 2 . Setting ∂ J / ∂ ρ = 0 gives ρ = y ¯ cos ⁡ θ − x ¯ sin ⁡ θ , so the fitted line passes through the point centroid. Centering the coordinates and setting ∂ J / ∂ θ = 0 gives

tan ⁡ ( 2 θ ) = 2 ∑ i x i ′ y i ′ ∑ i ( ( x i ′ ) 2 − ( y i ′ ) 2 ) ,

where x i ′ = x i − x ¯ and y i ′ = y i − y ¯ . This closed form chooses the principal axis direction that minimizes perpendicular squared error; the two-angle ambiguity and the correct normal-versus-line direction must be resolved from the objective and convention. It demonstrates how centroid and second moments encode line orientation, connecting Hough-style parameterization to inertia-based shape orientation. From correlation to sparse, multidimensional pattern matching

The first alignment baseline is to slide a golden image E 1 over a runtime image E 2 and choose the displacement ( u , v ) that minimizes squared difference,

D ( u , v ) = ∬ Ω [ E 1 ( x , y ) − E 2 ( x + u , y + v ) ] 2 d x d y .

Expanding the square shows why this is closely tied to correlation: the terms ∬ E 1 2 and ∬ E 2 2 are constant (or nearly constant if the overlap window changes), leaving the cross-product ∬ E 1 ( x , y ) E 2 ( x + u , y + v ) d x d y . Thus minimizing squared error and maximizing correlation choose nearly the same translation. The catch is cost: with N pixels and M tested positions, the direct method is O ( N M ) , so adding rotation, scale, or skew multiplies the search burden. A constant brightness offset or contrast change can also make squared error look bad even when shape is aligned. The normalized correlation used in the lecture subtracts each image patch’s mean and divides their inner product by the product of their centered Euclidean lengths:

ρ ( u , v ) = ∬ Ω ( E 1 − E ¯ 1 ) ( E 2 , u , v − E ¯ 2 , u , v ) d x d y ∬ Ω ( E 1 − E ¯ 1 ) 2 d x d y ∬ Ω ( E 2 , u , v − E ¯ 2 , u , v ) 2 d x d y .

The Cauchy–Schwarz inequality bounds ρ between − 1 and 1 . A perfect same-polarity match gives 1 , no linear correlation is near 0 , and a perfect contrast reversal gives − 1 . Removing the mean makes it invariant to an additive brightness offset; dividing by the two norms makes it insensitive to positive contrast scaling. Unlike unnormalized correlation, the value can be interpreted against an acceptance threshold (the lecture uses approximately 0.95 as a strong-match illustration), rather than merely choosing the largest peak. However, every-pixel correlation is still expensive, and an occlusion or missing gear tooth contributes many mismatching pixels. High frame-rate optical mice illustrate the alternative: if frame-to-frame displacement is small, gradient-based local motion estimation can be cheaper than exhaustive correlation. The Cognex-style model replaces the full image patch with a sparse set of probes. Training begins from a clean golden sample, computes and links subpixel boundary points, splits chains at sharp curvature changes, then redistributes probe locations to a chosen density. Each probe stores a position, expected gradient direction, and weight; the model also stores a useful coarsest granularity and expected contrast polarity. Runtime matching transforms the small model onto the precomputed gradient image and samples only at probe positions. That is efficient because a model may contain tens or hundreds of probes instead of millions of pixels. The runtime image remains untouched: transforming a few model coordinates is cheaper and avoids resampling or rotating the entire image. The direction of an edge gradient is generally more stable than its magnitude when illumination or material response changes. A direction score can therefore be flat within a tolerance and decline linearly outside it: the example accepts errors through 11.25 ∘ fully, fades to zero by 22.5 ∘ , then wraps around the full circle. If the application permits contrast reversal, an additional acceptance lobe near 180 ∘ is needed. That doubles the angular range in which unrelated edges can count as partial matches, so polarity invariance increases false evidence. If gradient magnitude is used, it can be ignored, used as a weight, or scored with saturation so very strong gradients do not dominate without bound. Summing weighted probe evidence over a pose gives a score surface; search peaks propose instances, while an end-stage threshold accepts or rejects each one. Weak edge fragments are retained through early stages and rejected only when they form too short or low-total-weight chains, postponing a fragile threshold until evidence accumulates. This representation also accommodates inspection. A probe with negative weight can penalize an expected edge that should be absent, such as the continuation of a rounded phone outline beyond its endpoint. Such probes can disambiguate a symmetric shape, but unlike positive probes extracted automatically from an edge chain, the negative ones require human-authored knowledge and were described as uncommon in automated use. A missing or occluded part lowers match score rather than necessarily destroying the match, allowing the same alignment to support defect inspection. A CAD outline can generate a model, but a real golden sample may be better when fabrication rounds corners or distorts the ideal design. The search space is built from application-relevant degrees of freedom: image translations, cyclic rotation, logarithmic size change, and—only when the optics or object pose require it—shear and independent axis/aspect changes. A percentage size increment is better expressed logarithmically: a fixed increment in log scale yields a similar percentage change for small and large objects. Every added degree of freedom increases cost, so omit unsupported transformations. Search begins on coarse quantized pose grids, using efficient hexagon-centered translation patterns and tie-breaking rules for hexagonal neighborhoods, then refines around promising candidates with finer steps. Multiple local candidates should be kept because an early coarse peak may not be the global match. The approach is a strong initializer for a later continuous optimizer, but its final precision is limited by the pose-grid spacing. The score is a design choice, and affine transforms act on normals

The industrial matcher does not have one universally best score. A normalized direction-only score can be written schematically as

S 1 a ( T ) = ∑ i w i r ( Δ θ i ( T ) ) ∑ i w i ,

where T is a candidate pose, w i is probe i ’s weight, r is the angular agreement function, and Δ θ i is the wrapped difference between the trained direction and the runtime gradient direction. This score reaches 1 for a perfect match and has an interpretable absolute scale. A faster variant keeps only positive-weight probes and tests whether each is within tolerance, avoiding per-probe multiplication. A background-noise-corrected version subtracts the expected random coincidence contribution n ; the patent’s illustrative direction tolerance yields about 3 / 32 chance agreement per probe, approximately 10 % . If contrast reversal is allowed, the accepted angular interval doubles and so does that background term. A fine-scan score can multiply by gradient magnitude, but that makes the raw score depend on illumination; a normalized saturated magnitude score prevents one extremely strong edge from overwhelming all the others. Use the cheapest score that suffices during broad search, then spend more computation on normalized or magnitude-aware scores for the few final candidates. An often-missed detail appears when the model undergoes a general affine warp. A gradient is a normal to an isophote (a curve of constant brightness), not a tangent direction, so it cannot be transformed as though it were an ordinary point vector. If image coordinates change by x ′ = A x , then the chain rule gives the transformed brightness gradient

∇ ′ E = A − T ∇ E .

The inverse transpose preserves the fact that a gradient remains perpendicular to the warped isophote. An intuitive construction is: rotate the gradient by 90 ∘ to get the isophote tangent; transform that tangent with A ; then rotate the transformed tangent back by 90 ∘ to recover the new normal. For a right-angle rotation, this reduces to swapping components and changing one sign, so the correction is cheap. But under shear or aspect-ratio change, simply applying A to the gradient gives the wrong direction and weakens every probe comparison. PatMax: continuous pose refinement after coarse localization

PatQuick and PatMax solve complementary search problems. PatQuick makes a sparse probe model and searches a quantized pose space broadly enough to produce an initial match. PatMax assumes that initial pose lies in the correct capture basin, then iteratively improves position and orientation by minimizing a weighted least-squares-like alignment energy. The patent calls an update an attraction step and prefers four iterations as a practical stopping rule; a different system can stop when the update or residual is small. Because it never globally explores all poses, PatMax can refine more precisely but can converge to the wrong local match if initialization is too far away. MITV-15 (Vision, XR, and Playable Worlds, Part 1, Ch. 5) (video 00:00:12–00:06:59, 00:31:45–00:36:57)

Training computes subpixel edge fragments from the golden image. PatMax calls these oriented fragments dipoles, but the course cautions that the name suggests the wrong physics: point charges or electric dipoles have singular or orientation-dependent interactions, unlike this algorithm. A mechanical spring analogy is closer. Imagine each runtime edge sample connected to the nearest compatible training edge by a spring; alignment reduces total spring energy. Since an edge measurement constrains position mainly across its normal and is ambiguous along its tangent, the target end should slide along the model edge like a carriage, rather than attach to an arbitrary point. MITV-15 (Vision, XR, and Playable Worlds, Part 1, Ch. 5) (video 00:02:16–00:04:13, 00:24:16–00:25:22)

The model stores both oriented edge fragments and a dense two-dimensional attraction field. Field vectors encode distance and direction back toward nearby trained edges, but only out to a chosen cutoff. Beyond that, the cell is marked unknown so distant texture cannot provide misleading attraction. Propagation begins at known subpixel boundary seeds, then fills neighboring cells outward. Manhattan distance is simple to update exactly with axis steps but is not Euclidean; Euclidean distance requires more careful geometry, especially when each cell stores a direction vector as well as a length. Where fronts from two edge segments collide, similar proposals can be combined, but a large disagreement indicates a corner; mark the region so it cannot spuriously pull the alignment. This is a directed distance field, not merely a scalar distance transform. MITV-15 (Vision, XR, and Playable Worlds, Part 1, Ch. 5) (video 00:13:22–00:24:15, 00:41:18–00:45:14)

At runtime, PatMax detects edges in the live image, maps those comparatively few dipoles back into the precomputed model field, and aggregates their local forces. This reverses PatQuick’s mapping direction: PatQuick moves a small trained model over a runtime gradient image; PatMax moves runtime edge samples through a trained field. In either case the whole image is not warped at every candidate pose. Translation follows the vector sum F = ∑ i w i f i . Rotation follows torque about a chosen center, τ = ∑ i w i ( r i × f i ) z , where the planar cross product contributes only its out-of-plane scalar. Scale can be estimated from radial forces, because a size mismatch stretches the spring-like displacements more strongly farther from the center. The chosen transformation parameters are coupled, so these sums form a local linearized least-squares system; solving it yields one update, not a closed-form global optimum. MITV-15 (Vision, XR, and Playable Worlds, Part 1, Ch. 5) (video 00:25:25–00:31:26, 00:45:17–00:48:44)

The dense field and candidate edges support inspection in two directions. Coverage asks what fraction of trained model boundaries found a runtime match; clutter asks how much runtime edge evidence is unexplained by the trained object. A missing gear tooth can preserve a good pose but reduce coverage. An extra scratch or textured background can increase clutter. These metrics make positioning, recognition, and part inspection distinct outputs of one matcher. A client map first corrects rectangular or unequal camera pixel pitch so calculations occur in a Cartesian square grid. Multiscale training builds a separate model at each resolution: refine at a coarse level for speed, then use that pose to initialize finer edge geometry. C. How should an edge alignment score behave?

A raw binary overlap score changes abruptly when a predicted edge moves by one pixel. A distance-field score changes gradually: each transformed template point receives a penalty based on its distance to the nearest observed edge. That smoothness supports optimization and tolerance to quantization. However, overly broad distance penalties can let an incorrect nearby contour score well; the distance scale should reflect the inspection tolerance and expected edge uncertainty.
