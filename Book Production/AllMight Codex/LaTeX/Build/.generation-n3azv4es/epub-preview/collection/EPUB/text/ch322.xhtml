Multiple importance sampling

Multiple importance sampling combines estimators from several sampling techniques without pretending that one proposal distribution is good everywhere.

Suppose two techniques generate the same contribution f ( x ) using PDFs p a ( x ) and p b ( x ) . With one sample from each technique, an MIS estimator can use weights w a ( x ) and w b ( x ) satisfying appropriate partition and support conditions. The balance heuristic uses

w a ( x ) = n a p a ( x ) n a p a ( x ) + n b p b ( x ) ,

with the symmetric definition for w b . For one sample from each, n a = n b = 1 .

The key idea is not “average two answers.” The estimator must evaluate the PDFs in the same measure for the same sampled event. Mixing a solid-angle PDF with an area PDF without the Jacobian conversion makes the weights meaningless.

Support matters

If technique A can sample a contribution that B cannot, then p b ( x ) = 0 at that event and A should receive full weight. But if the implementation accidentally reports zero because it evaluated the wrong lobe, wrong hemisphere, or wrong light-selection probability, MIS can hide a bug behind a numerically finite result.

For direct lighting, the full light-sampling PDF may include both discrete light selection and continuous point/direction sampling:

p l i g h t = p ( choose light ) p ( sample point or direction ∣ light ) .

The BSDF PDF must be converted to the same directional measure before comparison.

Power heuristic

A common alternative is

w a = ( n a p a ) β ( n a p a ) β + ( n b p b ) β ,

often with β = 2 . This suppresses a technique more aggressively when its PDF is much smaller than the competing proposal.

The heuristic changes variance, not the target integral, when the estimator is constructed correctly.

Scene-level MIS witness

tools/labs/path_transport_scene_lab.cpp lifts the estimator checks into an actual camera/geometry/shading path. A camera ray intersects a sphere, establishes the shading normal, and evaluates Lambertian outgoing radiance under a constant environment using two proposals for the same hemisphere integral: uniform-hemisphere light sampling and cosine-weighted BSDF sampling. Each sample evaluates both PDFs in the same solid-angle measure and uses the balance heuristic.

Because constant environment radiance over a Lambertian surface has the analytic solution

L o = ρ L e n v ,

the pixel estimate has an independent target rather than merely comparing two noisy implementations. The witness therefore checks geometry, throughput, proposal PDFs, MIS weighting and convergence together. Emissive-geometry NEE, multiple bounces, media and full rendered-image parity remain later evidence layers.
