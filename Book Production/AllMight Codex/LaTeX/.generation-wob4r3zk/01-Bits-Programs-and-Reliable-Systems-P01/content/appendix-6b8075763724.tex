\begin{allmightroledefinition}

\subsection{Definition and mechanism}\label{appendix-6b8075763724-definition-and-mechanism}

\hypertarget{appendix-6b8075763724-definition-and-mechanism}{}

Base 16 maps one digit to four bits, preserving visible bit structure compactly.

\end{allmightroledefinition}

Hex digits 0--9 and A--F represent values 0--15. A nibble is four bits, so \BookInlineCode{{1}{0}{1}{0}{\ }{1}{1}{0}{1}{₂}}{1010\ 1101₂} is \BookInlineCode{{A}{D}{₁}{₆}}{AD₁₆}. Group from the right and pad only the left when needed. Human digit order does not determine array packing order.
