\section{Weak observation and ownership cycles}\label{appendix-b9548675eb2b-weak-observation-and-ownership-cycles}

\hypertarget{appendix-b9548675eb2b-weak-observation-and-ownership-cycles}{}

\textbf{Curriculum depth:} Introduced · \textbf{First seen:} C010 · \textbf{Latest development:} C010

\begin{allmightroledefinition}

\subsection{Definition and mechanism}\label{appendix-b9548675eb2b-definition-and-mechanism}

\hypertarget{appendix-b9548675eb2b-definition-and-mechanism}{}

\BookInlineCode{std::weak\_ptr\textless T\textgreater{}} observes a \BookInlineCode{shared\_ptr} ownership group without increasing its strong count. \BookInlineCode{lock()} atomically attempts to create a temporary strong owner; the result is empty if the managed object is no longer alive. Replacing one edge of an otherwise all-strong ownership cycle with a weak observation can allow the strong count to reach zero. A check with \BookInlineCode{expired()} followed later by access is not equivalent to a successful \BookInlineCode{lock()}.

\end{allmightroledefinition}

\BookInlineCode{enable\_shared\_from\_this} joins the already-established shared ownership group; it must not create a second \BookInlineCode{shared\_ptr} control block from \BookInlineCode{this}.
