\subsection{Definition and mechanism}\label{appendix-0104b704fb11-definition-and-mechanism}

\hypertarget{appendix-0104b704fb11-definition-and-mechanism}{}

Consumer constructors/assignments now distinguish the cast from actual resource transfer. Const can force copying, return std::move(local) can prevent NRVO, and move\_if\_noexcept selects a path based on usable construction properties.

\end{allmightroledefinition}

std::move is an xvalue cast preserving constness, not a resource transfer. A deduced cv-unqualified T\&\& parameter can be a forwarding reference: lvalue arguments deduce T\& and collapse to an lvalue reference. std::forward\textless T\textgreater{} restores the category encoded by deduction.
